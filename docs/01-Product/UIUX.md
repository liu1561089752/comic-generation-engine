## 1. 设计系统基础

### 1.1 设计语言

| 维度 | 描述 |
|------|------|
| **风格定位** | 专业、高效、面向创作者的工具型应用 |
| **目标用户** | 漫画创作者、编剧、AI 生图运营人员、内容审核员 |
| **灵感来源** | Notion（内容管理）+ Figma（编辑器交互）+ Webtoon 阅读器（漫画预览） |
| **默认主题** | 深色模式为主（创作者长时间使用），辅以品牌色点缀 |
| **设计原则** | 清晰（Clear）、高效（Efficient）、一致（Consistent）、可扩展（Scalable） |

| 断点 | 宽度 | 行为 |
|------|------|------|
| **桌面** | ≥1280px | 完整三栏/两栏布局 |

## 3. 导航设计

### 3.1 主导航（左侧边栏）

按工作流顺序排列，分为三个分组：

#### 分组一：工作台

| 图标 | 名称 | 说明 |
|------|------|------|
| 📊 | Dashboard | 项目概览、统计、快速入口 |
| 📁 | 项目管理 | 所有漫画项目的列表与管理 |

#### 分组二：制作流程

| 图标 | 名称 | 说明 |
|------|------|------|
| 📖 | 小说管理 | 上传/编辑小说原文 |
| 👤 | 人物IP中心 | 角色定义、特征、服装、关系 |
| 🔍 | 剧情拆解 | Scene / Panel 拆分与标注 |
| 🎬 | 分镜中心 | 分镜稿生成与管理 |
| 📐 | 版式中心 | 页面版式模板管理 |
| 🤖 | Prompt中心 | Prompt 模板管理与历史 |
| 🖼️ | 生图中心 | 批量生图、A/B/C/D 选图 |
| ✅ | 质量控制 | 检测结果、审核流程 |

#### 分组三：输出

| 图标 | 名称 | 说明 |
|------|------|------|
| ✏️ | 漫画编辑器 | 最终合成编辑 |
| 📤 | 导出中心 | 导出设置与记录 |

#### 交互规则

- 当前激活项高亮（品牌色左侧竖条 + 文字高亮）
- 分组标题不可点击，仅做分组分隔
- 折叠态：仅显示图标，Hover 展开 Tooltip 显示名称

### 3.2 二级导航

| 类型 | 使用场景 | 规范 |
|------|----------|------|
| **Tab 切换** | 详情页内部的子视图切换（如人物详情页：基本信息 / 关系图 / 服装库 / 参考图） | 水平 Tab Bar，激活项下划线高亮 |
| **面包屑** | 层级深度导航（如：项目管理 > 项目A > 章节3） | 文字链接 + `/` 分隔符 |
| **步骤条** | 多步骤流程（如：快速开始向导） | 水平步骤指示器，已完成/当前/未完成 |

## 6. 交互规范

### 6.1 通用交互

| 交互 | 规范 |
|------|------|
| **Hover 状态** | 所有可点击元素有 hover 反馈：颜色变化 / 背景色变化 / 轻微上浮（`translateY(-1px)`） |
| **点击反馈** | 按钮点击有 0.1s 缩放效果（`scale(0.97)`），弹起恢复 |
| **Focus 状态** | 输入框、按钮 focus 显示品牌色光环（`box-shadow: 0 0 0 2px rgba(108,92,231,0.4)`） |
| **加载状态** | 所有异步操作显示 loading 指示器；列表/卡片优先使用骨架屏（Skeleton） |
| **空状态** | 列表为空时显示引导插图 + 说明文案 + 推荐操作按钮 |
| **错误状态** | 操作失败显示 Toast 通知（3 秒自动消失），表单错误在字段下方内联提示 |
| **成功状态** | 操作成功显示 Toast 通知（1.5 秒自动消失），或直接在界面内即时更新 |

#### 骨架屏规范

- 使用渐变 shimmer 动画（`@keyframes shimmer { 0% → 100% }`）
- 形状匹配真实内容布局（矩形块模拟卡片、长条模拟文字行）
- 启动时优先显示骨架屏，数据加载完成后平滑过渡

#### Toast 通知规范

| 类型 | 图标 | 位置 | 持续时间 |
|------|------|------|----------|
| 成功 | ✅ | 顶部居中 | 1.5s |
| 错误 | ❌ | 顶部居中 | 3s |
| 警告 | ⚠️ | 顶部居中 | 3s |
| 信息 | ℹ️ | 顶部居中 | 2s |

### 6.2 拖拽交互

## 8. 无障碍

### 8.1 键盘操作支持

| 操作 | 说明 |
|------|------|
| **Tab 导航** | 所有交互元素支持 Tab 键顺序聚焦 |
| **Enter / Space** | 触发焦点元素的默认操作（按钮点击、链接跳转） |
| **Arrow Keys** | 列表/表格/画布中的方向导航 |
| **Escape** | 关闭弹窗、下拉菜单、取消选中 |
| **自定义快捷键** | 见第 6.3 节快捷键列表 |

### 8.2 ARIA 标注

- 所有图标按钮必须包含 `aria-label` 属性（如 `aria-label="删除"`）
- 导航区域使用 `role="navigation"` 和 `aria-label` 标识
- 弹窗使用 `role="dialog"` + `aria-modal="true"` + `aria-labelledby`
- 状态变化使用 `aria-live="polite"` 区域通知
- 拖拽元素使用 `role="button"` + `aria-grabbed`
- 选项卡使用 `role="tablist"` / `role="tab"` / `role="tabpanel"` 模式

### 8.3 色彩对比度

| 层级 | 对比度要求 | 说明 |
|------|-----------|------|
| **主文字** | ≥ 7.0 : 1 | `#FFFFFF` on `#1A1A2E` = 16.9:1 ✅ |
| **次级文字** | ≥ 4.5 : 1 | `#A0A0B0` on `#1A1A2E` = 7.8:1 ✅ |
| **禁用文字** | ≥ 3.0 : 1 | `#606080` on `#1A1A2E` = 4.3:1 ✅ |
| **品牌色按钮文字** | ≥ 4.5 : 1 | `#FFFFFF` on `#6C5CE7` = 5.2:1 ✅ |

### 8.4 焦点指示器

- 所有可聚焦元素在 `:focus-visible` 状态下显示 2px 品牌色光环
- 避免使用 `outline: none` 而不提供替代焦点样式
- 焦点顺序与视觉顺序一致（从左到右、从上到下）
