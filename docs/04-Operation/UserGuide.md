## 1. 快速开始

5 步完成你的第一部漫画：

### 第 1 步：创建项目

1. 登录系统后，进入工作台首页
2. 点击"创建项目"按钮
3. 输入项目名称（如"我的第一部韩漫"）和简要描述
4. 点击"确认"，系统为你创建项目空间

### 第 2 步：导入小说

1. 进入项目后，点击左侧导航栏的"小说管理"
2. 点击"上传小说"按钮，选择你的小说文件（支持 TXT、DOCX、MD 格式）
3. 系统自动进行文本清洗和章节拆分
4. 清洗完成后，你可以在小说阅读器中浏览和编辑章节内容

### 第 3 步：设定人物 IP

1. 点击左侧导航栏的"人物 IP 管理"
2. 点击"创建人物"，为每个主要角色填写设定：
   - 基本信息：姓名、年龄、性别
   - 外貌特征：发色、发型、瞳色、肤色、体型
   - 服装风格：日常服装、标志性配饰
3. 系统会自动从小说中分析出候选角色，你可以直接编辑确认
4. 在"人物关系图"中查看角色之间的关系网络

### 第 4 步：运行 AI 生产管线

1. 点击左侧导航栏的"剧情拆解中心" → 点击"AI 分析"
2. 系统运行 10 个 AI Agent 自动处理：
   - 剧情分析 → 语义切句 → 分镜规划 → 镜头规划
   - 版式规划 → 气泡规划 → Prompt 生成
3. 在"AI 生图中心"中，选择要生成的画格，点击"生成图片"
4. 系统为每个画格生成 4-8 张候选图
5. 在"质量控制中心"查看 AI 一致性检测和质量评分结果

### 第 5 步：编辑与导出

1. 进入"漫画编辑器"，拖拽调整画格位置、编辑气泡文本
2. 在候选图中选择最喜欢的图片
3. 进入"导出中心"，选择导出格式（PNG 序列 / 长图 / ZIP 包）
4. 点击"导出"，下载成品漫画

## 2. 各模块使用说明

### 2.1 工作台

工作台是登录系统的首页，提供全局概览：

- **项目总览**：显示所有项目的卡片列表，每个卡片显示项目名称、进度百分比、最后更新时间
- **生产进度**：当前活跃项目的管线完成进度（小说导入 → 分镜 → 生图 → 导出）
- **任务中心**：显示近期 AI 任务执行状态（排队中/进行中/已完成/失败）
- **AI 任务队列**：实时查看当前所有 AI 任务的执行状态和进度
- **通知中心**：系统推送的通知消息，如任务完成提醒、审核通知

**使用技巧**：你可以点击项目卡片快速进入对应项目，或点击任务卡片查看任务详情。

### 2.2 小说管理

小说管理是内容生产的第一步：

- **上传小说**：支持拖拽或点击上传 TXT/DOCX/MD 文件，单文件上限 50MB
- **文本清洗**：上传后系统自动清洗文本（去噪、统一格式），你可以在清洗后手动编辑
- **章节管理**：系统自动识别章节边界，你可以手动调整章节名称和顺序
- **小说阅读器**：分章展示文本内容，支持字号调整和夜间模式
- **AI 分析**：一键触发 AI 分析，提取剧情结构、人物、场景、时间线

**支持的文件格式：**
| 格式 | 编码要求 | 说明 |
|------|----------|------|
| TXT | UTF-8 | 纯文本文件 |
| DOCX | - | Word 文档，支持保留标题层级 |
| Markdown | UTF-8 | `.md` 格式，保留基本排版 |

### 2.3 人物 IP 管理

人物 IP 管理是确保角色一致性的核心模块：

- **人物列表**：以卡片网格展示所有角色，显示头像（六视图）、姓名和简要特征
- **人物详情**：点击角色卡片进入详情页，查看和编辑角色的完整设定
- **特征设定**：支持精细化设定以下维度：
  - 外貌特征：发色、发型（示例图）、瞳色、肤色、脸型
  - 体型特征：身高、体型（苗条/健壮/丰满）
  - 服装风格：日常装、战斗装、正装等，每种可配参考图
  - 标志特征：伤疤、纹身、眼镜等辨识度高的特征
- **人物关系图**：以网络图形式展示角色之间的关系（盟友、敌对、情侣等）
- **人物尺寸图**：展示角色之间的身高比例对比，确保场景中大小一致

**最佳实践**：建议在运行 AI 管线前，为所有重要角色创建完整的人物设定。设定越详细，角色一致性越高。

### 2.4 剧情拆解

剧情拆解中心将小说文本转化为可编辑的剧情结构：

- **剧情分析**：AI 自动分析章节文本，提取场景（Scene）结构
- **场景管理**：每个 Scene 包含地点、时间、参与人物、情绪标签
- **语义切句**：AI 将每个 Scene 拆分为多个画格（Panel），每个 Panel 对应一个漫画画面
- **Panel 管理**：以列表形式展示所有 Panel，支持手动调整顺序、合并、拆分
- **原文追溯**：每个 Panel 关联原文段落，点击可跳转到原文位置

**手动编辑**：AI 分析结果可能不完美，你可以在任何环节手动修改：
- 合并相邻场景
- 调整 Panel 边界
- 修改 Panel 文本描述

### 2.5 分镜规划

分镜中心为每个 Panel 确定视觉呈现方案：

- **分镜建议**：AI 自动为每个 Panel 生成视觉描述（构图、元素、色彩）
- **镜头规划**：为每个 Panel 指定镜头类型（远景/中景/近景/特写/仰拍/俯拍）
- **构图参考**：显示构图示意图（三分法、对称、引导线等）
- **批量编辑**：支持多选 Panel 批量设置镜头类型

**分镜原则：**
- 对话场景：中景 + 正反打交错
- 动作场景：远景 + 特写结合，多角度切换
- 情绪场景：特写 + 特殊视角（俯拍/仰拍）
- 避免连续 3 个同类型镜头

### 2.6 生图

AI 生图中心是漫画制作的核心生产环节：

- **选择 Panel**：在列表中勾选需要生图的 Panel（支持单选/多选/全选）
- **配置参数**：设置生成参数（模型、步数、CFG Scale、Batch Size）
- **执行生成**：点击"开始生成"，任务进入 Celery 队列
- **进度追踪**：通过 WebSocket 实时查看生成进度
- **候选图浏览**：每个 Panel 生成完成后，在画廊中浏览所有候选图
- **选择确认**：从候选图中选择最满意的一张，标记为"通过"

**参数说明：**
| 参数 | 建议值 | 说明 |
|------|--------|------|
| 采样步数 (Steps) | 25-35 | 越高细节越多，但耗时增加 |
| CFG Scale | 6-8 | 越高与 Prompt 越一致，但可能过饱和 |
| Batch Size | 4-8 | 每批生成的候选图数量 |
| Seed | -1（随机） | 固定值可复现同一结果 |

**批量生成技巧**：建议分批次批量生成，每次 10-20 个 Panel，方便集中筛选。

### 2.7 质量控制

质量控制中心确保最终成品的质量：

- **一致性检测**：AI 自动比对角色特征与人物 IP 设定的匹配度，逐维度打分（发色、发型、瞳色、服装等）
- **质量评分**：AI 对每张图片进行多维度评分（构图、角色完整性、光影、细节）
- **缺陷报告**：标记检测到的问题（手部变形、面部异常等）
- **人工审核**：逐 Panel 确认图片质量，可"通过"或"打回重做"
- **批量操作**：支持批量通过、批量打回

**评分等级说明：**
| 等级 | 评分范围 | 建议操作 |
|------|----------|----------|
| 优秀 | ≥ 90 分 | 直接通过 |
| 良好 | 75-89 分 | 检查后通过 |
| 合格 | 60-74 分 | 建议微调后使用 |
| 不合格 | < 60 分 | 打回重新生成 |

### 2.8 漫画编辑器

漫画编辑器是最终的精细调整工具，基于 Konva.js 实现：

- **画格编辑**：拖拽调整画格位置和大小
- **图片替换**：从候选图中切换不同图片
- **气泡编辑**：添加、删除、移动气泡；调整气泡大小和形状
- **文本编辑**：修改气泡中的文字内容、字体、字号、颜色
- **图层管理**：管理图片层、气泡层、特效层的叠放顺序
- **页面管理**：切换不同页面，调整页面内画格布局
- **长图预览**：以 Webtoon 竖屏阅读模式预览整话内容

**快捷键：**
| 快捷键 | 功能 |
|--------|------|
| Ctrl+Z | 撤销 |
| Ctrl+Shift+Z | 重做 |
| Delete | 删除选中元素 |
| Ctrl+C / Ctrl+V | 复制/粘贴元素 |
| 滚轮 | 缩放画布 |
| 空格+拖拽 | 平移画布 |

### 2.9 导出

导出中心将完成的漫画输出为可发布的文件：

- **导出为 PNG 序列**：每页导出为独立的 PNG 文件，保留原始分辨率
- **导出为长图**：将所有页面拼接为一张竖长图，适合 Webtoon 平台发布
- **导出为 JPG**：压缩体积更大的 JPG 格式，适合快速分享
- **导出为 ZIP 包**：将所有资源打包为 ZIP 文件，包含图片和元数据
- **导出为 PSD**：导出为 Photoshop 源文件，保留图层结构（高级功能）

**导出设置：**
| 设置项 | 说明 | 默认值 |
|--------|------|--------|
| 图片格式 | PNG / JPG / WebP | PNG |
| 分辨率 | 画格原始分辨率 / 缩放输出 | 原始分辨率 |
| 质量 | JPG/WebP 压缩质量 | 90% |
| 包含气泡 | 是否将气泡渲染到图片上 | 是 |
| 水印 | 添加版权水印 | 否 |

## 3. 最佳实践

### 3.1 如何确保角色一致性

1. **设定完整的人物 IP**：在开始管线前，为所有主要角色创建详细的设定
2. **分维度描述**：不要只写"帅哥/美女"，而是分头发、眼睛、肤色、脸型、服装逐项描述
3. **使用参考图**：为角色上传参考图，帮助 AI 更精准理解角色外观
4. **一致性检查**：启用 AI 一致性检查 Agent，自动标记不一致的 Panel
5. **统一提示词**：在 Prompt 中心维护角色描述模板，确保所有 Panel 使用统一的角色描述

### 3.2 如何提高生图质量

1. **优化 Prompt 模板**：在 Prompt 中心精细化调整 10 层 Prompt 模板
2. **选择合适的模型**：不同的生图模型适合不同的画风（SDXL 适合半写实，SD3 适合卡通）
3. **调整生成参数**：
   - 角色一致性优先 → 提高 CFG Scale (7.5-8.5)
   - 创意多样性优先 → 降低 CFG Scale (5.0-6.5)
   - 细节丰富度优先 → 提高采样步数 (30-40)
4. **多次生成筛选**：每 Panel 生成 4-8 张候选图，从中选择最佳
5. **相同 Seed 复现**：找到满意的结果后，记录 Seed 值，后续类似场景使用相同 Seed

### 3.3 如何提高管线效率

1. **批量处理**：不要逐 Panel 操作，利用批量选择功能批量触发 AI 处理
2. **分阶段推进**：先完成所有 Scene 拆分，再统一处理分镜，再统一生成图片
3. **模板复用**：创建 Prompt 模板和版式模板，在不同项目中复用
4. **快捷键使用**：熟悉编辑器快捷键，减少鼠标操作
5. **检查点确认**：在每个关键节点（Scene 拆分完成、分镜完成）确认结果，避免问题累积

## 4. 常见场景

### 场景一：短篇小说改漫画（1-5 章）
- 预期耗时：1-2 天
- 操作建议：全自动管线运行，人工审核重点放在角色一致性和生图质量

### 场景二：中长篇改漫画（20-50 章）
- 预期耗时：1-2 周
- 操作建议：分批次处理，每 5 章为一个批次，逐批次审核

### 场景三：已有分镜的漫画制作
- 操作：在"分镜中心"手动输入分镜描述，跳过 AI 分镜规划，直接进入生图环节
