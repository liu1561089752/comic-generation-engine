> **版本**：v1.0  
> **最后更新**：2026-06-27  
> **状态**：草案

## 一、安装与配置

### Q1：系统对硬件有什么要求？

**答：** 系统本身是 B/S 架构，对客户端硬件无特殊要求。服务端最低配置如下：

| 配置项 | 最低要求 | 推荐配置 |
|--------|----------|----------|
| CPU | 4 核 | 8 核 |
| 内存 | 8 GB | 16 GB |
| 磁盘 | 50 GB | 200 GB（SSD）|
| GPU | 可选（用于本地生图） | NVIDIA RTX 3060+ |

> 生图服务可部署在远程服务器或使用云端 API，本地可不配备 GPU。

### Q2：必须安装 PostgreSQL 吗？可以用 MySQL 吗？

**答：** 系统设计使用 PostgreSQL 15+，开发环境可使用 SQLite 替代（无需安装）。不支持 MySQL。PostgreSQL 的 JSONB 数据类型和 GIN 索引是本系统数据结构的关键依赖。

### Q3：如何配置 LLM 的 API Key？

**答：** 在系统设置 → AI 模型中心中配置，或通过环境变量 `LLM_API_KEY` 设置。系统支持 GPT-4、DeepSeek、通义千问等兼容 OpenAI API 格式的模型。

### Q4：可以用 Midjourney 生成图片吗？

**答：** 可以。系统通过 Midjourney Adapter 适配 Midjourney API。你需要部署 MJ-Proxy 中间件来提供兼容 Stable Diffusion 格式的 API 接口。

## 二、小说导入

### Q5：支持哪些文件格式？

**答：** 支持 TXT（UTF-8 编码）、DOCX（Word 文档）、Markdown 三种格式。不支持 PDF、EPUB 等格式。单文件上限 50MB。

### Q6：为什么我导入的小说章节识别不准确？

**答：** AI 章节识别基于常见章节标题格式（如"第一章"、"第 1 章"、"Chapter 1"等）。如果你的小说使用特殊格式，建议：
1. 导入后在章节管理页面手动调整章节边界
2. 或先在外部编辑器中统一章节标题格式

### Q7：小说文本清洗做了什么？

**答：** AI 文本清洗 Agent 会执行以下操作：
- 移除多余空行和空格
- 统一全角/半角标点符号
- 修正常见编码错误
- 识别并保留章节标题格式
- 统一对话引号格式（中文「」或 ""）

## 三、人物 IP

### Q8：必须为所有角色创建详细设定吗？

**答：** 建议为所有主要角色（出场次数 > 3 次）创建详细设定。配角可以使用简略设定。系统会自动从小说中分析候选角色，你可以选择性确认和编辑。角色设定越详细，AI 生成的角色一致性越高。

### Q9：如何确保角色在不同画格中长相一致？

**答：** 系统通过以下机制保证角色一致性：
1. **人物 IP 档案**：集中存储角色外观设定
2. **10 层 Prompt 结构**：角色描述作为单独一层注入 Prompt
3. **一致性检查 Agent**：AI 自动检测角色特征是否与设定一致

最佳实践：为角色创建包含发色、发型、瞳色、肤色、服装的完整设定，并使用参考图。

### Q10：可以删除不需要的角色吗？

**答：** 可以。在人物 IP 列表页，点击角色卡片的删除按钮即可。删除角色不会影响已生成的图片，但后续新生成的画格将不再使用该角色的设定。建议先确认该角色不在任何活跃的管线中。

## 四、AI 管线

### Q11：AI 管线需要多长时间？

**答：** 取决于小说长度和 AI 模型响应速度。大致时间参考：

| 处理阶段 | 1 章（约 3000 字） | 10 章（约 3 万字） |
|----------|-------------------|-------------------|
| 文本清洗 | 5-10 秒 | 30-60 秒 |
| 剧情分析 | 10-30 秒 | 2-5 分钟 |
| 语义切句 | 20-60 秒 | 3-10 分钟 |
| 分镜/镜头规划 | 10-30 秒 | 2-5 分钟 |
| 版式/气泡规划 | 10-20 秒 | 1-3 分钟 |
| Prompt 生成 | 1-5 秒 | 5-20 秒 |
| **生图（每 Panel）** | **5-15 秒 × 4-8 张** | **20-60 分钟** |

> 生图是最耗时的环节，建议分批生成，每批 10-20 个 Panel。

### Q12：AI 分析结果不准确怎么办？

**答：** 所有 AI 分析结果都支持手动编辑。建议：
1. 在"剧情拆解中心"手动调整 Scene 边界和 Panel 拆分
2. 在"分镜中心"手动修改镜头描述
3. 所有修改后，触发该 Panel 的重新生成

### Q13：可以跳过某个 AI Agent 吗？

**答：** 可以。在项目设置中，你可以配置自定义工作流，选择跳过某些 Agent。例如，如果你已有分镜方案，可以跳过"分镜规划 Agent"和"镜头规划 Agent"，直接从"版式规划"开始。

## 五、生图与质量

### Q14：为什么生成的图片角色不像？

**答：** 常见原因及解决方案：
1. **角色设定不够详细**：补充发色、发型、瞳色、服装等细节
2. **Prompt 模板未正确引用角色**：检查 Prompt 中心模板中的角色变量
3. **CFG Scale 过低**：尝试提高到 7.5-8.5
4. **模型不适合**：某些模型对特定风格表现更好，尝试切换模型

### Q15：生图速度很慢怎么办？

**答：** 优化建议：
1. 降低每批生成数量（Batch Size: 4 → 2）
2. 降低采样步数（Steps: 30 → 20）
3. 使用更快的生图模型
4. 检查网络延迟（如果使用云端 API）
5. 增加 Celery Worker 并发数

### Q16：如何批量重新生成不满足的 Panel？

**答：** 在"质量控制中心"中，使用以下方法：
1. 勾选所有不满足的 Panel
2. 点击"批量打回"按钮
3. 这些 Panel 的状态变为"待生成"
4. 在"AI 生图中心"中，过滤状态为"待生成"的 Panel
5. 全选后点击"开始生成"

### Q17：AI 一致性检测的准确率如何？

**答：** 当前版本的一致性检测 Agent 使用 YOLOv8 + 特征比对技术，对发色、瞳色等明显特征的检测准确率约 85-90%。对服装细节、配饰等细微特征的检测准确率约 70-80%。建议将 AI 检测作为辅助工具，最终由人工确认。

## 六、编辑与导出

### Q18：可以在漫画编辑器中做什么？

**答：** 漫画编辑器提供以下功能：
- 调整画格位置和大小（拖拽）
- 切换 Panel 的不同候选图
- 编辑气泡文本内容和样式
- 添加/删除气泡
- 管理图层顺序
- 以 Webtoon 竖屏模式预览整话

### Q19：支持导出哪些格式？

**答：** 支持以下格式：

| 格式 | 适用场景 | 特点 |
|------|----------|------|
| PNG 序列 | 逐页编辑、发布 | 无损画质 |
| 长图（PNG/JPG） | Webtoon 平台发布 | 竖屏长图 |
| JPG 序列 | 快速分享 | 文件体积小 |
| ZIP 包 | 存档、迁移 | 包含图片和元数据 |
| PSD | 专业后期 | 保留图层结构（高级功能） |

### Q20：导出图片分辨率可以自定义吗？

**答：** 可以。在导出设置中，你可以选择：
- 原始分辨率（默认 1080×1440 每 Panel）
- 缩放比例（50%、75%、100%、150%）
- 自定义宽高

## 七、账号与安全

### Q21：如何修改密码？

**答：** 在系统设置 → 用户设置中修改密码。需要输入当前密码和新密码。新密码要求至少 8 位，包含字母和数字。

### Q22：数据会丢失吗？

**答：** 系统采用以下数据保护措施：
- 数据库每日自动备份
- 操作日志记录所有变更
- 支持数据导出备份

建议管理员配置定期异地备份。

### Q23：如何备份项目？

**答：** 两种方式：
1. 在"导出中心"导出工程包（.awfproj），包含项目所有数据
2. 在"系统管理"使用数据备份功能，备份完整数据库和文件

## 八、故障处理

### Q24：页面加载不出来怎么办？

**答：** 按以下步骤排查：
1. 检查网络连接是否正常
2. 刷新页面尝试（F5）
3. 清除浏览器缓存（Ctrl+Shift+Delete）
4. 检查后端服务是否正常运行
5. 查看浏览器控制台是否有错误信息（F12）

### Q25：AI 任务一直显示"排队中"？

**答：** 可能原因：
1. Celery Worker 未启动 → 请管理员启动 Worker
2. Redis 连接中断 → 检查 Redis 服务
3. 队列积压过多 → 等待或增加 Worker 并发数

### Q26：遇到报错"数据库连接超时"？

**答：** 常见原因及解决：
1. 数据库服务未启动 → 启动 PostgreSQL 服务
2. 连接池耗尽 → 增大 `DB_POOL_SIZE` 配置
3. 网络问题 → 检查数据库网络连通性
4. 数据库负载过高 → 检查慢查询并优化

### Q27：系统提示"磁盘空间不足"？

**答：** 清理建议：
1. 清理临时导出文件：`./data/exports/`
2. 清理缓存：`./data/storage/cache/`
3. 清理日志归档
4. 将不常用的项目导出备份后从系统中删除
5. 扩容磁盘或迁移到 MinIO 对象存储

## 九、其他问题

### Q28：系统是否支持多语言？

**答：** 当前版本支持中文界面。后续版本将支持英文。

### Q29：移动端可以使用吗？

**答：** 漫画编辑器等核心功能依赖大屏幕操作，移动端体验不佳。建议在桌面端（屏幕分辨率 1366×768 以上）使用。基础的项目管理和任务查看功能可在平板上使用。

### Q30：如何获取帮助或报告 Bug？

**答：** 通过以下渠道：
- **帮助中心**：查看内置帮助文档
- **提交 Issue**：请联系技术支持团队，在项目仓库提交 Issue

## 附录：常见错误码

| 错误码 | 含义 | 处理方法 |
|--------|------|----------|
| `NOT_FOUND` | 请求的资源不存在 | 检查资源 ID 是否正确 |
| `VALIDATION_ERROR` | 请求参数校验失败 | 检查请求参数格式 |

| `MODEL_UNAVAILABLE` | AI 模型不可用 | 检查模型配置 |
| `STORAGE_FULL` | 存储空间不足 | 清理存储空间 |
