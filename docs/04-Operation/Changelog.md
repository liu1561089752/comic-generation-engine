## [v1.0.0] - 2026-06-27

### 📌 版本概览
- **版本类型**：首个正式发布版（MVP）
- **版本代号**："启程"
- **目标**：实现完整的一条"短篇小说→Webtoon"制作管线

### ✨ 新增功能

#### 项目管理
- 项目创建、编辑、删除、归档
- 项目总览仪表盘（Dashboard）
- 项目级进度跟踪

#### 小说管理
- 小说导入（支持 TXT/DOCX/MD 格式）
- 文本自动清洗（格式统一、去噪）
- 章节自动拆分与手动编辑
- 段落编号与结构化展示
- 小说阅读器（分章浏览）

#### 人物 IP 管理
- 人物创建、编辑、删除
- 人物外貌特征设定（发色、发型、瞳色、肤色、体型）
- 人物服装风格设定
- 人物关系图（力导向图）
- 人物尺寸图（身高比例对比）

#### 世界观资产库
- 世界观管理
- 场景资产库

#### 剧情拆解
- AI 剧情分析（Scene 结构提取）
- Scene 管理（创建、编辑、排序）
- 语义切句（Scene → Panel 拆分）
- Panel 管理（列表、编辑、原文追溯）

#### 分镜规划
- AI 分镜建议生成
- 镜头类型选择（远景/中景/近景/特写/仰拍/俯拍）
- 视觉描述编辑

#### 版式规划
- 页面管理（创建、排序）
- AI 自动版式规划
- Panel 布局手动调整

#### 漫画文本
- AI 气泡规划（对白/旁白/内心独白自动识别）
- 对白管理
- 旁白管理

#### Prompt 中心
- 10 层结构化 Prompt 模板
- Prompt 编辑器
- Prompt 模板库

#### AI 生图
- 单 Panel 生图与批量生图
- 候选图管理（生成 4-8 张候选图）
- 图片版本管理
- 生图进度实时推送（WebSocket）
- 生图参数配置（Steps、CFG Scale、Batch Size）

#### 质量控制
- AI 人物一致性检测（逐维度特征比对）
- AI 质量评分（多维度评分）
- 人工审核（通过/打回）
- 缺陷报告

#### 漫画编辑器
- Canvas 画布操作（缩放、平移）
- 画格拖拽调整位置和大小
- 候选图切换
- 气泡编辑（添加、移动、修改）
- 文本编辑（字体、字号、颜色）
- 页面管理
- Webtoon 竖屏预览

#### 导出中心
- 导出为 PNG 序列
- 导出为长图
- 导出为 JPG
- 导出为 ZIP 包

#### AI 模型中心
- LLM 模型管理（添加、切换、测试连接）
- 生图模型管理
- 模型参数配置

#### 系统管理
- 用户登录/注册
- 用户设置
- 系统设置

#### 基础设施
- Docker Compose 一键部署
- 健康检查端点
- 审计日志记录

### 🔧 技术特性

#### 后端
- FastAPI 异步 REST API
- SQLAlchemy 2.0 异步 ORM
- Celery 分布式任务队列（4 个优先级队列）
- Redis 缓存 + 消息队列
- JWT 认证（Access Token + Refresh Token）
- API Key AES-256-GCM 加密存储
- 全局异常处理 + 统一响应格式
- 结构化日志（structlog）
- 请求限流（令牌桶算法）

#### 前端
- React 18 + TypeScript + Vite
- Zustand 状态管理
- Ant Design 5.x 组件库
- Tailwind CSS 原子化样式
- Konva.js 漫画编辑器
- React Router 6 嵌套路由
- WebSocket 实时通信
- 图片懒加载 + 虚拟滚动

#### AI
- 适配器模式支持多 LLM（OpenAI、DeepSeek、通义千问）
- 适配器模式支持多生图模型（SDXL、SD3 等）
- 10 层结构化 Prompt 机制
- Agent Registry 管理 10 个 AI Agent
- 幂等 Agent 设计（支持独立重跑）

### 🐛 Bug 修复
- 首个正式版，无历史 Bug 修复记录

### ⚠️ 已知问题
1. 角色一致性检测准确率约 85-90%，对细微特征（饰品、花纹）检测有限
2. 单项目建议不超过 50 话（大规模数据下性能有待优化）
3. 不支持多人实时协同编辑
4. 插件中心仅提供框架，尚无第三方插件
5. 暂不支持时间线分析功能

## 版本号规范

`主版本号.次版本号.补丁号`

| 版本段 | 变更条件 | 示例 |
|--------|----------|------|
| 主版本号 | 重大架构变更或不兼容 API 修改 | 1 → 2 |
| 次版本号 | 向下兼容的新功能 | 0 → 1 |
| 补丁号 | 向下兼容的 Bug 修复 | 1 → 2 |

**版本标签：**
- 无标签：正式发布版
- `-alpha.N`：内部测试版
- `-beta.N`：公开测试版
- `-rc.N`：发布候选版
