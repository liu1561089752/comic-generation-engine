## 第103章 LLM 模型管理

### 103.1 功能概述

LLM 模型管理模块负责配置和管理系统中使用的大语言模型（Large Language Model）。系统依赖 LLM 执行剧情分析、Prompt 生成、一致性检测等文本处理任务。支持接入符合 OpenAI API 兼容格式的各类 LLM 服务。

### 103.2 LLM 配置

#### 功能描述

提供 LLM 连接的配置界面，用户可填写 API 地址、API Key 和模型名称来接入 LLM 服务。

#### 配置字段

| 字段 | 必填 | 说明 | 示例 |
|------|------|------|------|
| 配置名称 | 是 | 当前配置的标识名称 | "我的 GPT-4 配置" |
| API 地址 | 是 | LLM 服务的 API 端点 URL | https://api.openai.com/v1 |
| API Key | 是 | 身份认证密钥 | sk-xxxxxxxxxxxxxxxx |
| 模型名称 | 是 | 使用的具体模型名 | gpt-4-turbo / deepseek-chat |
| 备用 API 地址 | 否 | 主地址不可用时的备用地址 | https://api2.openai.com/v1 |
| 代理设置 | 否 | 如需通过代理访问 | http://127.0.0.1:7890 |
| 超时时间 | 否 | API 请求超时秒数（默认 60s） | 60 |
| 最大重试次数 | 否 | 失败自动重试次数（默认 3） | 3 |

#### 操作流程

1. 进入「LLM 模型管理」页面
2. 查看当前配置概览（显示已接入的模型列表和状态）
3. 点击「添加配置」→ 弹出配置表单
4. 填写配置字段
5. 点击「保存」→ 配置保存成功
6. 点击「设为默认」→ 将该配置设为默认 LLM
7. 支持配置多个 LLM 服务，可随时切换默认配置

#### 界面要求

- API Key 输入框使用密码掩码显示
- API Key 存储时加密
- 配置列表展示：配置名称、模型名称、API 地址（脱敏）、状态（在线/离线）
- 支持编辑和删除配置
- 删除配置前确认是否已在使用中
- 状态指示灯（绿色/红色）显示连接状态

### 103.3 支持 OpenAI 兼容接口

#### 功能描述

系统 LLM 模块基于 OpenAI API 协议标准设计，兼容任何实现该协议标准的 LLM 服务。

#### 兼容性要求

| 要求 | 说明 |
|------|------|
| API 协议 | 兼容 OpenAI Chat Completions API |
| 请求格式 | 支持 messages 数组格式 |
| 响应格式 | 支持 choices 数组格式 |
| 流式输出 | 支持 SSE 流式响应（可选） |
| 功能调用 | 支持 function calling（可选） |

#### 已兼容的模型服务（示例）

| 服务商 | 模型 | API 地址 |
|--------|------|---------|
| OpenAI | GPT-4 / GPT-4o / GPT-4-turbo | https://api.openai.com/v1 |
| DeepSeek | deepseek-chat / deepseek-reasoner | https://api.deepseek.com/v1 |
| 通义千问 | qwen-max / qwen-plus | https://dashscope.aliyuncs.com/compatible-mode/v1 |
| 文心一言 | ERNIE-4.0 / ERNIE-Bot | 需使用 OpenAI 兼容代理 |
| 讯飞星火 | spark-4.0 / spark-3.5 | 需使用 OpenAI 兼容代理 |

#### 操作流程

1. 用户自行填写 API 地址和 Key
2. 系统自动检测 API 兼容性（发送轻量测试请求）
3. 兼容性通过后显示"已连接"状态
4. 不兼容时显示错误信息和建议

### 103.4 模型切换

#### 功能描述

支持在已配置的多个 LLM 模型之间自由切换，切换后系统将使用新模型执行所有 LLM 相关的任务。

#### 切换流程

1. 在 LLM 配置列表中选择一个已配置的模型
2. 点击「设为默认」
3. 系统确认切换：

| 确认项 | 说明 |
|--------|------|
| 影响范围 | 所有使用 LLM 的功能将切换为新模型 |
| 效果差异 | 提示不同模型可能产生不同的输出效果 |
| 兼容性确认 | 确认新模型支持当前使用的所有功能 |

4. 确认 → 默认 LLM 切换完成

#### 界面要求

- 当前默认模型在配置列表中高亮标记（"默认"标签）
- 切换时弹出确认对话框
- 切换完成后发送系统通知

### 103.5 模型测试

#### 功能描述

向已配置的 LLM 模型发送测试请求，验证模型的可用性和响应质量。

#### 测试方式

| 测试项 | 说明 |
|--------|------|
| 连通性测试 | 发送简单请求验证 API 是否可达 |
| 响应速度测试 | 发送标准请求测量响应时间 |
| 质量测试 | 发送特定 Prompt 评估回复质量 |
| 流式测试 | 测试 SSE 流式输出是否正常 |

#### 操作流程

1. 在 LLM 配置详情页点击「测试连接」
2. 系统自动发送测试 Prompt："请回复 Hello World 以验证连接。"
3. 测试结果显示：

| 结果项 | 说明 |
|--------|------|
| 状态 | 成功 / 失败 |
| 响应时间 | 从发送到收到完整响应的时间 |
| 响应内容 | 模型返回的原始内容 |
| Token 消耗 | 本次测试消耗的 Token 数 |
| 错误信息 | 失败时的错误详情 |

4. 支持自定义测试 Prompt 进行更深入的测试
5. 测试结果可保存到测试日志

#### 界面要求

- 测试连接显示加载动画
- 测试结果以卡片形式清晰展示
- 自定义测试提供文本输入框
- 历史测试结果可查看

## 第104章 生图模型管理

### 104.1 功能概述

生图模型管理模块负责配置和管理系统中使用的 AI 生图模型。系统支持接入符合 Stable Diffusion API 兼容格式的生图服务，用户可配置多种生图模型并根据需要切换使用。

### 104.2 生图模型配置

#### 功能描述

提供生图模型的连接配置界面，用户可填写 API 地址、API Key 和模型名称来接入生图服务。

#### 配置字段

| 字段 | 必填 | 说明 | 示例 |
|------|------|------|------|
| 配置名称 | 是 | 当前配置的标识名称 | "我的 SDXL 配置" |
| API 地址 | 是 | 生图服务的 API 端点 URL | http://127.0.0.1:7860/sdapi/v1 |
| API Key | 否 | 身份认证密钥（视服务而定） | sk-xxxxxxxx |
| 模型名称 | 是 | 使用的具体模型名 | sdxl-base-1.0 |
| 默认分辨率 | 否 | 生图默认分辨率 | 1080×1440 |
| 最大分辨率 | 否 | 支持的最大分辨率 | 2048×2048 |
| 并发限制 | 否 | 该模型的最大并发请求数 | 4 |

#### 操作流程

1. 进入「生图模型管理」页面
2. 查看当前已配置的生图模型列表
3. 点击「添加配置」→ 填写表单
4. 保存后系统自动测试连通性
5. 设置默认生图模型

#### 界面要求

- 配置列表显示：配置名称、模型名称、API 地址、状态（在线/离线）
- 状态指示灯实时显示模型可用性
- 支持编辑和删除配置
- 显示模型的默认参数预设

### 104.3 支持 Stable Diffusion API 兼容接口

#### 功能描述

系统生图模块基于 Stable Diffusion WebUI API 协议标准设计，兼容任何实现该协议标准的生图服务。

#### 兼容性要求

| 要求 | 说明 |
|------|------|
| API 协议 | 兼容 SD WebUI API（sdapi/v1）格式 |
| 端点 | 支持 txt2img、img2img 端点 |
| 参数格式 | 支持 JSON 格式的参数字段 |
| 响应格式 | 支持 base64 编码的图片返回 |

#### 已兼容的生图服务（示例）

| 服务商 | 模型 | 接入方式 |
|--------|------|---------|
| Stable Diffusion | SDXL / SD3 / SD1.5 | 本地部署 / API |
| 豆包（字节跳动） | doubao-image | 云 API（SD 兼容模式） |
| 通义万相（阿里） | tongyi-wanxiang | 云 API（SD 兼容模式） |
| Midjourney | Midjourney V6 | 通过轮询代理服务 |
| ComfyUI | 任意 ComfyUI 工作流 | 通过 ComfyUI API |

#### 界面要求

- 显示兼容的模型列表供用户参考
- 连接时自动检测 API 兼容性
- 不兼容时返回具体的错误信息和建议
- 提供接入文档链接

### 104.4 模型切换

#### 功能描述

支持在已配置的多个生图模型之间切换，切换后新的生图任务将使用当前默认模型执行。

#### 切换流程

1. 在生图模型配置列表中选择目标模型
2. 点击「设为默认」
3. 系统显示切换确认信息：

| 确认信息 | 说明 |
|---------|------|
| 当前默认模型 | 之前使用的模型 |
| 目标模型 | 要切换到的模型 |
| 参数差异 | 两个模型默认参数的差异说明 |
| 效果差异 | 两个模型出图风格的预期差异 |

4. 确认后默认生图模型切换完成

#### 界面要求

- 默认模型在列表中高亮
- 切换时有确认对话框
- 切换后可在参数预设中选择新模型的默认参数

### 104.5 模型参数预设

#### 功能描述

不同生图模型有各自的最佳参数范围，系统为每个模型提供预设的参数配置，用户在生图时可直接选择适用的参数预设。

#### 预设参数

| 参数 | 说明 | SDXL 默认 | 豆包 默认 | 通义万相 默认 |
|------|------|-----------|-----------|--------------|
| 采样步数 | Steps | 30 | 25 | 20 |
| CFG Scale | 提示词相关性 | 7.0 | 6.5 | 7.5 |
| 采样器 | Sampler | DPM++ 2M Karras | DPM++ SDE Karras | Euler a |
| 分辨率 | Width × Height | 1080×1440 | 1024×1360 | 1080×1440 |
| 高清修复 | HiRes Fix | 关闭 | 关闭 | 开启 |

#### 操作流程

1. 在生图模型配置页中点击「参数预设」
2. 查看该模型的所有预设参数方案
3. 编辑预设：修改参数值，保存为新预设
4. 设置某个预设为「默认参数」
5. 在生图任务中可直接选择应用的参数预设

#### 界面要求

- 预设列表以卡片形式展示，每张卡片显示预设名称和关键参数
- 编辑预设时参数范围自动校验
- 支持复制预设和创建新预设
- 参数预设可导出和导入

## 第105章 模型参数管理

### 105.1 功能概述

模型参数管理模块提供统一的参数预设管理能力，用户可创建不同用途的参数预设（如"高质量预设"、"快速预设"），并在生图任务中快速应用。

### 105.2 参数预设管理

#### 功能描述

创建、编辑、删除和管理生图参数预设，支持不同模型使用不同的参数预设集合。

#### 预设数据结构

| 字段 | 说明 | 示例 |
|------|------|------|
| 预设名称 | 预设标识 | "高质量预设" |
| 预设描述 | 使用场景说明 | 用于最终出图，质量优先 |
| 关联模型 | 适用的模型列表 | SDXL, 豆包, 通义万相 |
| 采样步数 | Steps | 40 |
| CFG Scale | 提示词相关性 | 7.5 |
| 采样器 | Sampler | DPM++ 2M Karras |
| 分辨率 | 图片尺寸 | 1080×1440 |
| 高清修复 | 是否开启高清修复 | 开启 |
| 高清修复倍率 | Upscale 倍数 | 1.5 |
| 负面 Prompt | 默认负面 Prompt | "nsfw, low quality, ..." |
| 种子 | Seed（-1 为随机） | -1 |
| 批量大小 | Batch Size | 1 |
| 裁剪模式 | Clip Skip | 2 |

#### 预设分类

| 分类 | 说明 | 适用场景 |
|------|------|---------|
| 高质量预设 | 高步数、高清修复、质量优先 | 最终出图、精品制作 |
| 快速预设 | 低步数、低分辨率、速度优先 | 草图测试、快速迭代 |
| 平衡预设 | 质量和速度的折中 | 日常使用 |
| 自定义预设 | 用户完全自定义 | 特殊需求 |

#### 操作流程

1. 进入「参数预设管理」页面
2. 查看所有预设列表
3. 点击某个预设 → 查看详细参数
4. 编辑预设：修改参数值
5. 新建预设：选择模板后自定义
6. 删除预设：确认删除

#### 界面要求

- 预设列表以卡片网格展示，不同分类用颜色区分
- 每张卡片显示预设名称、描述和关键参数摘要
- 编辑参数时实时显示参数值标签
- 参数值超出模型支持范围时提示警告

### 105.3 参数模板应用到生图任务

#### 功能描述

用户在创建生图任务时，可直接从参数预设中选择预设参数，一键应用到任务配置中。

#### 应用流程

1. 在生图任务创建页面中选择「参数预设」
2. 下拉列表展示所有可用的参数预设
3. 选择预设 → 自动填充所有参数
4. 用户可在此基础上微调参数
5. 若有参数超出模型支持范围，系统自动提示并建议调整

#### 界面要求

- 预设选择下拉列表带有预览（预设名称 + 简要说明）
- 应用预设后，已修改的参数标记为"已修改"状态
- 支持重置为预设原始值

### 105.4 参数范围校验

#### 功能描述

系统为每个参数定义合法范围，在用户编辑参数或应用预设时进行校验，防止无效参数导致的生图失败。

#### 参数校验范围

| 参数 | 最小 | 最大 | 说明 |
|------|------|------|------|
| 采样步数 | 1 | 50 | 步数过少图片质量差，过多不增加收益 |
| CFG Scale | 1.0 | 30.0 | 过高会导致色彩饱和度过高 |
| 分辨率（宽） | 512 | 2048 | 取决于模型支持 |
| 分辨率（高） | 512 | 2048 | 取决于模型支持 |
| 批量大小 | 1 | 8 | 取决于硬件配置 |
| 高清修复倍率 | 1.0 | 2.0 | 过高可能失真 |

#### 校验方式

| 校验类型 | 说明 | 处理方式 |
|---------|------|---------|
| 范围校验 | 参数值是否在合法范围内 | 超出时显示红色警告 |
| 模型兼容校验 | 参数是否被当前模型支持 | 不支持时显示黄色提示 |
| 硬件限制校验 | 参数组合是否超出硬件能力 | 超出时显示建议调整 |

#### 界面要求

- 参数输入框右侧显示合法范围提示
- 超出范围时输入框红色高亮，显示错误提示
- 不兼容时显示黄色警告图标和建议值
- 提交前进行整体校验，汇总显示所有问题

## 第106章 模型切换

### 106.1 功能概述

模型切换模块提供项目级别的模型管理，支持为不同项目设置不同的默认模型，并支持批量切换项目中所有待生成任务的模型。

### 106.2 项目级模型设置

#### 功能描述

每个项目可独立设置默认的 LLM 模型和生图模型，不同项目可使用不同的模型组合。

#### 项目模型设置

| 设置项 | 说明 | 默认值 |
|--------|------|--------|
| 默认 LLM 模型 | 该项目使用的 LLM | 系统全局默认 LLM |
| 默认生图模型 | 该项目使用的生图模型 | 系统全局默认生图模型 |
| 默认参数预设 | 该项目默认使用的参数预设 | 平衡预设 |

#### 操作流程

1. 进入项目设置 →「模型设置」选项卡
2. 选择该项目使用的 LLM 模型（从已配置的模型中选择）
3. 选择该项目使用的生图模型（从已配置的模型中选择）
4. 选择该项目默认的参数预设
5. 保存设置

#### 界面要求

- 项目模型设置在项目详情页或项目设置中
- 下拉列表显示所有已配置的模型及其状态
- 未配置模型时显示"前往 AI 模型中心配置"链接

### 106.3 批量切换

#### 功能描述

当用户需要更换生图模型时，可将项目中所有待生成（未执行）的任务批量切换到新模型。

#### 切换流程

1. 在生图模型配置中选定新模型
2. 点击「批量切换」→ 弹出切换配置

| 配置项 | 说明 | 默认 |
|--------|------|------|
| 切换范围 | 当前项目 / 所有项目 | 当前项目 |
| 切换对象 | 仅待生成任务 / 全部任务（含已生成） | 仅待生成任务 |
| 参数适配 | 自动适配新模型的参数预设 | 是 |
| 预览影响 | 显示本次切换会影响的任务数量 | - |

3. 确认切换 → 系统将选定任务的模型配置更新为新模型
4. 已完成生成的任务不受影响

#### 界面要求

- 切换前显示影响范围统计
- 切换过程显示进度条
- 切换完成后显示结果报告
- 支持撤销操作（恢复到切换前的模型配置快照）

### 106.4 模型兼容性提示

#### 功能描述

在切换模型时，系统自动检查新模型与原任务的参数兼容性，并提供调整建议。

#### 兼容性检查项

| 检查项 | 说明 |
|--------|------|
| 参数兼容性 | 检查原任务的参数是否在新模型支持的范围内 |
| 功能兼容性 | 检查新模型是否支持原任务所需的功能（如高清修复） |
| 分辨率兼容性 | 检查原任务的分辨率是否在新模型支持的范围内 |
| 模型特性差异 | 提示两个模型之间的特性差异 |

#### 提示方式

| 兼容性等级 | 标识 | 说明 |
|-----------|------|------|
| 完全兼容 | ✅ | 所有参数和功能都兼容 |
| 部分兼容 | ⚠️ | 部分参数需要调整才能适配 |
| 不兼容 | ❌ | 存在无法兼容的参数，需要手动修改 |

#### 界面要求

- 兼容性提示在切换确认对话框中展示
- 不兼容的参数项以红色标记并给出建议值
- 支持一键应用建议值
- 兼容性检查结果可导出

## 第107章 模型调用日志

### 107.1 功能概述

模型调用日志记录系统中每次 AI 模型 API 调用的完整信息，包括 LLM 调用和生图模型调用。用户可查看调用详情、分析性能和排查错误。

### 107.2 调用记录

#### 功能描述

完整记录每次 API 调用的请求和响应详情，包括输入参数、输出结果和性能指标。

#### 调用记录数据结构

| 字段 | 说明 | 示例 |
|------|------|------|

### 107.3 请求/响应详情

#### 功能描述

查看单次 API 调用的完整请求和响应数据，用于调试和分析。

#### 详情展示

| 区域 | 内容 |
|------|------|
| 请求头 | 调用时发送的 HTTP 请求头（不含敏感信息） |
| 请求体 | 完整的请求参数 JSON |
| 响应头 | 返回的 HTTP 响应头 |
| 响应体 | 完整的响应结果 JSON |
| 原始数据 | 原始请求/响应的 Base64 或文件链接（如生图返回的图片） |

#### 操作流程

1. 在调用日志列表中点击某条记录 → 展开详情
2. 查看请求和响应的完整内容
3. 对于生图请求，可在详情中预览生成的图片
4. 支持复制请求参数（方便手动测试）

#### 界面要求

- 请求/响应以折叠面板展示，默认折叠
- JSON 内容格式化展示，支持语法高亮
- 敏感字段（如 API Key）自动脱敏
- 生图响应中的图片以缩略图展示
