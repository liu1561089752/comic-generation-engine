# 第十五篇 资源中心

---

## 第98章 图片资源库

### 98.1 功能概述

图片资源库是项目中所有图片的统一管理中心。无论是 AI 生成的图片、用户上传的参考图还是外部导入的素材，都在此进行集中管理。用户可进行浏览、筛选、搜索和查看元数据操作。

### 98.2 统一图片管理

#### 功能描述

以统一的视图展示项目中所有类型的图片资源，支持多维度的浏览和检索。

#### 图片类型

| 类型 | 来源 | 说明 |
|------|------|------|
| AI 生成图 | AI 生图中心 | 由 AI 模型生成的漫画 Panel 图片 |
| 候选图 | AI 生图中心 | AI 生成的备选图片（未被选中的） |
| 参考图 | 用户上传 | 用于角色或场景设计的参考图片 |
| 素材图 | 用户上传/素材库 | 背景、特效、装饰等素材 |
| 封面图 | 用户上传 | 项目或章节封面 |

#### 视图模式

| 模式 | 说明 | 适用场景 |
|------|------|---------|
| 网格视图（默认） | 缩略图网格排列，4-6 列 | 快速浏览 |
| 列表视图 | 缩略图+详细信息列表 | 批量操作 |
| 详情视图 | 大图预览+右侧信息面板 | 查看图片详情 |

#### 界面要求

- 默认以网格视图展示，缩略图尺寸 200×280px（漫画比例），圆角 4px
- 列表视图可自定义显示的列（名称、类型、大小、生成时间、模型等）
- 支持选中多张图片进行批量操作（导出、删除、添加标签）
- 拖拽调整缩略图大小（滑块控制）
- 缩略图懒加载，滚到哪加载到哪

### 98.3 多维筛选

#### 功能描述

支持按项目、章节、Panel 等多个维度对图片进行筛选过滤。

#### 筛选维度

| 筛选维度 | 说明 | 示例 |
|---------|------|------|
| 按项目 | 选择特定项目 | 修仙之王 |
| 按章节 | 选择特定章节 | 第5章 |
| 按 Scene | 选择特定场景 | Scene-002 |
| 按 Panel | 选择特定画格 | Panel-0032 |
| 按图片类型 | AI 生成 / 参考图 / 素材 | AI 生成图 |
| 按生成模型 | 使用的生图模型 | SDXL / 豆包 |
| 按生成时间 | 时间范围 | 最近 7 天 |
| 按状态 | 已选 / 候选 / 待审核 | 已选 |

#### 操作流程

1. 进入图片资源库 → 默认显示当前项目全部图片
2. 点击筛选栏的某个维度 → 展开该维度的选择器
3. 支持多维度组合筛选，各维度之间为 AND 关系
4. 筛选结果实时更新

#### 界面要求

- 筛选栏在图片列表上方，以横向排列的筛选条件展示
- 每个筛选项以 Tag 形式展示，可单独移除
- 维度选择器支持搜索（如章节较多时可通过搜索定位）
- 结果显示当前筛选条件下的图片数量
- 支持保存筛选条件为预设，方便快速切换

### 98.4 图片标签和搜索

#### 功能描述

支持为图片添加自定义标签，并通过标签和关键词搜索快速定位图片。

#### 标签管理

| 功能 | 说明 |
|------|------|
| 添加标签 | 选中图片后，在右侧面板或右键菜单中添加标签 |
| 标签分类 | 内置分类：人物 / 场景 / 道具 / 特效 |
| 自定义标签 | 用户可创建任意自定义标签 |
| 标签颜色 | 标签可设置颜色以区分类型 |
| 批量标签 | 选中多张图片后批量添加/移除标签 |
| 标签统计 | 显示每个标签下的图片数量 |

#### 搜索功能

| 搜索方式 | 说明 |
|---------|------|
| 关键词搜索 | 搜索图片文件名、标签、关联 Panel 编号 |
| 标签搜索 | 按标签精确匹配图片 |
| 混合搜索 | 关键词+标签组合搜索 |

#### 界面要求

- 搜索框在页面顶部，支持 Enter 确认和实时搜索（300ms 防抖）
- 标签以彩色 Badge 形式展示在缩略图右下角
- 搜索关键词在结果中高亮显示
- 支持标签云的展示方式（标签大小关联该标签的图片数量）

### 98.5 图片详情与元数据

#### 功能描述

查看单张图片的详细信息，包括基础属性、生成参数和关联数据。

#### 元数据展示

| 信息类别 | 字段 | 说明 |
|---------|------|------|
| 基础信息 | 文件名 | 图片文件名 |
| | 文件大小 | 如 2.3MB |
| | 分辨率 | 如 1080×1440 |
| | 格式 | PNG / JPG |
| | 创建时间 | 图片生成或上传时间 |
| | 修改时间 | 最后修改时间 |
| 生成参数 | 模型名称 | SDXL / 豆包 / 通义万相 |
| | 生图参数 | 步数、CFG Scale、分辨率、Seed |
| | 正向 Prompt | 生成时使用的正向 Prompt |
| | 负向 Prompt | 生成时使用的负向 Prompt |
| | 生成耗时 | 图片生成用时 |
| 关联数据 | 关联项目 | 所属项目 |
| | 关联章节 | 所属章节 |
| | 关联 Panel | 关联的画格编号 |
| | 关联角色 | 图片中出现的角色 |
| | 关联场景 | 图片中的场景 |
| 版本信息 | 版本号 | 图片版本编号 |
| | 是否为选中版本 | 是/否 |
| | 历史版本 | 该图片的历史版本列表 |

#### 界面要求

- 左侧大图预览（可缩放查看细节）
- 右侧信息面板展示元数据
- 元数据按类别折叠分组显示
- 生成参数中的 Prompt 支持一键复制
- 关联数据可点击跳转到对应页面
- 支持下载原图、复制图片到剪贴板

## 第99章 Prompt 资源库

### 99.1 功能概述

Prompt 资源库是用户在项目中使用的所有 Prompt 的存档中心。系统自动收集每次 AI 生图所用的 Prompt，并按效果评分排序，方便用户复用好用的 Prompt 配方。

### 99.2 Prompt 存档

#### 功能描述

自动记录项目中每次 AI 生图任务使用的完整 Prompt 数据，包括正向 Prompt、负向 Prompt、生图参数和生成结果。

#### 存档数据结构

| 字段 | 说明 | 示例 |
|------|------|------|
| Prompt ID | 唯一标识 | PR-20260627-001 |
| 关联项目 | 所属项目 | 修仙之王 |
| 关联 Panel | 关联的画格 | Panel-0032 |
| Prompt 类型 | 正向 / 负向 | 正向 |
| Prompt 内容 | 完整的 Prompt 文本 | "1girl, swordsman, ..." |
| 模板来源 | 使用的 Prompt 模板 | "战斗场景模板 v2" |
| 生成模型 | 使用的 AI 模型 | SDXL |
| 生图参数 | 步数、CFG、分辨率等 | {steps:30, cfg:7.5} |
| 关联图片 | 该 Prompt 生成的图片列表 | [img001, img002] |
| 效果评分 | 用户评分（1-5 星） | 4.5 |
| AI 质量评分 | AI 自动评分 | 4.2/5.0 |
| 使用次数 | 该 Prompt 被复用的次数 | 12 |
| 创建时间 | Prompt 首次使用时间 | 2026-06-27 |
| 标签 | 用户添加的标签 | ["战斗", "单人"] |

#### 操作流程

1. 系统自动记录每次生图任务的 Prompt 到资源库
2. 用户在资源库中浏览、搜索和查看 Prompt
3. 点击某条 Prompt → 展开详情，查看完整内容和生成的图片
4. 用户可以手动为 Prompt 评分和添加标签

#### 界面要求

- Prompt 列表以卡片形式展示，每张卡片显示 Prompt 摘要、评分、模型和预览图
- Prompt 内容较长时折叠显示，点击展开查看全文
- 关联图片以缩略图小网格展示
- 支持一键复制 Prompt 内容

### 99.3 效果评分与排序

#### 功能描述

支持用户对 Prompt 的效果进行评分，系统根据评分自动排序，高评分 Prompt 置顶推荐。

#### 评分机制

| 评分来源 | 占比 | 说明 |
|---------|------|------|
| 用户评分 | 70% | 用户手动评分（1-5 星） |
| AI 质量评分 | 20% | 系统自动评定的图片质量 |
| 复用次数 | 10% | Prompt 被复用的次数（越高分越高） |

#### 排序方式

| 排序 | 说明 |
|------|------|
| 综合评分（默认） | 按综合评分降序排列 |
| 用户评分 | 按用户评分降序 |
| 使用次数 | 按复用次数降序 |
| 最近使用 | 按使用时间降序 |

#### 界面要求

- 评分以星级图标展示（★☆☆☆☆）
- 综合评分以数字形式展示（如 4.5/5.0）
- 高评分 Prompt（评分 ≥ 4.5）有"推荐"标签
- 评分鼠标悬停可查看具体评分项

### 99.4 高评分 Prompt 推荐

#### 功能描述

系统自动筛选综合评分前 10% 的 Prompt 作为推荐，在 Prompt 编辑器中提供快捷引用入口。

#### 推荐展示

| 区域 | 展示内容 |
|------|---------|
| 推荐列表 | 评分最高的 20 条 Prompt |
| 快速插入 | 在 Prompt 编辑器中以"推荐"标签展示 |
| 推荐理由 | 显示高评分原因（如"人物一致性优秀"、"细节丰富"） |

#### 操作流程

1. 在 Prompt 资源库默认展示推荐 Prompt 列表
2. 推荐列表支持按模型筛选（如只看 SDXL 的高评分 Prompt）
3. 在 Prompt 编辑器中，点击「推荐」面板可快速插入推荐 Prompt

#### 界面要求

- 推荐 Prompt 带有"🔥 推荐"角标
- 推荐列表展示评分最高的 Prompt，附带示例图
- 推荐理由以简短文字展示在 Prompt 下方

### 99.5 Prompt 复用

#### 功能描述

将历史 Prompt 应用到其他 Panel，无需手动重新编写。

#### 操作流程

1. 在 Prompt 资源库中找到目标 Prompt
2. 点击「复用」按钮 → 弹出选择目标对话框

| 参数 | 说明 |
|------|------|
| 应用范围 | 单个 Panel / 批量 Panel / 整个场景 |
| 覆盖策略 | 完全覆盖 / 仅覆盖指定字段 |
| 参数调整 | 是否允许在应用前微调参数 |

3. 选择目标 Panel 后点击「确认应用」
4. 系统将 Prompt 应用到目标 Panel，生成新的生图任务
5. 应用完成后跳转至生图任务队列

#### 界面要求

- 复用前可预览 Prompt 内容
- 批量应用时显示目标 Panel 数量
- 应用进度条实时显示
- 支持撤销操作（如误应用）

## 第100章 模板资源库

### 100.1 功能概述

模板资源库管理系统中所有可复用的模板，涵盖版式模板、画风模板和 Prompt 模板。用户可创建、编辑、导入和导出模板，并通过模板市场进行分享。

### 100.2 版式模板管理

#### 功能描述

管理 Webtoon 页面布局模板，包括 Panel 分割方式、页面结构、阅读顺序等。

#### 版式模板数据结构

| 字段 | 说明 | 示例 |
|------|------|------|
| 模板名称 | 模板标识 | "标准三格" |
| 模板描述 | 使用场景说明 | 适合对话场景 |
| Panel 数量 | 每页包含的 Panel 数 | 3 |
| 布局结构 | Panel 位置和尺寸定义 | JSON 结构 |
| 阅读顺序 | Panel 的 Z 轴顺序 | [1, 2, 3] |
| 默认气泡位置 | Panel 中气泡的默认位置 | 右上 / 左下 |
| 封面缩略图 | 布局预览图 | image.png |
| 适用场景 | 推荐使用的场景类型 | 对话 / 动作 / 混合 |
| 使用次数 | 该模板被使用的次数 | 45 |
| 创建者 | 模板创建者 | 系统 / 用户名 |

#### 操作流程

1. 进入版式模板管理页面 → 展示所有可用模板
2. 支持按「适用场景」筛选（对话/动作/混合）
3. 点击模板 → 预览布局效果
4. 创建新模板：编辑 Panel 布局、保存命名
5. 编辑已有模板：修改布局参数
6. 删除模板：确认后删除

#### 界面要求

- 模板以缩略图网格展示，缩略图显示布局预览
- 鼠标悬停时放大显示布局细节
- 模板编辑使用可视化编辑器（拖拽调整 Panel 分隔线）
- 支持从已有模板复制作为新模板的起点

### 100.3 画风模板管理

#### 功能描述

管理漫画画风模板，定义整体视觉风格，包括线条风格、上色风格、光影效果、渲染方式等。

#### 画风模板数据结构

| 字段 | 说明 | 示例 |
|------|------|------|
| 模板名称 | 风格标识 | "韩漫厚涂风" |
| 风格描述 | 风格说明 | 厚涂上色，写实光影 |
| 风格标签 | 关键词标签 | ["厚涂", "写实", "韩漫"] |
| 参考图片 | 风格参考图 | image.png |
| 生图参数预设 | 推荐的生图参数 | {steps:30, cfg:7.0} |
| Prompt 前缀 | 风格相关 Prompt 前缀 | "masterpiece, best quality, ..." |
| 适用范围 | 人物 / 场景 / 全部 | 全部 |

#### 操作流程

1. 进入画风模板管理页面
2. 查看模板列表，支持网格/列表视图
3. 点击模板 → 查看详细风格说明和参考图
4. 应用画风模板到项目：选择模板 → 确认应用到项目
5. 编辑模板：修改风格参数、替换参考图

#### 界面要求

- 模板展示时附带多张参考样图
- 参考图支持放大查看
- 应用画风模板时显示该模板生成的示例图片
- 标签系统支持多选筛选

### 100.4 Prompt 模板管理

#### 功能描述

管理 Prompt 模板库，模板包含 Prompt 的结构化框架和变量定义，用于快速组装出高质量的 Prompt。

#### Prompt 模板结构

```
模板名称: 战斗场景标准
模板内容:
  [质量前缀], [角色描述], [动作描述], [环境描述], [光照描述], [镜头描述], [风格后缀]
变量:
  - [角色描述]: ${character_name}, ${character_outfit}, ${character_expression}
  - [动作描述]: ${action_description}
  - [环境描述]: ${environment} background, ${weather}
  - [光照描述]: ${lighting}
  - [镜头描述]: ${camera_angle}, ${camera_distance}
  - [质量前缀]: masterpiece, best quality, ultra-detailed
  - [风格后缀]: webtoon style, korean comic style
```

#### 操作流程

1. 进入 Prompt 模板管理页面
2. 查看模板列表，按场景类型分类
3. 编辑模板：修改 Prompt 框架、增删变量
4. 测试模板：在编辑器中填入变量值，预览生成的 Prompt
5. 保存为新版本

#### 界面要求

- 模板编辑器支持变量高亮和自动补全
- 变量定义区域独立展示，可批量编辑
- 模板测试区实时显示变量替换后的完整 Prompt
- 支持模板版本对比

### 100.5 模板市场

#### 功能描述

模板市场是模板的交换中心，支持模板的导入和导出，用户可将自己的模板分享给他人，也可导入他人分享的模板。

#### 功能特性

| 功能 | 说明 |
|------|------|
| 模板导出 | 将选定模板导出为 .awftemplate 文件 |
| 模板导入 | 从 .awftemplate 文件导入模板 |
| 模板包 | 批量导出多个模板为一个包 |
| 内置模板 | 系统预置的官方模板（不可删除） |
| 用户模板 | 用户创建的自定义模板 |

#### 操作流程

**导出模板：**
1. 选中一个或多个模板
2. 点击「导出」→ 选择导出格式（单个/打包）
3. 确认导出 → 下载文件

**导入模板：**
1. 点击「导入」→ 选择 .awftemplate 文件
2. 系统解析模板内容，显示预览信息
3. 确认导入 → 模板加入用户模板库
4. 如有同名模板，选择「覆盖」或「重命名」

#### 界面要求

- 导入时显示模板的完整信息和兼容性说明
- 导出文件自动命名包含模板名和版本号
- 模板市场支持搜索模板名称和描述
- 已安装的模板显示"已安装"标记

## 第101章 素材资源库

### 101.1 功能概述

素材资源库管理用户上传的自定义素材资源，包括背景图片、特效素材、装饰元素和边框素材。用户可在漫画编辑器中直接使用这些素材。

### 101.2 自定义素材上传

#### 功能描述

支持用户上传自己的素材文件到系统，上传后自动分类并可在编辑器中调用。

#### 上传流程

1. 点击「上传素材」→ 选择文件或拖拽文件到上传区域
2. 支持的文件格式：

| 格式 | 类型 | 最大文件大小 |
|------|------|-------------|
| PNG | 图片 | 50MB |
| JPG | 图片 | 50MB |
| WebP | 图片 | 50MB |
| SVG | 矢量图 | 5MB |
| GIF | 动图 | 20MB |

3. 上传时填写素材信息：

| 字段 | 必填 | 说明 |
|------|------|------|
| 素材名称 | 是 | 用于搜索和识别 |
| 素材分类 | 是 | 背景/特效/装饰/边框 |
| 标签 | 否 | 自定义标签，多个用逗号分隔 |
| 素材描述 | 否 | 对素材的说明 |

4. 上传完成后素材自动进入对应分类的素材库

#### 界面要求

- 上传区域支持点击选择和拖拽上传
- 支持多文件同时上传
- 上传进度条展示每个文件的上传进度
- 上传完成后显示缩略图预览
- 文件名重复时提示重命名或覆盖

### 101.3 素材分类

#### 功能描述

素材按用途分为四大类，每类素材在编辑器中有不同的用途。

#### 分类说明

| 分类 | 说明 | 示例 |
|------|------|------|
| 背景素材 | 用于漫画 Panel 的背景图片 | 风景、室内、城市 |
| 特效素材 | 用于增强画面效果 | 闪光、爆炸、烟雾、速度线 |
| 装饰素材 | 用于页面装饰 | 分隔线、装饰花纹、标题框 |
| 边框素材 | 用于 Panel 边框样式 | 圆角边框、破碎边框、特效边框 |

#### 操作流程

1. 默认按分类展示素材库（Tab 切换）
2. 每个分类独立展示该分类下的所有素材
3. 支持在分类内进一步按标签筛选

#### 界面要求

- 顶部 Tab 切换四大分类
- 每个分类显示该分类的素材数量和最新上传时间
- Tab 切换时保留之前的筛选状态
- 分类文件夹图标区分

## 第102章 图标资源库

### 102.1 功能概述

图标资源库管理系统中的所有图标资源，包括系统内置图标和用户上传的自定义图标。图标可在漫画编辑器中作为界面元素使用，也可用于漫画中的符号和标记。

### 102.2 系统图标管理

#### 功能描述

管理系统中预置的所有图标资源，用户可浏览、搜索和使用系统图标。

#### 图标类型

| 类型 | 说明 | 数量（预估） |
|------|------|-------------|
| 表情图标 | 用于表示角色表情变化 | 50+ |
| 动作图标 | 表示动作姿态的图标 | 30+ |
| 道具图标 | 道具的简化图标表示 | 40+ |
| 特效图标 | 特殊效果的图标表示 | 25+ |
| 装饰图标 | 页面装饰用图标 | 60+ |
| 符号图标 | 标点符号、指示符号等 | 20+ |

#### 操作流程

1. 进入图标资源库 → 默认展示系统图标分类
2. 按分类浏览系统图标，支持缩略图/列表视图
3. 搜索图标名称或标签
4. 点击图标 → 查看图标详情（名称、分类、尺寸、SVG 源码）
5. 点击「使用」→ 图标插入到编辑器当前选中位置

#### 界面要求

- 图标以网格列表展示，每个图标居中显示
- 图标大小统一为 64×64px 预览
- 支持调整预览大小（小/中/大）
- 图标详情可查看和复制 SVG 代码
- 分类标签在顶部 Tab 切换

### 102.3 用户上传图标

#### 功能描述

支持用户上传自定义图标文件，用于扩展图标库或替换系统图标。

#### 上传要求

| 格式 | 说明 | 支持 |
|------|------|------|
| SVG | 矢量图标，推荐 | ✓ |
| PNG | 栅格图标 | ✓（自动转换为 SVG 建议） |
| ICO | Windows 图标格式 | ✓ |
| WebP | 现代图片格式 | ✓ |

#### 操作流程

1. 在图标库点击「上传图标」
2. 选择图标文件（推荐 SVG 格式）
3. 填写图标信息：

| 字段 | 必填 | 说明 |
|------|------|------|
| 图标名称 | 是 | 用于搜索和识别 |
| 图标分类 | 是 | 选择一个已有分类或新建 |
| 标签 | 否 | 自定义标签 |

4. 上传完成后图标自动归入对应分类

#### 界面要求

- 上传区域支持拖拽和点击选择
- SVG 文件上传后显示矢量缩放预览
- PNG 上传后提供背景透明化编辑（可选）
- 图标上传后实时出现在资源库中

### 102.4 图标在编辑器中使用

#### 功能描述

图标资源库中的图标可在漫画编辑器中直接拖拽或点击使用，作为漫画中的装饰元素或功能标识。

#### 使用方式

| 方式 | 说明 |
|------|------|
| 拖拽使用 | 从资源库拖拽图标到编辑器的目标位置 |
| 点击插入 | 在资源库点击图标 → 图标插入到当前选中的 Panel |
| 替换使用 | 选中编辑器中已有图标 → 在资源库选择替换 |

#### 图标编辑

图标插入到编辑器后，支持以下编辑操作：

| 操作 | 说明 |
|------|------|
| 缩放 | 调整图标大小 |
| 旋转 | 调整图标角度 |
| 颜色调整 | 修改图标颜色（仅 SVG） |
| 透明度 | 调整图标透明度 |
| 位置 | 自由拖拽移动图标位置 |
| 图层顺序 | 调整图标在 Panel 中的图层叠放顺序 |
| 复制 | 复制图标到其他位置 |
| 删除 | 从编辑器中删除图标 |

#### 界面要求

- 资源库面板在编辑器侧边栏可固定/收起
- 拖拽时显示图标预览和放置位置提示
- 插入后的图标保留在资源库中的原始分类关联
- 支持在编辑器中快捷打开资源库搜索
