# 第八篇 Webtoon版式中心

---

## 第54章 页面管理

### 54.1 功能描述

页面管理是 Webtoon 版式编排的基础模块，负责管理漫画页面的增删、排序和状态跟踪。每个页面由若干 Panel（画格）组成，页面管理决定了整部漫画的页面结构和翻页节奏。

**核心功能：**
- 页面列表展示：页码、版式类型（单格/双格/三格/四格/整页/跨格）、包含 Panel 数、状态
- 页面排序：支持拖拽调整页面顺序
- 页面增删：在任意位置插入新页面、删除空页面
- 页面状态跟踪：待编辑 / 已排版 / 已生成 / 已完成
- 页面与章节的归属关系管理

### 54.2 操作流程

1. **查看页面列表**：进入页面管理，默认按章节分组展示所有页面
2. **自动生成页面**：点击"自动排版"，系统根据 Panel 数量和版式规则自动生成页面
3. **手动添加页面**：在指定位置点击"添加页面"，选择版式类型
4. **删除页面**：选中空页面或确认删除后移除（含 Panel 的页面需二次确认）
5. **拖拽排序**：通过拖拽调整页面在章节内的顺序
6. **页面编辑**：点击页面进入版式编辑模式
7. **状态更新**：手动更新页面处理状态

### 54.3 界面要求

- **网格列表视图**：以缩略网格形式展示页面，每页显示为矩形缩略图
- **页面缩略图**：在缩略图中以简化方块示意 Panel 布局
- **页码标注**：每个缩略图左上角显示页码
- **页眉信息**：每个缩略图下方显示版式类型标签和 Panel 数量
- **状态色条**：页面左侧或底部用色条标识状态
- **拖拽排序**：支持整页拖拽，拖拽时有半透明占位提示
- **节/话分组**：按"话"分组，组标题显示话号和 Panel 总数统计
- **批量操作**：支持多选页面进行批量状态更新

## 第55章 Webtoon模板管理

### 55.1 功能描述

模板管理提供 Webtoon 版式模板的定义、管理和复用能力。模板决定了 Panel 在页面中的排列方式和相对比例，是保证版式多样性和效率的关键。

**核心功能：**
- 模板库管理：系统内置常用版式模板库
- 模板类型：
  - 单格模板：单个 Panel 占满整页
  - 双格模板：上下/左右排列两个 Panel
  - 三格模板：1+2 或 2+1 或均分三格
  - 四格模板：2×2 网格或 1+3 等排列
  - 整页模板：整页作为一个大 Panel（适合高潮场景）
  - 跨格模板：Panel 跨越两个或多个画格
- 模板预览：以缩略图和示意图形式预览模板
- 自定义模板：用户自定义 Panel 排列方式和比例
- 模板导入/导出：支持模板文件的导入和导出（JSON 格式）

### 55.2 操作流程

1. **浏览模板库**：进入模板管理，浏览系统内置模板
2. **选择模板**：点击模板缩略图查看详情，点击"应用"将模板用于当前页面
3. **预览模板**：模板详情页显示大尺寸示意图和参数
4. **自定义模板**：点击"创建模板"，在编辑器中自定义 Panel 数量和比例
5. **保存模板**：将自定义模板保存到"我的模板"分类
6. **导入模板**：选择 JSON 文件导入外部模板
7. **导出模板**：选择已有模板导出为 JSON 文件

### 55.3 界面要求

- **模板库网格**：以卡片网格展示模板库，每张卡片显示模板名称、缩略图和 Panel 数量
- **模板分类 Tab**：按类型分类（单格/双格/三格/四格/整页/跨格 + 我的模板）
- **模板详情弹窗**：点击模板弹出详情，显示大尺寸示意图、参数配置（Panel 宽高比、间距等）
- **模板编辑器**：
  - 画布区：显示页面矩形，可通过分割线工具自由切割
  - 分割工具：水平分割（H）、垂直分割（V）、删除分割线
  - 比例调整：拖拽分割线调整各 Panel 面积比例
  - 实时预览：编辑过程中实时展示效果
- **标签系统**：支持为模板添加标签（如"对话专用"、"动作场景"等）便于检索

## 第56章 自动版式规划

### 56.1 功能描述

自动版式规划根据 Panel 的内容特征和节奏要求，自动为每个页面选择合适的版式模板。这是实现"AI 驱动工业化"的关键环节，极大减少手动排版工作量。

**核心功能：**
- 根据内容自动选择版式：
  - 连续动作 → 三格竖排（适合表现动作连贯性）
  - 高潮场景 → 整页大格（增强视觉冲击）
  - 对话场景 → 双格或三格（便于阅读）
  - 情绪描写 → 单格或两格（留白增强氛围）
  - 过渡场景 → 四格小图（加快节奏）
- 版式调整建议：AI 提供备选版式方案及推荐理由
- 手动覆盖：用户可手动替换 AI 选择的版式
- 全局/局部切换：支持一次性为整话自动排版，或仅对选定页面排版

### 56.2 操作流程

1. **选择范围**：选择要自动排版的范围（整章 / 单页 / 选中页面）
2. **启动自动排版**：点击"AI 自动排版"，系统分析每个页面内的 Panel 内容
3. **AI 分析中**：显示分析进度，标注当前 AI 正在处理的页面
4. **结果预览**：排版完成后以缩略图形式展示所有页面
5. **逐页审核**：查看每个页面的版式选择，AI 在页面上标注推荐理由
6. **接受/替换**：接受 AI 方案或替换为其他模板
7. **确认应用**：确认后生成最终版式方案

### 56.3 界面要求

- **缩略对比视图**：以两列形式展示"AI 推荐版式"与"当前版式"的缩略图对比
- **推荐理由标记**：在每个缩略图上显示 AI 推荐理由标签（如"连续动作→三格竖排"）
- **置信度指示**：显示 AI 对该版式选择的置信度（高/中/低）
- **快速替换**：点击缩略图下方的备选模板列表可直接替换
- **批量接受**：提供"全部接受"、"全部拒绝"、"逐项确认"三种模式
- **切换动画**：版式切换时展示平滑过渡动画，便于感知变化

## 第57章 画格布局编辑

### 57.1 功能描述

画格布局编辑是版式中心的核心交互模块，提供可视化的 Panel 布局编辑能力。用户可以在页面画布上自由调整每个 Panel 的大小、位置和排列方式。

**核心功能：**
- 拖拽调整 Panel 大小：通过拖拽 Panel 边缘或角点调整尺寸
- Panel 位置微调：在页面上精细微调 Panel 位置（像素级）
- Panel 分割/合并：在页面上直接分割一个 Panel 为两个，或合并两个相邻 Panel
- 画格间距调整：统一或单独调整 Panel 之间的间距
- 实时预览：编辑过程中实时显示效果

### 57.2 操作流程

1. **选中页面**：在页面列表中选择要编辑的页面，进入编辑模式
2. **选中 Panel**：点击页面

## 第58章 阅读节奏优化

### 58.1 功能描述

阅读节奏优化是 Webtoon 版式编排的高级功能，通过分析 Panel 内容特征、对话密度、动作强度等因素，自动优化页面的阅读节奏和视觉流。良好的阅读节奏能引导读者的视线自然流动，在关键情节处形成视觉高潮，提升整体阅读体验。

**核心功能：**
- 阅读节奏分析：AI 分析每个 Panel 的内容特征，评估其叙事节奏
- 视觉流优化：调整 Panel 大小和排列，形成自然的视线引导路径
- 节奏标记系统：为页面标注"舒缓/正常/紧凑/高潮"等节奏类型
- Panel 拆分/合并建议：根据节奏需要，AI 提供拆分或合并 Panel 的建议
- 阅读时间预估：估算每页和整话的阅读时间
- 节奏一致性检查：检测相邻页面之间的节奏过渡是否自然

### 58.2 节奏分析

#### 58.2.1 功能描述

系统基于多维度的内容分析，为每个页面和 Panel 生成节奏评分和类型标签。节奏分析是后续优化操作的基础。

**节奏分析维度：**

| 维度 | 说明 | 评估指标 |
|------|------|----------|
| 对话密度 | Panel 中对白/旁白的数量和长度 | 字符数、气泡数、文本占比 |
| 动作强度 | Panel 中动作描写的激烈程度 | 动作关键词、运镜方式、景别 |
| 情绪张力 | Panel 中的情绪强度和氛围 | 情绪关键词、光线、色彩 |
| 信息密度 | Panel 中的视觉信息丰富度 | 角色数、道具数、场景复杂度 |
| 视觉复杂度 | Panel 的视觉元素复杂度 | Panel 内元素数量、色彩丰富度 |

**节奏类型分类：**

| 节奏类型 | 说明 | 典型场景 |
|----------|------|----------|
| 舒缓 | 阅读速度较慢，适合情感描写 | 内心独白、风景描写、抒情段落 |
| 正常 | 标准阅读节奏 | 日常对话、常规叙述 |
| 紧凑 | 阅读速度加快，营造紧张感 | 战斗准备、追逐、争执 |
| 高潮 | 快速阅读，视觉冲击力强 | 战斗高潮、关键转折、震撼画面 |
| 过渡 | 快速略过，连接段落 | 场景切换、时间跳转 |

#### 58.2.2 操作流程

1. **选择分析范围**：选择要分析节奏的章节或页面范围
2. **启动分析**：点击"AI 节奏分析"按钮
3. **分析进行中**：系统逐页分析内容特征，生成节奏评分
4. **查看结果**：分析完成后以可视化方式展示节奏曲线
5. **标注节奏类型**：系统自动标注每个页面的节奏类型标签
6. **手动调整**：用户可手动修改个别页面的节奏标注

#### 58.2.3 界面要求

- **节奏曲线图**：以折线图展示整话的节奏变化，横轴为页码，纵轴为节奏强度
- **节奏色条**：每个页面缩略图左侧或顶部显示节奏类型的彩色标识条
- 舒缓=绿色、正常=蓝色、紧凑=橙色、高潮=红色、过渡=灰色
- **分析详情面板**：点击页面可查看该页面的详细分析维度评分
- **节奏概览**：顶部显示"舒缓:N / 正常:N / 紧凑:N / 高潮:N / 过渡:N"统计

### 58.3 视觉流优化

#### 58.3.1 功能描述

视觉流优化根据阅读节奏分析结果，自动调整 Panel 的布局排列，引导读者的视线按照预期的路径流动。

**优化策略：**

| 节奏目标 | 优化策略 | 效果 |
|----------|----------|------|
| 舒缓节奏 | 增大 Panel 留白、降低 Panel 密度 | 减缓阅读速度，增强氛围感 |
| 正常节奏 | 保持标准 Panel 布局 | 稳定舒适的阅读体验 |
| 紧凑节奏 | 增加 Panel 数量、减小单个 Panel 尺寸 | 加快阅读速度，增强紧张感 |
| 高潮节奏 | 将关键 Panel 放大到整页或跨页 | 增强视觉冲击力 |
| 过渡节奏 | 使用小尺寸 Panel 快速过渡 | 快速推进叙事 |

**视觉流路径：**
- 自然 Z 字形：适合标准阅读，视线从左到右、从上到下
- 垂直引导：适合竖屏滚动阅读，视线沿垂直方向自然下移
- 焦点引导：通过 Panel 大小对比，引导视线先看大 Panel
- 对角线引导：通过 Panel 排列形成对角线视觉路径

#### 58.3.2 操作流程

1. **查看当前视觉流**：在版式编辑器中开启"视觉流预览"模式
2. **启动 AI 优化**：点击"AI 视觉流优化"按钮
3. **选择优化目标**：选择优化目标（舒缓/标准/紧凑）或让 AI 自动推荐
4. **预览优化方案**：系统生成优化后的布局方案，以动画过渡展示变化
5. **接受/拒绝**：逐项接受或拒绝优化建议
6. **手动微调**：在 AI 建议基础上手动拖拽微调

#### 58.3.3 界面要求

- **视线引导线**：在编辑器画布上叠加显示视线引导箭头（半透明）
- **热力图叠加**：可选显示阅读注意力热力图，标注预期的视觉焦点区域
- **对比模式**：左右分栏对比"优化前"和"优化后"的布局
- **过渡动画**：布局变化时展示平滑过渡动画
- **撤销/重做**：支持多步撤销和重做

### 58.4 Panel 拆分与合并建议

#### 58.4.1 功能描述

基于节奏分析结果，AI 自动识别需要拆分或合并的 Panel，并提供具体建议。

**拆分场景：**
- 单个 Panel 内容过多（对话密集 + 动作复杂）
- 情绪/节奏需要在单页内变化
- Panel 内包含多个连续动作

**合并场景：**
- 相邻 Panel 内容过于分散
- 连续快速动作需要整合
- 节奏需要放缓，减少切割感

#### 58.4.2 操作流程

1. **查看建议列表**：在节奏分析完成后，侧边栏显示拆分/合并建议列表
2. **预览建议**：点击建议项，在编辑器中高亮相关 Panel
3. **应用拆分**：接受拆分建议，系统自动生成拆分后的 Panel 内容
4. **应用合并**：接受合并建议，系统自动合并 Panel 内容
5. **批量处理**：支持一键接受所有建议或逐项确认

#### 58.4.3 界面要求

- **建议卡片**：每条建议以卡片形式展示，包含建议类型、原因和影响分析
- **高亮标记**：建议涉及的 Panel 用虚线边框高亮标记
- **拆分预览**：以分屏形式展示拆分前后的效果对比
- **影响提示**：提示拆分/合并对后续生图和气泡的影响范围

### 58.5 阅读时间预估

#### 58.5.1 功能描述

系统根据页面内容复杂度估算阅读时间，帮助创作者控制整话的阅读时长。

**预估指标：**

| 指标 | 说明 |
|------|------|
| 每页阅读时间 | 单页的预估阅读时长（秒） |
| 整话阅读时间 | 整话的总预估阅读时长 |
| 字数阅读时间 | 基于文本量的阅读时间 |
| 画面阅读时间 | 基于画面复杂度的阅读时间 |
| 阅读速度调整 | 根据节奏类型调整阅读速度系数 |

#### 58.5.2 操作流程

1. 完成版式编排后，自动显示阅读时间预估
2. 查看"每页阅读时间"分布图
3. 查看"整话阅读时间"总览
4. 若总时长超出目标范围，系统给出调整建议
5. 根据建议调整版式后，阅读时间自动重新计算
6. 支持手动设置目标阅读时长，系统据此反向优化

#### 58.5.3 界面要求

- **阅读时间仪表盘**：以仪表盘或进度条展示整话阅读时间
- **页面时间柱状图**：以柱状图展示每页的阅读时间分布
- **目标标记线**：在图表上标记目标阅读时长的参考线
- **超时警告**：超出目标范围时显示橙色/红色警告
- **调整建议**：显示具体的调整建议（如"建议合并第5-6页以缩短30秒"）

### 58.6 节奏一致性检查

#### 58.6.1 功能描述

在完成版式编排后，系统对整话的节奏进行全面检查，识别节奏过渡不自然的问题区域。

**检查项：**

| 检查项 | 说明 | 告警条件 |
|--------|------|----------|
| 节奏突变 | 相邻页面节奏类型差异过大 | 高潮↔舒缓直接相邻（无过渡页） |
| 节奏疲劳 | 连续多页保持同一高节奏 | 连续5页以上为紧凑/高潮 |
| 节奏断层 | 节奏曲线出现异常中断 | 应有节奏变化但未变化 |
| 开口过长 | 开篇节奏过于缓慢 | 前3页均为舒缓 |
| 高潮不足 | 整话缺乏节奏高潮点 | 无高潮标记页面 |

#### 58.6.2 操作流程

1. 点击"节奏一致性检查"按钮
2. 系统自动扫描整话的节奏分布
3. 检查结果以列表形式展示问题项
4. 点击问题项，自动定位到对应页面
5. 系统给出修改建议（如"建议在第8页增加一个紧凑页面作为过渡"）
6. 用户根据建议调整后，重新检查

#### 58.6.3 界面要求

- **检查报告**：以列表形式展示所有检查问题
- **严重等级**：每个问题标注严重等级（错误/警告/提示）
- **定位跳转**：点击问题项自动跳转到编辑器对应页面
- **修正建议**：每条问题附带 AI 修正建议
- **一键修复**：对简单问题提供"一键修复"按钮
- **重新检查**：修改后支持快速重新检查
