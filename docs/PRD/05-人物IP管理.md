# 第五篇 人物IP管理

---

## 第29章 人物列表

### 29.1 功能概述

人物列表是人物 IP 管理模块的核心入口，集中展示项目中所有已创建的角色。用户通过列表页可以快速浏览、搜索、筛选和管理角色，是日常使用频次最高的页面之一。列表页同时提供角色创建入口和视图切换功能。

### 29.2 功能点

#### 29.2.1 全部人物展示

**功能描述：**
- 以列表或卡片形式展示项目中所有已创建的角色
- 每个角色展示：头像缩略图（圆形裁切）、角色姓名、角色标签（如"主角/配角/反派"）
- 角色头像使用系统生成的默认头像或用户上传的自定义头像
- 鼠标悬停时显示角色快速预览卡片（带简要信息摘要）

**操作流程：**
1. 进入"人物列表"页面，默认加载所有角色数据
2. 角色按创建时间倒序排列（最新的在前）
3. 每个角色卡片显示核心识别信息
4. 鼠标悬停角色卡片，弹出快速预览浮层
5. 点击角色卡片进入该角色的详情页

**界面要求：**
- 卡片视图：每行 4-5 个角色卡片，卡片尺寸约 180×220px
- 卡片内容：圆形头像（直径约 100px）居中上部、姓名居中、角色标签在姓名下方
- 角色标签使用彩色徽章样式：
  - 主角：红色徽章（🔴 主角）
  - 配角：蓝色徽章（🔵 配角）
  - 反派：黑色徽章（⚫ 反派）
  - 客串：灰色徽章（⚪ 客串）
- 快速预览浮层：显示角色头像(大)、姓名、角色标签、简短性格描述、出场章节数
- 空状态：无角色时显示占位插画 + "点击上方按钮创建第一个角色"提示

#### 29.2.2 人物搜索与筛选

**功能描述：**
- 支持按角色姓名关键词搜索（实时搜索，输入即出）
- 支持多维度筛选：
  - 按角色标签筛选：主角 / 配角 / 反派 / 客串
  - 按出场章节筛选：选择特定章节范围
  - 按状态筛选：草稿 / 已完成 / 待完善
- 多个筛选条件可叠加使用
- 筛选结果实时更新列表

**操作流程：**
1. 在列表页顶部搜索框中输入角色姓名关键词
2. 系统实时展示匹配结果（无需点击搜索按钮）
3. 点击筛选下拉框，选择需要的筛选维度
4. 筛选条件激活时，对应控件显示高亮状态
5. 点击"清除筛选"按钮重置所有筛选条件

**界面要求：**
- 搜索框：位于页面顶部居中或偏左位置，宽度约 400px
- 搜索框内带放大镜图标，右侧有清除按钮（×）
- 筛选条件行：位于搜索框下方，使用横向排列的筛选下拉框
- 每个筛选下拉框显示当前选中项，未选中时显示"全部"
- 激活的筛选条件显示蓝色高亮边框
- 筛选结果数量显示在列表上方："共 X 个角色"

#### 29.2.3 人物创建入口

**功能描述：**
- 提供显眼的人物创建入口
- 支持多种创建方式：
  - 从空白创建：手动填写所有角色信息
  - 从小说分析导入：选择已分析的 IP 角色（来自第 20 章人物分析结果）
  - AI 辅助创建：输入角色核心设定，AI 自动补全
- 创建后自动跳转到该角色的人物设定编辑页

**操作流程：**

**空白创建：**
1. 点击人物列表页右上角的"新建角色"按钮
2. 弹出创建角色对话框（或跳转到新页面）
3. 填写角色姓名、角色标签、性别、年龄等基本信息
4. 点击"保存"创建角色
5. 创建成功后跳转到该角色的详情页

**从小说分析导入：**
1. 点击"从小说导入"按钮
2. 弹窗显示小说分析中评级为 S/A 级的人物列表
3. 勾选要导入的角色（支持多选）
4. 点击"导入选中角色"
5. 系统自动将选中人物的信息填充到对应角色

**AI 辅助创建：**
1. 点击"AI 辅助创建"按钮
2. 输入角色核心设定提示词（如"一个 17 岁的魔法学院学生，性格傲娇"）
3. 点击"AI 生成"
4. 系统展示 AI 生成的完整角色设定草稿
5. 用户确认或修改后保存

**界面要求：**
- 新建角色按钮：页面右上角，紫色/主色调大按钮（+ 新建角色）
- 创建方式选择：弹出下拉菜单，"空白创建"、"从小说导入"、"AI 辅助创建"
- 空白创建表单：模态对话框，包含姓名、角色标签、性别、年龄等基础字段
- 小说导入弹窗：左右分栏，左侧为可选人物列表（带复选框），右侧为选中人物预览
- AI 辅助创建：输入框 + 生成按钮，生成结果以表单形式展示（可编辑）
- 成功创建后显示 toast 提示"角色创建成功"

#### 29.2.4 列表视图与卡片视图切换

**功能描述：**
- 提供两种列表展示模式：卡片视图（默认）和列表视图
- 卡片视图：网格布局，突出头像和视觉表现
- 列表视图：表格布局，展示更多信息维度（角色名、标签、出场数、创建时间、状态）
- 用户可自由切换两种视图模式
- 切换时保持当前筛选条件和滚动位置

**操作流程：**
1. 页面右上角提供视图切换按钮组
2. 点击"卡片视图"图标切换到卡片模式
3. 点击"列表视图"图标切换到列表模式
4. 切换后页面布局即时变化
5. 当前激活的视图模式按钮高亮显示

**界面要求：**
- 视图切换按钮组：两个图标按钮并列（卡片图标 <img> / 列表图标 📋）
- 卡片视图：网格布局（响应式，4-5 列），参看 29.2.1
- 列表视图：表格布局，列包含：
  - 头像（小圆形，40×40px）
  - 姓名（可点击进入详情）
  - 角色标签（彩色徽章）
  - 出场章节数（数字）
  - 创建时间（格式化日期）
  - 状态（草稿/已完成/待完善）
  - 操作按钮（编辑、删除）
- 列表视图支持点击列头排序

#### 29.2.5 人物删除需二次确认

**功能描述：**
- 删除角色是一项不可逆操作，必须经过二次确认
- 删除前系统检测该角色是否被项目其他模块引用
- 若存在引用，提示用户哪些模块引用该角色
- 确认删除后，角色及相关数据（服装、表情、姿势等）一并标记为删除或归档

**操作流程：**
1. 在列表视图中点击目标角色的"删除"按钮
2. 弹出删除确认对话框
3. 对话框显示角色名称和头像，确认是否为要删除的角色
4. 系统自动检测引用情况：
   - 若无引用：直接确认即可删除
   - 若有引用：列出引用该角色的模块列表（如"被第 3 章第 5 个 Panel 引用"等）
5. 用户需勾选"我确认删除该角色及其所有关联数据"
6. 点击"确认删除"执行删除操作
7. 删除成功后显示"已删除"提示，并刷新列表

**界面要求：**
- 删除确认对话框：居中模态，宽度约 450px
- 对话框顶部：警告图标（⚠️ 红色）+ "确认删除角色"标题
- 对话框中段：角色头像 + 姓名，确认对象无误
- 引用检测结果区域：若有引用，显示黄色背景警告列表
- 确认复选框："我确认删除该角色及其所有关联数据"，红色文字
- 按钮：灰色"取消" + 红色"确认删除"
- 对话框关闭后，列表刷新（无感刷新或短暂 loading）

### 29.3 数据模型

| 字段 | 类型 | 说明 |
|------|------|------|
| character_id | UUID | 角色唯一标识 |
| project_id | UUID | 所属项目 ID |
| name | String | 角色姓名 |
| avatar_url | String | 头像图片 URL |
| role_tag | Enum | protagonist / supporting / villain / cameo |
| status | Enum | draft / completed / pending |
| source_novel_id | UUID | 来源小说 ID（从小说导入时关联） |
| created_at | DateTime | 创建时间 |
| updated_at | DateTime | 更新时间 |

## 第30章 人物详情

### 30.1 功能概述

人物详情页是角色的完整信息展示中心，聚合了角色的基本设定、关联画格、关联服装和出场统计等全部信息。用户在一个页面中可以全面了解该角色在项目中的使用情况，并通过编辑入口快速修改角色设定。

### 30.2 功能点

#### 30.2.1 人物基本信息展示面板

**功能描述：**
- 集中展示角色的全部基本信息
- 信息分区展示：头像区、基础属性区、性格描述区、外貌特征区
- 所有信息为只读展示模式，点击编辑按钮切换为编辑模式
- 信息字段与第 31 章人物设定编辑的字段同步

**操作流程：**
1. 从人物列表点击角色卡片进入详情页
2. 详情页默认加载并展示该角色的全部信息
3. 基本信息以结构化面板展示
4. 查看者点击"编辑"按钮切换到编辑模式
5. 编辑保存后详情页信息同步更新

**界面要求：**
- 页面布局：左右两栏或上中下三栏
- 左栏/顶部：头像展示区域（大尺寸，约 200×200px）+ 角色姓名 + 角色标签
- 右栏/中部：基本信息表格或卡片式排列
- 信息分组清晰，使用分隔线或卡片区分不同类别
- 每个字段显示字段名和字段值
- 空字段显示"-"或"未设置"灰色提示

#### 30.2.2 关联画格列表

**功能描述：**
- 展示所有出现该角色的画格（Panel）列表
- 画格列表按章节顺序排列
- 每个画格显示：所属章节、所属 Scene、画格缩略图（如有）
- 点击画格项可跳转到分镜中心或漫画编辑器中对应的画格位置
- 支持画格搜索（按章节号或关键词）

**操作流程：**
1. 在人物详情页中切换到"关联画格"标签页
2. 默认按章节顺序展示画格列表
3. 每个画格项以卡片形式展示
4. 点击画格卡片跳转到目标位置
5. 可通过顶部的章节筛选器过滤画格

**界面要求：**
- 关联画格以标签页（Tab）形式嵌入详情页
- 画格卡片：缩略图（120×80px）+ 章节名 + Scene 编号 + 画格编号
- 跳转按钮：卡片右下角的"跳转"链接图标
- 空状态：无关联画格时显示"该角色还未出现在任何画格中"
- 筛选器：章节名下拉框

#### 30.2.3 关联服装列表

**功能描述：**
- 展示该角色所有已创建的服装
- 每个服装显示：服装名称、类型标签、颜色方案预览色块
- 支持点击服装进入第 34 章人物服装库详情
- 显示当前场景下正在使用的服装标记
- 支持快速切换角色当前使用的服装

**操作流程：**
1. 在人物详情页切换到"服装"标签页
2. 展示该角色关联的所有服装列表
3. 当前场景使用的服装以"当前"标记高亮
4. 点击服装卡片跳转到服装库详情
5. 在服装卡片上点击"设为当前"按钮切换默认服装

**界面要求：**
- 服装列表：横向滚动或卡片网格
- 服装卡片：小型缩略图 + 服装名称 + 类型标签
- "当前"标记：绿色"✓ 使用中"徽章
- 颜色方案：卡片底部显示 2-3 个颜色小色块
- 空状态："尚未创建服装，前往服装库创建"

#### 30.2.4 人物出场统计

**功能描述：**
- 统计该角色在项目中的总出场次数
- 按章节统计出场频次分布（柱状图或折线图）
- 以可视化方式展示角色在剧情中的出场密度
- 统计数据随剧情拆解更新而自动更新

**操作流程：**
1. 在人物详情页切换到"出场统计"标签页
2. 顶部显示总出场数（大号数字）
3. 下方按章节顺序展示出场频次分布图
4. 鼠标悬停图表可查看具体数值
5. 图表支持导出为图片

**界面要求：**
- 总出场数：大号字体（48px+），带"次"单位
- 分布图：横向柱状图，X 轴为章节号，Y 轴为出场次数
- 柱状条使用渐变蓝色，悬停时显示"第 X 章：Y 次"
- 首次出场章节特殊标记（金色星标）
- 图表区域宽高比约 16:9

#### 30.2.5 编辑入口

**功能描述：**
- 详情页提供进入完整编辑模式的入口
- 点击编辑按钮跳转到第 31 章人物设定编辑页
- 详情页内也提供快速编辑部分字段的能力
- 编辑入口位于页面右上角显眼位置

**操作流程：**
1. 点击详情页右上角的"编辑"按钮
2. 跳转到人物设定编辑页面（第 31 章）
3. 编辑完成后自动返回详情页并刷新
4. 或者点击详情页中某字段旁的铅笔图标，进行内联编辑

**界面要求：**
- "编辑"按钮：页面右上角，蓝色主色调，带编辑图标（✎）
- 内联编辑：字段值旁显示铅笔图标，点击后变为可编辑输入框
- 内联编辑保存后字段值即时更新
- 跳转编辑：过渡动画平滑

## 第31章 人物设定编辑

### 31.1 功能概述

人物设定编辑模块是角色精细化设定的核心工具，提供完整的表单用于填写和维护角色的全部属性。这里的设定数据将直接用于 AI 生图的角色描述 Prompt 生成，是确保角色生成一致性的基础数据源。

### 31.2 功能点

#### 31.2.1 基础属性字段

**功能描述：**
- 提供角色基础属性的完整表单
- 所有字段支持中文输入
- 字段说明清晰标注，方便用户理解

**基础属性字段列表：**

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| 名字 | 文本 | 是 | 角色姓名（支持别名/昵称，可用逗号分隔） |
| 年龄 | 文本 | 是 | 可以是具体数字或模糊描述如"17岁""20多岁" |
| 身高 | 文本 | 是 | 身高数值，如"165cm""175cm" |
| 体重 | 文本 | 否 | 体重数值，如"55kg" |
| 发色 | 颜色选择器+文本 | 是 | 选择色值并填写颜色名称，如"金色 (#FFD700)" |
| 发型 | 文本 | 是 | 发型描述，如"及腰直发""短发碎发" |
| 瞳孔颜色 | 颜色选择器+文本 | 是 | 选择色值并填写颜色名称，如"红色 (#FF0000)" |
| 肤色 | 颜色选择器+文本 | 是 | 选择色值并填写颜色名称，如"白皙 (#FFF5E6)" |
| 性格 | 多选标签 | 是 | 预设性格标签库，可自定义添加 |
| 职业 | 文本 | 否 | 角色的身份/职业 |

**操作流程：**
1. 进入人物设定编辑页，表单默认展示当前值
2. 按字段顺序填写或修改各属性值
3. 对于颜色类字段（发色、瞳色、肤色），使用颜色选择器选取
4. 性格字段从预设标签中选择（支持多选）
5. 填写过程中表单实时自动保存（或手动点击保存）
6. 必填字段未填写时显示红色提示

**界面要求：**
- 表单使用两列布局（左列 + 右列），充分利用空间
- 每行一个字段：左侧为字段名（带必填标记*），右侧为输入控件
- 颜色字段：颜色选择器（方形色块） + 颜色名称输入框 + HEX 色值显示
- 颜色选择器：点击色块弹出取色面板，支持预设颜色和自定义取色
- 性格字段：标签选择器，预设标签如"开朗、内向、温柔、暴躁、傲娇、腹黑、冷酷、热血、胆小、勇敢、狡猾、善良"等
- 预设标签可搜索，支持输入自定义标签（输入后回车添加）

#### 31.2.2 穿搭描述

**功能描述：**
- 自由文本字段，描述角色的日常穿着风格
- 可引用已创建的服装库中的服装（第 34 章）
- 支持引用关联服装并标注"日常""战斗"等场景用途
- 描述文本将作为 AI 生图 Prompt 中服装部分的参考

**操作流程：**
1. 在穿搭描述区域输入自由文本
2. 可点击"引用服装"按钮，从服装库中选择已创建的服装
3. 引用的服装以标签形式嵌入描述文本
4. 可添加多个场景的穿搭描述
5. 描述完成后保存

**界面要求：**
- 自由文本输入框：多行富文本框，高度约 120px
- 引用服装按钮：输入框下方的"＋ 引用服装"按钮
- 引用服装弹窗：服装库列表，选中后以标签形式插入
- 场景穿搭分栏：支持添加多个场景标签页（日常/战斗/校园/正式等）
- 每个场景标签页独立描述文本

#### 31.2.4 关键特征描述

## 第32章 人物关系图（Relationship Sheet）

### 32.1 功能概述

人物关系图模块以可视化图谱方式呈现角色之间的复杂关系网络。采用力导向图布局，角色为节点、关系为连线，直观展示角色联系、情感纽带和剧情羁绊。关系图支持编辑、标注和导出，帮助创作者清晰梳理角色关系网。

### 32.2 功能点

#### 32.2.1 可视化关系图谱

**功能描述：**
- 采用力导向图（Force-Directed Graph）布局算法
- 角色作为节点（Node），关系作为连线（Edge）
- 节点大小根据角色重要性（S/A/B 评级）动态缩放
- 连线颜色和样式根据关系类型区分
- 图谱支持缩放、平移、旋转操作
- 布局自动优化，避免节点重叠

**操作流程：**
1. 进入人物关系图页面，默认加载所有角色及其已定义的关系
2. 图谱自动渲染，节点按力导向算法排布
3. 用户可通过鼠标滚轮缩放视图
4. 拖拽空白区域平移画布
5. 悬停节点显示角色名称和角色标签
6. 悬停连线显示关系类型和关系描述

**界面要求：**
- 图谱容器占满页面主体区域（画布面积建议 ≥ 900×600px）
- 节点样式：圆形头像（角色头像）+ 角色姓名标签
- 节点尺寸：S 级直径 80px、A 级 65px、B 级 50px、C 级 40px、D 级 35px
- 连线样式：有向连线（箭头指向），线宽根据关系强度变化（1-4px）
- 连线颜色映射：
  - 喜欢/暗恋：粉色 (#FF6B9D)
  - 讨厌/仇敌：红色 (#FF4444)
  - 家人：绿色 (#44BB44)
  - 朋友：蓝色 (#4488FF)
  - 师徒：橙色 (#FF8844)
  - 主仆：紫色 (#9944FF)
- 图例：画布右下角展示关系类型与颜色的映射图例
- 缩放控件：画布左下角的 +/- 按钮

#### 32.2.2 关系类型定义

**功能描述：**
- 预定义多种关系类型供用户选择
- 每种关系类型有对应的视觉样式（颜色、线型）
- 支持用户自定义关系类型
- 关系类型可在关系编辑时选择

**预定义关系类型：**

| 关系类型 | 标签 | 连线颜色 | 说明 |
|---------|------|----------|------|
| 喜欢 | 💕 喜欢 | 粉色 | 单方面喜欢 |
| 暗恋 | 💗 暗恋 | 粉色(虚线) | 暗恋，未被对方知晓 |
| 讨厌 | 💢 讨厌 | 红色 | 厌恶或反感 |
| 仇敌 | ⚔️ 仇敌 | 深红 | 敌对或仇恨关系 |
| 家人 | 👨‍👩‍👧‍👦 家人 | 绿色 | 家庭成员关系 |
| 朋友 | 🤝 朋友 | 蓝色 | 友好关系 |
| 师徒 | 📚 师徒 | 橙色 | 师徒或师生关系 |
| 主仆 | 👑 主仆 | 紫色 | 主从或雇佣关系 |
| 情侣 | 💑 情侣 | 玫红 | 恋爱关系（双向） |
| 对手 | 🏆 对手 | 金色 | 竞争或对手关系 |
| 同僚 | 👥 同僚 | 青色 | 同事或同学关系 |
| 陌生人 | ➖ 陌生人 | 灰色 | 尚未建立关系 |

**操作流程：**
1. 在关系编辑面板中选择关系类型
2. 默认展示预定义关系类型列表
3. 如需要自定义关系类型，点击"添加自定义关系"
4. 输入自定义关系名称、选择颜色、图标
5. 自定义类型保存后可在关系编辑时选择

**界面要求：**
- 关系类型选择器：下拉列表或图标网格
- 每个关系类型显示：颜色标识 + 图标 + 名称
- 自定义关系类型弹窗：名称输入 + 颜色选择器 + 图标选择器
- 类型列表支持搜索（类型较多时）

#### 32.2.3 关系双向描述

**功能描述：**
- 关系是双向的，A 对 B 的态度和 B 对 A 的态度可能不同
- 分别记录"A→B"和"B→A"的关系描述
- 支持对每个方向的关系填写态度描述文本
- 支持为每个方向的关系选择强度等级（1-5 星）

**操作流程：**
1. 选中有关系的两个节点（角色 A 和角色 B）
2. 在关系编辑面板中分别填写：
   - "A 对 B 的态度"（选择关系类型 + 强度 + 描述文本）
   - "B 对 A 的态度"（选择关系类型 + 强度 + 描述文本）
3. 若两个方向的关系类型相同，可勾选"双向一致"
4. 保存后连线显示双向关系信息
5. 鼠标悬停连线的 A 端显示 A→B 的关系，B 端显示 B→A 的关系

**界面要求：**
- 关系编辑面板：图谱右侧或底部滑出的侧边栏
- 双向关系分两个区域上下排列：
  - 上半区："A → B"，含关系类型下拉框 + 强度星级 + 描述输入框
  - 下半区："B → A"，同样布局
- "双向一致"复选框在上半区和下半区之间
- 强度星级：5 星评分，用实心/空心星显示
- 描述输入框：单行文本，最多 100 字符
- 保存后的连线两端显示关系标签（小字，分别靠近两端节点）

#### 32.2.4 关系编辑：拖拽连线/删除线

**功能描述：**
- 支持通过拖拽操作创建新关系连线
- 从一个节点拖出一条连线到另一个节点，自动创建关系
- 支持删除已有关系连线
- 连线的创建和删除实时反映在图谱上
- 拖拽交互流畅，有视觉反馈

**操作流程：**

**创建关系：**
1. 鼠标悬停关系源节点，节点边缘出现拖拽手柄（小圆点）
2. 点击并拖拽手柄，出现一条跟随鼠标的虚线
3. 拖拽到目标节点上时，目标节点高亮
4. 释放鼠标，弹出关系创建对话框
5. 填写关系类型和描述后保存

**删除关系：**
1. 鼠标悬停在关系连线上，连线高亮变粗
2. 连线中间出现删除按钮（×）
3. 点击删除按钮，弹出确认对话框
4. 确认后删除关系连线
5. 连线从图谱上消失

**界面要求：**
- 拖拽创建：源节点上的拖拽手柄在悬停时渐显
- 拖拽中：虚线样式（---），线上显示"+ 建立关系"提示
- 目标节点高亮：蓝色光环围绕节点
- 删除按钮：连线中间的 × 圆形按钮，红色背景
- 删除确认：小弹窗"确认删除 [A] 和 [B] 之间的关系？"
- 所有操作支持 Ctrl+Z 撤销

#### 32.2.5 导出关系图为 PNG

**功能描述：**
- 将当前关系图谱导出为 PNG 图片
- 导出内容包含完整图谱（节点、连线、图例）
- 支持选择导出区域（当前视图 / 全图）
- 导出的图片分辨率可配置（1x / 2x）

**操作流程：**
1. 点击图谱右上角的"导出"按钮
2. 选择导出选项：
   - 区域：当前视图 / 全图
   - 分辨率：标准 (1x) / 高清 (2x) / 4K
3. 点击"导出"
4. 系统生成 PNG 图片并触发下载
5. 导出完成后显示"导出成功"提示

**界面要求：**
- 导出按钮：图谱右上角，下载图标
- 导出选项弹窗：区域选择 + 分辨率选择
- 导出进度：大图导出时显示进度条
- 导出图片质量：背景透明（自动）/ 纯白背景选项
- 默认文件命名："{项目名}_角色关系图.png"

## 第33章 人物尺寸图（Scale Sheet）

### 33.1 功能概述

人物尺寸图模块以可视化方式呈现角色之间的身高对比。通过按真实身高比例生成对比条，用户可以直观地看到角色间的身高差异，为分镜构图中角色相对位置和视角高度提供参考依据。

### 33.2 功能点

#### 33.2.1 角色身高对比可视化

**功能描述：**
- 按照角色设定的真实身高数值，按比例生成垂直对比条
- 对比条从地面线（0cm）向上延伸至角色身高高度
- 身高比例精确，确保多角色同时对比时显示真实身高差
- 支持毫米级精确度，身高四舍五入到整数厘米展示

**操作流程：**
1. 进入人物尺寸图页面，默认展示已选角色的身高对比
2. 页面自动渲染身高对比条
3. 对比条底部对齐（地面线对齐）
4. 悬停对比条顶部显示精确身高数值
5. 点击对比条选中该角色

**界面要求：**
- 对比条排列：水平等间距排列，从左到右
- 每个对比条宽度固定（约 80px），高度按比例
- 对比条样式：渐变色填充（上部稍亮、下部稍暗）
- 地面线：底部灰色水平线，标注"地面 0cm"
- 身高标尺：左侧或右侧显示垂直标尺，以 20cm 为刻度
- 标尺范围：自动适配最高角色的身高（最高角色上方留 20px 空白）
- 悬停提示：tooltip 显示"角色名：175cm"

#### 33.2.2 支持多角色同时对比

**功能描述：**
- 支持同时选择多个角色进行身高对比
- 最多可同时对比全部角色（不限数量）
- 角色选择面板支持多选、全选、反选
- 选中的角色即时在对比图中显示

**操作流程：**
1. 左侧或底部的角色选择面板显示所有角色
2. 勾选需要对比的角色（复选框）
3. 对比图即时更新，仅显示选中的角色
4. 点击"全选"选择所有角色
5. 点击"清除"取消所有选择
6. 选中的角色在面板中显示为高亮状态

**界面要求：**
- 角色选择面板：左侧侧边栏或底部抽屉式面板
- 每个角色项：小头像（40×40px）+ 姓名 + 身高 + 复选框
- 选中状态：复选框打勾，角色项背景浅蓝色高亮
- 面板顶部操作按钮："全选"、"反选"、"清除"
- 选中角色数量显示在面板顶部："已选 X/Y 个角色"
- 选择面板可折叠/展开

#### 33.2.3 角色头像 + 姓名 + 身高标注

**功能描述：**
- 每个对比条顶部显示角色头像和姓名
- 对比条底部（地面线处）显示角色姓名
- 对比条顶部精确显示身高数值
- 标注信息清晰美观，不重叠

**操作流程：**
1. 选中角色后，对比条自动渲染
2. 对比条顶部显示圆形头像（直径 50px）
3. 头像下方显示角色姓名（居中）
4. 对比条最顶端标注身高数值
5. 若头像和标签重叠（角色过多时），自动错开排列

**界面要求：**
- 头像显示：圆形裁切，50×50px，白色细边框
- 姓名显示：对比条顶部下方，字体 14px，加粗，居中
- 身高标注：对比条最顶部，字体 16px，加粗，与对比条同色
- 多角色时，标注高度自动分层避免重叠
- 角色标签颜色：主角/配角/反派分别使用红/蓝/黑配色

#### 33.2.4 导出为 PNG 图片

**功能描述：**
- 将身高对比图导出为 PNG 图片
- 导出内容包含：对比条、角色头像、姓名、身高标注、身高标尺
- 支持导出当前选择的所有角色
- 导出图片包含项目名称水印（可选）

2. 点击页面右上角的"导出"按钮
3. 选择导出设置：
   - 包含角色头像（是/否）
   - 包含身高标尺（是/否）
   - 背景透明（是/否）
4. 点击"导出"触发下载
5. 默认文件名："{项目名}_角色身高对比.png"

**界面要求：**
- 导出按钮：页面右上角，与关系图导出风格一致

- 单图生成按钮：每个表情卡片上的小号"刷新/生成"图标

## 第37章 人物动作库

- 动作描述可结合该角色的特征（如"因为个子矮，需要踮脚"）

**界面要求：**

- 动作名称限制：20 字以内

#### 37.2.2 动作分类

**预设动作分类：**

| 分类 | 说明 | 示例动作 |

**界面要求：**

## 第39章 人物一致性管理

### 39.1 功能概述

人物一致性管理模块是确保 AI 生成的角色在所有画格中保持视觉一致的关键质量控制工具。系统通过角色特征 Checklist、AI 自动对比检测、不一致报警和一致性报告等功能，帮助用户发现和修正角色外观的偏差。

### 39.2 功能点

#### 39.2.1 角色特征 Checklist

**功能描述：**
- 为每个角色建立完整的视觉特征清单
- 清单列出所有关键特征维度，每个维度记录"当前设定值"
- 特征维度与人物设定（第 31 章）同步
- 清单供 AI 对比检测时作为标准参照

**特征维度列表：**

| 维度 | 设定值（示例） | 数据来源 |
|------|---------------|---------|
| 发色 | 金色 (#FFD700) | 人物设定 |
| 发型 | 及腰直发，刘海遮右眉 | 人物设定 |
| 瞳色 | 红色 (#FF0000) | 人物设定 |
| 肤色 | 白皙 (#FFF5E6) | 人物设定 |
| 当前服装 | 天玄学院校服 | 服装库 |
| 身高 | 165cm | 人物设定 |
| 体型 | 纤细 | 人物设定 |
| 脸部特征 | 左眼角有泪痣 | 关键特征 |
| 饰品 | 红色发带 | 关键特征 |
| 标志性特征 | 虎牙明显 | 关键特征 |

**操作流程：**
1. 进入人物一致性管理页面，选择目标角色
2. 默认展示该角色的特征 Checklist
3. 清单以列表形式展示所有特征维度
4. 每个维度的"设定值"从人物设定中自动同步
5. 若设定值尚未填写，显示"未设置"提示（黄色警告）

- 状态指示灯：每行左侧有状态点（绿色=已设置/黄色=未设置/红色=不匹配）
- 页面顶部显示概览："已设置 X/Y 项，缺失 Z 项"
- 顶部提供"补全缺失特征"快捷按钮

#### 39.2.2 AI 自动对比：新生成图片中的角色特征检测

- 检测维度与 Checklist 中的特征维度一致
- AI 将检测到的特征值与设定值进行比对
- 比对结果标记为：一致 / 不一致 / 无法确定
- 无法确定的维度标记为"需人工审核"

**操作流程：**
1. AI 生图完成后，自动触发一致性检测
2. 系统将图片发送到特征检测模型进行分析
3. 检测模型提取图片中的角色特征值
4. 与 Checklist 中的设定值逐一比对
5. 比对结果汇总生成"一致性检测报告"
6. 结果实时推送到前端展示
7. 用户可手动触发重新检测

**界面要求：**
- 检测结果弹窗/面板：生图完成后自动弹出
- 结果列表：每行一个检测维度
- 结果状态图标：一致（✓ 绿色）/ 不一致（✗ 红色）/ 无法确定（❓ 灰色）
- 不一致项高亮显示，并显示"检测值" vs "设定值"对比
- 支持点击查看检测的图片区域标注（如标注头发区域检测到的颜色）
- 手动检测按钮：位于结果面板顶部

#### 39.2.3 不一致报警弹出/列表

**功能描述：**
- 当 AI 检测到角色特征与设定值不一致时，触发报警
- 报警分为三个等级：警告（1 项不一致）、严重（2-3 项不一致）、危险（3 项以上不一致）
- 报警以弹出通知和列表两种形式展示
- 报警列表中记录所有历史不一致事件
- 用户可将报警标记为"已忽略"或"已修复"

**报警等级：**

| 等级 | 名称 | 颜色 | 触发条件 |
|------|------|------|---------|
| 🔴 | 危险 | 红色 | 3 项以上特征不一致 |
| 🟠 | 严重 | 橙色 | 2-3 项特征不一致 |
| 🟡 | 警告 | 黄色 | 1 项特征不一致 |

**操作流程：**
1. 检测到不一致时，系统立即弹出报警通知
2. 通知显示：报警等级 + 不一致特征数量 + 角色名
3. 点击通知打开不一致详情列表
4. 详情列表展示全部不一致项
5. 用户可对每条不一致项执行操作：
   - "查看原图"：跳转到对应图片
   - "标记已忽略"：忽略该不一致
   - "更新设定"：以检测值更新角色的特征设定
   - "重新生成"：返回生图流程调整 Prompt 重新生成

**界面要求：**
- 弹出通知：页面右下角的 toast 通知，显示报警等级图标 + 简要信息
- 通知停留 5 秒后可手动关闭（记录仍在列表中保留）
- 报警列表：独立页面或侧边栏，按时间倒序排列
- 每个报警项展示：报警时间 + 角色名 + 报警等级 + 不一致项数 + 生成图片缩略图
- 报警项可展开查看具体不一致维度
- 每条不一致维度行显示：维度名 + 设定值（绿色）→ 检测值（红色）+ 操作按钮

#### 39.2.4 一致性报告导出

**功能描述：**
- 将角色的一致性检测结果导出为结构化报告
- 报告可针对单个角色或全部角色
- 报告格式支持：PDF、Markdown、JSON
- 报告包含：检测时间、角色总览、各维度比对结果、不一致详情

**报告内容结构：**
```
# 人物一致性检测报告
- 项目名称：XXX
- 检测角色：[角色名1]、[角色名2]...
- 检测时间：2026-06-27 14:30:00
- 总检测项：X 项
- 一致项：X 项（X%）
- 不一致项：X 项（X%）
- 无法确定：X 项（X%）

## [角色名] 检测详情
- 发色：设定值[金色] → 检测值[金色] ✓ 一致
- 发型：设定值[及腰直发] → 检测值[及腰直发] ✓ 一致
- 瞳色：设定值[红色] → 检测值[橙色] ✗ 不一致
  - 关联图片：[图片链接]
  - 建议操作：更新设定 或 重新生成
...
```

**操作流程：**
1. 在一致性管理页面点击"导出报告"按钮
2. 选择报告范围和格式：
   - 范围：当前角色 / 全部角色
   - 格式：PDF / Markdown / JSON
3. 选择时间范围（可选）：最近 7 天 / 最近 30 天 / 全部
4. 点击"导出"生成报告
5. 报告生成后自动下载
6. 已导出的报告可在"一致性历史"中查看

**界面要求：**
- 导出按钮：页面右上角的"导出报告"按钮
- 导出设置弹窗：范围选择器 + 格式选择器 + 时间范围选择器
- PDF 预览：生成后弹窗显示 PDF 预览
- 导出进度：大报告显示进度条
- 默认文件名："{项目名}_人物一致性报告_{日期}.{格式}"
- 历史报告列表：底部或独立页面展示已导出的报告
- 历史报告支持重新下载和删除
