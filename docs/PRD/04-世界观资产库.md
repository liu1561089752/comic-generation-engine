# 第四篇 世界观资产库

---

## 第23章 世界观管理

### 23.1 功能概述

世界观管理模块用于创建和管理 Webtoon 作品的整体世界观设定。世界观是所有场景、道具、建筑、服装等资产的上层容器，决定了作品的时间背景、空间背景和文化基调。每个项目可以拥有多个世界观，以支持跨时空叙事（如穿越、回忆杀、平行宇宙等场景）。

### 23.2 创建世界观

#### 23.2.1 功能描述

用户可以从头创建新的世界观，设定其年代类型、地域风格、文化背景等核心属性。系统同时支持从小说原文中自动分析提取世界观建议。

**世界观属性字段：**

| 属性 | 类型 | 说明 | 示例 |
|------|------|------|------|
| 世界观名称 | 文本（必填） | 世界观唯一标识名称 | "主世界·天玄大陆" |
| 年代类型 | 单选 | 作品所处的时间背景 | 古代、现代、未来、近未来、架空、穿越等 |
| 时间跨度 | 文本 | 故事发生的年份/纪元范围 | "天历 300-350 年" |
| 背景描述 | 多行文本（必填） | 世界观的核心背景设定描述 | 详细描述世界的物理规则、社会结构、文明水平 |
| 核心设定 | 标签组 | 世界观的标签化特征 | 修仙、魔法、科技、末日、学院等 |
| 地域风格 | 单选 | 主要文化地域风格 | 东方、西方、中东、科幻、混合等 |
| 文明水平 | 单选 | 科技/魔法发展程度 | 原始、封建、工业、信息、星际、魔法文明等 |
| 封面图 | 图片（可选） | 世界观的视觉代表图 | — |

#### 23.2.2 操作流程

1. 用户进入"世界观管理"页面，点击"创建世界观"按钮
2. 弹出创建表单，填写世界观名称、年代类型、背景描述等必填属性
3. 可选填写时间跨度、核心设定标签、地域风格等选填属性
4. 可选上传世界观封面图（拖拽或文件选择器）
5. 点击"保存"提交表单
6. 系统校验必填字段，校验通过后创建世界观记录
7. 创建成功后自动跳转到该世界观的编辑页面

**AI 辅助创建流程：**

1. 用户点击"AI 辅助创建"按钮
2. 选择来源项目中的小说（已导入的小说）
3. 系统调用 LLM 分析小说全文，提取世界观要素
4. 生成世界观建议表单（可编辑）
5. 用户确认/修改后保存

#### 23.2.3 界面要求

- 创建表单使用全屏模态对话框或新页面
- 表单分为基本信息区（名称、年代、类型）和详细设定区（背景描述、核心设定）
- 背景描述使用富文本编辑器，支持多段落
- 核心设定标签支持输入自定义标签 + 选择预设标签
- 封面图上传区域：200×280px 竖向区域，带"上传封面"提示
- 年代类型使用横向单选按钮组，带图标标识
- 表单底部分布"取消"和"保存"按钮

### 23.3 世界观编辑

#### 23.3.1 功能描述

用户可以对已有世界观的全部属性进行编辑修改。编辑时需保持数据完整性，若某世界观已被项目中的章节引用，修改后需记录修改历史。

**编辑支持的特性：**
- 所有创建时的属性均可修改
- 修改历史记录（记录每次修改的时间、修改人、修改内容摘要）
- 修改后自动更新引用该世界观的所有关联数据

#### 23.3.2 操作流程

1. 用户从世界观列表中找到目标世界观，点击进入详情页
2. 在详情页点击"编辑"按钮进入编辑模式
3. 修改需要变更的属性字段
4. 点击"保存更改"提交
5. 系统检测是否有其他模块引用该世界观
6. 若有引用，弹出确认对话框，提示用户"以下模块引用了此世界观，修改可能影响相关内容"
7. 用户确认后保存
8. 保存成功后显示"修改已生效"

#### 23.3.3 界面要求

- 编辑模式与详情模式可在同一页面切换（通过"编辑"按钮切换）
- 编辑状态下表单控件的样式与创建表单一致
- 页面顶部显示修改历史入口（时间线图标）
- 修改历史以侧边栏形式展示，按时间倒序排列
- 每一条修改历史显示：修改时间、修改字段名、旧值→新值（简短显示）

### 23.4 多世界观切换

#### 23.4.1 功能描述

一个项目可能包含多个世界观（如现实世界与异世界切换）。用户可以在项目内创建多个世界观，并在场景/章节层面指定使用的世界观。

**多世界观关系：**
- 一个项目可以包含 N 个世界观
- 一个世界观可以被多个场景/章节引用
- 每个场景只能关联一个世界观
- 世界观之间可设置"主世界观"标记

#### 23.4.2 操作流程

1. 用户在世界观列表页查看所有已创建的世界观
2. 通过设置"主世界观"标记指定默认世界观
3. 在场景管理页面，从下拉框中选择该场景所属的世界观
4. 场景列表按世界观分类展示
5. 用户可通过世界观筛选器快速过滤场景

#### 23.4.3 界面要求

- 世界观列表页顶部显示"主世界观"徽标
- 世界观卡片显示缩略图、名称、场景引用数、章节引用数
- 场景管理中的世界观筛选器为下拉选择框，支持搜索
- 多世界观场景下，场景卡片显示所属世界观标签（彩色标签）

### 23.5 世界观引用统计

#### 23.5.1 功能描述

统计每个世界观在项目中的使用情况，包括关联的场景数、关联的章节数、使用的角色数等，帮助用户了解世界观的使用深度。

**统计指标：**

| 指标 | 说明 |
|------|------|
| 关联场景数 | 该世界观下定义的场景总数（场景资产库） |
| 关联章节数 | 使用了该世界观的章节数量 |
| 关联角色数 | 在该世界观下活动的角色数量 |
| 关联道具数 | 属于该世界观的道具数量 |
| 关联建筑数 | 该世界观下的建筑数量 |
| 关联服装数 | 属于该世界观的服装数量 |

#### 23.5.2 操作流程

1. 在世界观详情页面，默认展示引用统计面板
2. 统计面板展示各个维度的引用数量和关联对象列表
3. 点击任意统计数字可查看详细关联列表
4. 关联列表中的对象支持点击跳转

#### 23.5.3 界面要求

- 统计面板位于详情页侧边栏或顶部区域
- 统计数字以大号字体显示，带图标
- 关联列表以表格或卡片列表形式展示
- 每个列表项显示：名称、类型图标、最后修改时间
- 空数据时显示"暂无关联，前往场景资产库添加"

## 第24章 场景资产库

### 24.1 功能概述

场景资产库用于管理 Webtoon 中所有出现的地理位置和场景环境。每个场景包含详细的视觉属性（季节、天气、时间、光线、氛围），关联参考图片和关键词标签，为后续 Prompt 生成提供标准化的场景描述数据。

### 24.2 场景 CRUD

#### 24.2.1 功能描述

用户对场景资产进行完整的增删改查操作。场景按照所属世界观进行组织，支持分类浏览、搜索和筛选。

**场景属性字段：**

| 属性 | 类型 | 说明 | 示例 |
|------|------|------|------|
| 场景名称 | 文本（必填） | 场景唯一标识名称 | "天玄学院·主教学楼" |
| 所属世界观 | 关联（必填） | 关联的世界观 | "主世界·天玄大陆" |
| 场景类型 | 单选 | 场景的大类 | 室内、室外、半开放、地下、空中、水下等 |
| 季节 | 单选 | 场景的季节设定 | 春、夏、秋、冬、四季常青、无季节等 |
| 天气 | 单选 | 默认天气状态 | 晴、阴、雨、雪、雾、暴风、沙尘等 |
| 时间 | 单选 | 默认时段 | 清晨、上午、正午、下午、傍晚、夜晚、深夜 |
| 光线 | 单选 | 光线氛围 | 自然光、暖光、冷光、昏暗、明亮、霓虹、烛光等 |
| 氛围 | 多选标签 | 场景给人的整体感觉 | 宁静、压抑、神秘、温馨、破败、宏伟、阴森等 |
| 描述详情 | 多行文本 | 场景的详细描述文字 | — |
| 场景关键词 | 标签组 | AI 生图时使用的关键词 | "魔法学院""古老建筑""石质地面"等 |

#### 24.2.2 操作流程

**创建场景：**

1. 进入"场景资产库"页面，点击"新建场景"按钮
2. 弹出创建表单，填写场景名称
3. 选择所属世界观（下拉选择框）
4. 设定场景类型、季节、天气、时间、光线、氛围等属性
5. 填写场景描述详情和场景关键词
6. 可选上传场景参考图
7. 点击"保存"完成创建

**编辑场景：**

1. 从场景列表中找到目标场景，点击进入场景详情
2. 点击"编辑"按钮进入编辑模式
3. 修改需要变更的属性
4. 点击"保存更改"

**删除场景：**

1. 在场景列表中勾选目标场景（支持批量删除）
2. 点击"删除"按钮
3. 系统提示确认删除对话框，并提示"该场景被 N 个画格引用"
4. 用户确认后删除

**查看场景：**

1. 在场景列表中点击场景名称进入场景详情页
2. 详情页展示场景所有属性、参考图、引用信息

#### 24.2.3 界面要求

- 场景列表页采用卡片网格布局（3-4 列）
- 每个场景卡片显示：缩略图（若无则显示默认占位图）、场景名称、所属世界观标签、场景类型图标
- 列表页顶部提供搜索框 + 筛选条件行（世界观、类型、季节、天气）
- 创建/编辑表单为全屏模态对话框，左侧为表单，右侧为参考图管理
- 氛围标签以彩色标签组展示，每个标签带颜色标识
- 场景类型以图标选择器展示（门类清晰）

### 24.3 场景属性（季节、天气、时间、光线、氛围）

#### 24.3.1 功能描述

每个场景的属性组合（季节+天气+时间+光线+氛围）将直接影响 AI 生图时的环境 Prompt 生成。系统支持预设场景属性模板，便于快速复制属性组合。

**属性组合规则：**
- 季节变化影响植被色彩、衣物厚度、日照角度
- 天气变化影响背景元素（雨/雪/雾粒子）、色彩饱和度
- 时间变化影响色彩色温、阴影方向、光源位置
- 光线与氛围共同决定画面整体色调和情感表达

#### 24.3.2 操作流程

1. 在场景编辑页面的"环境属性"区域设置各属性
2. 每个属性独立选择，互不冲突
3. 设置完成后，系统实时生成"环境描述预览"文本
4. 用户可将当前属性组合保存为"环境预设"，后续快速应用
5. 环境预设可在不同场景间复用

#### 24.3.3 界面要求

- 季节、天气、时间、光线使用横向选择按钮组，带图标和文字标签
- 氛围使用多选标签组，支持搜索和自定义添加
- 环境描述预览区域显示实时生成的文本摘要
- 环境预设面板：预设名称 + 一键应用按钮
- 预设列表支持 CRUD 操作

### 24.4 场景参考图管理

#### 24.4.1 功能描述

每个场景可关联多张参考图片，用于视觉参考和 AI 生图时的图生图输入。参考图可以是用户上传的真实照片、概念艺术图或 AI 生成的场景预览图。

**参考图管理功能：**
- 上传参考图（支持 JPG、PNG、WebP 格式）
- 参考图排序（拖动调整显示顺序）
- 参考图标注（在图上添加标注文字）
- 参考图分组（全景图、局部图、气氛图）
- 参考图作为 AI 生图的 Image2Image 输入

#### 24.4.2 操作流程

1. 在场景编辑页面的"参考图管理"区域操作
2. 点击"上传参考图"，从本地选择文件
3. 文件上传后生成缩略图，显示在图片库中
4. 拖动图片调整顺序
5. 点击图片进入预览模式，可在图片上添加标注点
6. 右键图片菜单：设为封面、删除、下载、设置为生图参考

#### 24.4.3 界面要求

- 参考图库采用瀑布流或网格布局
- 每张图片显示缩略图 + 文件名 + 上传时间
- 图片上支持鼠标悬停显示操作按钮（设为封面、删除、下载）
- 图片预览模态框支持左右切换、缩放、标注
- 标注功能：点击图片位置添加标注点，输入标注文本
- 拖拽排序使用直观的拖拽手柄图标

### 24.5 场景关键词/标签

#### 24.5.1 功能描述

场景关键词是用于 AI Prompt 生成的核心标签数据。系统支持自定义标签和自动标签生成，标签将作为 Prompt 组装中的重要组成部分。

**标签分类：**

| 标签类别 | 说明 | 示例 |
|---------|------|------|
| 环境标签 | 描述环境特征 | 森林、沙漠、雪地、城市、废墟 |
| 氛围标签 | 描述氛围感 | 神秘、诡异、热闹、冷清 |
| 元素标签 | 场景中的特定元素 | 喷泉、雕像、壁画、石碑 |
| 色彩标签 | 主色调描述 | 金色、暗红、冷蓝、翠绿 |
| 风格标签 | 视觉风格 | 写实、卡通、水墨、赛博朋克 |

#### 24.5.2 操作流程

1. 在场景编辑页面"关键词/标签"区域操作
2. 手动输入标签（输入后回车确认）
3. 从预设标签库中选择添加
4. 点击"AI 生成"按钮，系统根据场景描述自动生成推荐标签
5. 标签以标签组件展示，可点击 × 删除
6. 标签支持拖拽调整优先级顺序

#### 24.5.3 界面要求

- 标签输入框支持自动补全（从已有标签库匹配）
- 预设标签库以分类面板形式展示，点击即可添加
- AI 生成标签以淡紫色"推荐"标识与手动标签区分
- 标签按优先级从左到右排列，高优先级在前
- 标签显示颜色分类（不同类别的标签颜色不同）
- 标签数量限制提示（建议不超过 20 个）

## 第25章 道具资产库

### 25.1 功能概述

道具资产库用于管理 Webtoon 中出现的所有物品道具。道具是场景和角色交互中的重要元素，其视觉一致性对画面质量至关重要。系统通过分类管理、视觉描述和出场记录来维护道具的资产完整性和可追溯性。

### 25.2 道具 CRUD

#### 25.2.1 功能描述

用户对道具进行完整的增删改查操作，每个道具记录其名称、分类、视觉描述、参考图和出场记录。

**道具属性字段：**

| 属性 | 类型 | 说明 | 示例 |
|------|------|------|------|
| 道具名称 | 文本（必填） | 道具唯一标识名称 | "玄天剑" |
| 所属世界观 | 关联（必填） | 所属世界观 | "主世界·天玄大陆" |
| 道具分类 | 单选（必填） | 道具的大类归属 | 武器、日常、魔法、科技、食物、饰品等 |
| 子分类 | 单选 | 细分类型 | 武器→刀/剑/弓/杖/枪等 |
| 视觉描述 | 多行文本（必填） | 道具的外观详细描述 | "通体银色，剑柄镶嵌蓝宝石，剑身有流水纹路" |
| 颜色方案 | 颜色选择器 | 道具的主色和辅色 | 主色：#C0C0C0，辅色：#4169E1 |
| 尺寸 | 文本 | 道具的大致尺寸 | "剑身长 90cm，宽 5cm" |
| 材质 | 多选标签 | 道具的材质构成 | 金属、木材、宝石、皮革、布料等 |
| 关键特征 | 多行文本 | 对 AI 生图至关重要的细节 | "剑格为龙首造型，剑穗为红色丝线" |
| 参考图 | 图片组 | 道具的视觉参考图 | — |
| 重要程度 | 评分（1-5） | 道具在剧情中的重要程度 | 5 |
| 备注 | 多行文本（可选） | 其他补充说明 | — |

#### 25.2.2 操作流程

**创建道具：**

1. 进入"道具资产库"页面，点击"新建道具"按钮
2. 弹出创建表单，填写道具名称
3. 选择所属世界观和道具分类
4. 填写视觉描述和关键特征（这是 Prompt 生成的核心数据）
5. 设定颜色方案（支持取色器选择或色值输入）
6. 选填材质、尺寸、备注等信息
7. 可选上传道具参考图
8. 设定重要程度评分
9. 点击"保存"完成创建

**编辑/删除/查看流程** 同场景 CRUD 模式。

#### 25.2.3 界面要求

- 道具列表页采用列表视图（表格布局，便于扫描大量道具）
- 表格列：道具名称、分类、所属世界观、重要程度评分、出场次数、最后修改时间

#### 25.4.1 功能描述

**结构化视觉描述维度：**

| 维度 | 说明 | 示例 |

#### 25.4.3 界面要求

- 页面底部显示"完整视觉描述"预览区，实时生成
- 预览区支持一键复制
- AI 辅助按钮放置在"完整描述"框旁边

#### 27.5.1 功能描述

服装的细节描述是 AI 生图 Prompt 中服装部分的核心数据。系统支持按部位结构化描述。

**结构化描述维度：**

| 维度 | 说明 | 示例 |
|------|------|------|
| 上衣 | 上身服装描述 | "白色衬衫，立领，袖口有金色纽扣" |
| 下装 | 下身服装描述 | "深蓝色百褶裙，裙长至膝盖上方 10cm" |
| 外套 | 外层服装描述 | "深蓝色西装外套，双排扣，左胸有学院徽章" |
| 鞋袜 | 足部穿着 | "黑色皮鞋，白色短袜" |
| 头饰 | 头部装饰 | "红色蝴蝶结发带" |
| 配饰 | 其他穿戴品 | "银色项链，校徽胸针" |
| 特殊装饰 | 独特设计元素 | "袖口绣有金色魔法符文" |

#### 27.5.2 操作流程

1. 在服装编辑页面的"细节描述"区域，按部位输入
2. 每个部位有独立的输入框
3. 系统自动组装生成"完整服装描述"
4. 支持一键复制完整描述
5. AI 辅助：点击"AI 优化"按钮，系统根据当前输入优化描述文本

#### 27.5.3 界面要求

- 细节描述区域使用分栏布局（左侧输入，右侧完整描述预览）
- 每个部位输入框带有图示标识（小图标示意身体部位）
- 完整描述预览区实时更新，带有格式化的预览样式
- AI 优化按钮出现在每个输入框右侧

## 第28章 风格模板库

### 28.1 功能概述

风格模板库用于管理 Webtoon 作品的视觉风格模板。风格模板定义了作品中人物、场景、道具等视觉元素在 AI 生图时使用的一致性画风指引，是保证整部作品视觉统一性的核心工具。每个风格模板包含画风关键词、色彩基调、线条风格、渲染方式等参数。

**核心功能：**
- 风格模板 CRUD：创建、编辑、删除、查看风格模板
- 模板分类管理：按风格类型（韩漫、日漫、欧美、写实、Q版等）分类
- 模板预览：以示例图形式展示风格效果
- 模板引用统计：统计模板在人物、场景、Prompt 中的使用次数
- 系统预设模板：提供常用风格模板作为起点

### 28.2 风格模板 CRUD

#### 28.2.1 功能描述

用户对风格模板进行完整的增删改查操作，每个风格模板包含完整的画风定义参数。

**风格模板属性字段：**

| 属性 | 类型 | 说明 | 示例 |
|------|------|------|------|
| 模板名称 | 文本（必填） | 模板唯一标识名称 | "韩国网漫风格 V2" |
| 所属世界观 | 关联（必填） | 所属世界观 | "主世界·天玄大陆" |
| 风格分类 | 单选（必填） | 风格大类 | 韩漫、日漫、欧美、写实、水墨、Q版、赛博朋克等 |
| 画风关键词 | 多行文本（必填） | AI 生图时使用的画风指引 | "Webtoon style, clean lines, cel shading" |
| 色彩基调 | 多选标签 | 主色调和色彩倾向 | 暖色调、冷色调、高饱和、低饱和、黑白等 |
| 线条风格 | 单选 | 线条的粗细和质感 | 干净锐利、柔和圆润、粗犷有力、水墨晕染等 |
| 渲染方式 | 单选 | 色彩填充和阴影方式 | 赛璐珞、厚涂、水彩、素描、三渲二等 |
| 参考图 | 图片组 | 风格参考示例图 | — |
| 详细描述 | 多行文本 | 风格模板的详细说明 | "适用于玄幻题材的韩国条漫风格" |
| 使用次数 | 数字（自动） | 该模板被引用的次数 | 12 |

#### 28.2.2 操作流程

**创建风格模板：**

1. 进入"风格模板库"页面，点击"新建模板"按钮
2. 选择所属世界观
3. 填写模板名称和风格分类
4. 填写画风关键词（这是 AI Prompt 组装的核心数据）
5. 设置色彩基调、线条风格、渲染方式等视觉属性
6. 可选上传风格参考示例图
7. 填写详细描述
8. 点击"保存"完成创建

**编辑/删除/查看流程** 同其他资产 CRUD 模式。

#### 28.2.3 界面要求

- 模板列表页采用卡片网格布局（3-4 列）
- 每个模板卡片显示：预览缩略图、模板名称、风格分类标签、使用次数
- 卡片右下角显示"引用数"徽标
- 创建/编辑表单中，画风关键词字段为大面积文本输入区域，提示"此内容将直接用于 AI Prompt"
- 色彩基调为色块选择器，支持自定义色值
- 线条风格和渲染方式使用图标选择器

### 28.3 风格分类管理

#### 28.3.1 功能描述

风格分类体系用于组织和管理风格模板。

**预设风格分类：**

| 分类 | 说明 | 典型特征 |
|------|------|----------|
| 韩国网漫 | 典型的 Webtoon 风格 | 干净线条、赛璐珞上色、人物比例修长 |
| 日式动漫 | 日式动画/漫画风格 | 大眼睛、夸张表情、网点表现 |
| 欧美漫画 | 美式漫画风格 | 线条粗犷、色彩饱满、动态感强 |
| 写实风格 | 接近真实照片的风格 | 细节丰富、光影真实、材质质感强 |
| 水墨风格 | 中国传统水墨画风 | 墨色渲染、留白、意境表现 |
| 厚涂风格 | 油画质感的风格 | 色彩丰富、笔触明显、立体感强 |
| Q版风格 | 可爱夸张的风格 | 头大身小、简化细节、圆润线条 |
| 赛博朋克 | 赛博朋克视觉风格 | 霓虹配色、发光效果、科技元素 |

#### 28.3.2 操作流程

1. 新建/编辑模板时从"风格分类"下拉框选择
2. 选择分类后，系统自动填充该分类的默认画风关键词
3. 用户可基于默认关键词进行个性化调整

#### 28.3.3 界面要求

- 风格分类选择为图标选择器（每个分类配一个示例缩略图）
- 选择分类后，下方自动展示该分类的描述和推荐关键词
- 分类标签支持搜索过滤

### 28.4 风格模板预览

#### 28.4.1 功能描述

风格模板预览功能让用户在选择模板前能够直观地了解该模板的实际效果。系统利用示例图展示不同风格下的视觉效果对比。

**预览方式：**
- 缩略图预览：在模板列表中展示小尺寸效果图
- 大图预览：点击模板后展示大尺寸效果图
- 对比预览：将当前模板与系统默认模板并排对比
- 人物试妆：将模板应用到默认人物模型上生成预览图

#### 28.4.2 操作流程

1. 在模板库浏览时，鼠标悬停模板卡片显示大尺寸预览
2. 点击模板卡片进入详情页，展示完整预览图
3. 点击"对比预览"按钮，选择对比模板
4. 点击"人物试妆"，系统使用该模板为默认角色生成一张预览图
5. 预览图支持下载保存

#### 28.4.3 界面要求

- 预览区支持缩放和平移
- 对比视图采用左右分栏或上下分栏布局
- 预览图下方显示模板参数信息
- 人物试妆需要等待 AI 生成，显示加载状态

### 28.5 模板引用管理

#### 28.5.1 功能描述

跟踪风格模板在整个项目中的使用情况，包括被哪些人物、场景、Prompt 所引用。

**引用统计指标：**

| 指标 | 说明 |
|------|------|
| 关联角色数 | 使用该风格模板的角色数量 |
| 关联场景数 | 使用该风格模板的场景数量 |
| 关联 Prompt 数 | 使用该风格模板的 Prompt 数量 |
| 关联画格数 | 最终生成的画格数量 |

#### 28.5.2 操作流程

1. 在模板详情页面，默认展示引用统计面板
2. 统计面板展示各个维度的引用数量和关联对象列表
3. 点击任意统计数字可查看详细引用列表
4. 引用列表中的对象支持点击跳转
5. 删除模板时，提示用户"此模板被 N 个对象引用，删除后引用将失效"

#### 28.5.3 界面要求

- 引用统计面板位于详情页侧边栏
- 统计数字以大号字体显示，带图标标识
- 引用列表以表格形式展示，包含名称、类型、引用时间
- 空数据时显示"暂无引用"
