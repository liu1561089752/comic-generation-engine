## 第66章 Prompt模板库

### 66.1 功能描述

Prompt 模板库是 Prompt 组装的核心基础模块，提供预设的 Prompt 结构模板。系统定义了 **10 层 Prompt 结构**，每一层对应一个独立的语义维度，组装时合并为完整的生图 Prompt。模板库管理这些分层结构的预设方案，并通过变量体系实现动态数据注入。

**10 层 Prompt 结构定义：**

| 层级 | 名称 | 数据来源 | 示例 |
|------|------|----------|------|
| 1 | Character（角色描述） | 人物 IP 数据 | `{{character.name}}, {{character.appearance}}, wearing {{character.clothing}}` |
| 2 | Environment（环境描述） | 世界观场景数据 | `{{scene.name}}, {{scene.time_of_day}}, {{scene.weather}}` |
| 3 | Action（动作描述） | 动作库 | `{{action.type}}, {{action.intensity}}, {{action.detail}}` |
| 4 | Emotion（情绪描述） | 用户输入/AI 推导 | `{{emotion.mood}}, {{emotion.expression}}, {{emotion.intensity}}` |
| 5 | Camera（镜头类型） | 分镜数据 | `{{camera.type}}, {{camera.angle}}, {{camera.distance}}` |
| 6 | Lighting（光线设定） | 用户输入/场景推导 | `{{lighting.style}}, {{lighting.direction}}, {{lighting.color}}` |
| 7 | Composition（构图设定） | 构图数据 | `{{composition.type}}, {{composition.rule}}, {{composition.focus}}` |
| 8 | Webtoon Style（画风设定） | 风格模板 | `{{style.artist}}, {{style.renderer}}, {{style.detail_level}}` |
| 9 | Bubble（气泡描述） | 气泡数据 | `{{bubble.type}}, {{bubble.position}}, {{bubble.text_content}}` |
| 10 | Negative（负向 Prompt） | 系统预设 + 用户自定义 | `{{negative.default}}, {{negative.custom}}` |

**核心功能：**
- 模板列表：展示所有预设的 Prompt 结构模板
- 10 层结构定义：每层独立定义模板内容，支持自由组合
- 模板变量体系：通过 `{{变量名}}` 语法引用动态数据
- 模板分类管理：按用途、题材、画风等维度分类
- 模板导入/导出：支持 JSON 格式的模板数据交换
- 系统预设模板：内置覆盖主流场景的默认模板

### 66.2 操作流程

1. **浏览模板列表**：进入模板库，默认以卡片网格展示所有模板
2. **按分类筛选**：通过分类 Tab 或搜索框筛选特定类型模板
3. **查看模板详情**：点击模板卡片，展开模板详情，展示 10 层结构预览
4. **新建模板**：点击"新建模板"，从空白或基于已有模板创建
5. **编辑层内容**：在每层编辑框中编写模板文本，支持插入变量
6. **保存模板**：填写模板名称、分类、标签后保存
7. **应用模板**：从模板库选择一个模板，应用于当前 Panel 的 Prompt 组装
8. **导入/导出**：选择模板导出为 JSON 文件，或导入外部 JSON 模板

### 66.3 界面要求

- **模板卡片网格**：以卡片网格展示模板，每张卡片显示模板名称、缩略描述、分类标签、层数标识
- **分类 Tab 栏**：顶部 Tab 栏按分类筛选——全部 / 基础模板 / 题材模板 / 我的模板 / 收藏
- **搜索框**：支持按模板名称、变量名、层内容关键词搜索
- **模板详情弹窗**：
  - 左侧为 10 层结构的折叠列表，每层可展开查看具体内容
  - 右侧为模板元数据（名称、分类、标签、创建时间、使用次数）
  - 底部提供"应用模板"、"编辑"、"导出"操作按钮
- **模板编辑器**：
  - 10 层分页编辑：每层以独立标签页或折叠面板展示
  - 每层编辑框支持语法高亮（变量名以不同颜色标记）
  - 变量插入面板：右侧悬浮面板展示可用变量列表，点击插入
  - 实时预览区：底部固定区域展示合并后的完整 Prompt 效果
- **收藏图标**：每张卡片右上角提供收藏/取消收藏按钮

## 第67章 Prompt编辑器

### 67.1 功能描述

Prompt 编辑器是 Prompt 中心的核心交互界面，为用户提供可视化、结构化的 Prompt 编辑体验。编辑器基于 10 层结构设计，每层独立编辑，同时提供实时预览、语法高亮、变量自动补全和 Prompt 长度统计等辅助功能。

**核心功能：**
- **分层面板**：10 层分别以独立面板展示，支持折叠/展开
- **下拉可选值 + 自定义输入**：每层提供基于数据源的下拉选择列表，同时支持自由文本输入
- **实时预览组装结果**：编辑过程中实时显示各层合并后的完整 Prompt
- **语法高亮**：变量引用、关键词、负面词等使用不同颜色高亮
- **变量自动补全**：输入 `@` 或 `{{` 时触发自动补全建议（@角色名、@场景名、@动作名等）
- **Prompt 长度统计**：显示当前 Prompt 总字符数、Token 估算数，超出模型限制时警告
- **单层启用/禁用**：每层可独立开关，禁用的层不参与组装

### 67.2 操作流程

1. **进入编辑器**：从 Prompt 模板库选择模板，或从 Panel 管理页面跳转到 Prompt 编辑器
2. **浏览分层**：默认展开所有 10 层，以垂直滚动布局展示
3. **编辑层内容**：
   - 点击任一层的编辑框，输入描述文本
   - 输入 `@` 触发变量补全弹出，选择目标变量插入
   - 点击下拉按钮查看可选值列表，选择后自动填充
4. **预览 Prompt**：编辑过程中，底部预览区实时更新完整 Prompt
5. **开关层**：点击每层右侧的开关按钮，启用或禁用该层
6. **调整层顺序**：拖拽层标题区域调整各层在最终 Prompt 中的拼接顺序
7. **检查长度**：查看右上角的长度计数器，确认在模型限制范围内
8. **保存 Prompt**：编辑完成后点击"保存"，系统自动创建新版本
9. **应用 Promopt**：点击"应用到 Panel"，将当前 Prompt 绑定到目标 Panel

### 67.3 界面要求

- **垂直分层布局**：10 层垂直排列，每层包含层标题栏、输入区、操作区
- **层标题栏**：显示层编号、层名称（如"L1 Character"）、启用开关、折叠/展开按钮
- **输入区**：
  - 支持多行文本输入
  - 语法高亮渲染：
    - `{{变量}}` — 蓝色高亮 + 浅蓝背景
    - 关键词/触发词 — 绿色文字
    - 负向词 — 红色文字
  - 输入框右侧提供"清空"按钮
- **下拉选择区**：在输入框上方或左侧固定的下拉选择器面板
  - 选择器按层分类展示可选值
  - 选中后自动将对应文本插入到输入框光标位置
  - 支持搜索筛选可选值
- **变量补全弹出**：
  - 输入 `@` 或 `{{` 后触发
  - 弹出列表显示匹配的变量名和来源（角色/场景/动作等）
  - 选中后自动插入完整变量语法
  - 支持键盘上下选择 + Enter 确认
- **实时预览区**：
  - 固定在页面底部的横条或底部面板
  - 以纯文本形式展示合并后的完整 Prompt
  - 被禁用的层内容以灰色删除线显示或完全隐藏
  - 支持一键复制预览内容
- **长度统计**：
  - 右上角显示"字符数 / Token 估算数"
  - 超过模型限制时（如 2048 Token）显示红色警告
  - 鼠标悬停显示各层字符数分布（柱状图或表格）
- **工具栏**：页面顶部提供"选择模板"、"保存"、"应用到 Panel"、"重置"按钮

## 第68章 Prompt变量管理

### 68.1 功能描述

Prompt 变量管理是连接 Prompt 模板与业务数据的桥梁。变量从人物 IP、场景、分镜等上游模块自动提取，供 Prompt 模板引用。用户也可自定义变量，满足个性化需求。系统提供变量值编辑、引用关系追踪等功能，确保变量的可维护性和数据一致性。

**核心功能：**
- **系统变量列表**：从人物 IP、场景、分镜、气泡等模块自动提取的结构化变量
- **自定义变量**：用户自由创建和管理的变量
- **变量值编辑**：修改变量的默认值或为特定 Panel 设置覆盖值
- **变量引用关系追踪**：查看每个变量被哪些模板引用、影响哪些 Panel
- **变量分组展示**：按来源模块分组（角色变量 / 场景变量 / 分镜变量 / 气泡变量 / 自定义）
- **变量搜索与过滤**：按名称、来源、使用状态搜索变量

**系统变量来源及示例：**

| 来源模块 | 变量命名空间 | 示例变量 |
|----------|-------------|----------|
| 人物 IP | `character.*` | `character.name`, `character.appearance`, `character.clothing`, `character.hairstyle`, `character.expression` |
| 场景 | `scene.*` | `scene.name`, `scene.type`, `scene.time_of_day`, `scene.weather`, `scene.mood` |
| 分镜 | `camera.*`, `composition.*`, `action.*` | `camera.type`, `camera.angle`, `composition.type`, `action.type` |
| 气泡 | `bubble.*` | `bubble.type`, `bubble.text_content`, `bubble.position` |
| 画风 | `style.*` | `style.name`, `style.artist`, `style.renderer`, `style.detail_level` |
| 光线 | `lighting.*` | `lighting.style`, `lighting.direction`, `lighting.color_temperature` |
| 情绪 | `emotion.*` | `emotion.mood`, `emotion.expression`, `emotion.intensity` |

### 68.2 操作流程

1. **查看变量列表**：进入变量管理页面，默认展示所有系统变量（按模块分组）
2. **浏览变量详情**：点击变量行，展开变量详情面板，显示变量名、来源模块、当前值、引用计数
3. **编辑变量值**：在变量详情面板中修改默认值，修改后自动更新所有引用该变量的模板
4. **创建自定义变量**：点击"新建变量"，填写变量名、命名空间、默认值、描述
5. **删除自定义变量**：选择自定义变量删除（系统变量不可删除）
6. **查看引用关系**：点击"引用追踪"，展示引用该变量的所有模板列表和 Panel 列表
7. **搜索变量**：使用搜索框按变量名或值内容搜索
8. **变量值覆盖**：在特定 Panel 上下文中为变量设置覆盖值，不影响全局默认值

### 68.3 界面要求

- **分组列表视图**：按模块分组展示变量，每组有组标题栏（含模块名、变量数量统计）
- **变量行**：每行显示变量名（带命名空间前缀）、当前值预览（截断显示）、引用计数徽章、变量类型标签（系统/自定义）
- **变量详情面板**：从右侧滑出的详情面板
  - 顶部：变量全名、命名空间、类型标签
  - 基本信息：描述、来源模块、创建时间
  - 当前值：可编辑的文本框，修改后"保存"
  - 引用追踪 Tab：
    - "引用模板"列表：显示引用了该变量的模板名称和层号
    - "引用 Panel"列表：显示使用了该变量的 Panel 编号
    - 点击引用项可跳转到对应模板/Panel
  - 覆盖值列表：显示所有设置了覆盖值的 Panel 上下文
- **搜索与过滤**：顶部搜索框 + 过滤下拉（按模块 / 按类型 / 按引用状态）
- **自定义变量管理**：自定义变量行右侧有编辑/删除操作按钮，系统变量不可编辑/删除
- **变量值预览气泡**：鼠标悬停在变量值预览上时，弹窗显示完整值内容

## 第69章 Prompt版本管理

### 69.1 功能描述

Prompt 版本管理记录每次 Prompt 修改的历史，支持版本对比、回滚和标签管理。每个 Panel 的 Prompt 都可以拥有独立版本历史，方便用户在迭代过程中追踪变更、比较效果、恢复至最佳版本。

**核心功能：**
- **版本自动保存**：每次 Prompt 修改保存时自动生成新版本
- **版本号规则**：从 v1 开始递增，版本号为 `v{n}` 格式
- **版本对比（Diff）**：任意两个版本之间进行逐层对比，展示增删改差异
- **版本回滚**：将当前 Prompt 恢复到任意历史版本
- **版本标签**：为特定版本打标签（如"效果最佳版"、"已评审"、"需优化"），便于快速定位
- **版本备注**：每次保存时可输入版本备注说明
- **版本元数据**：记录版本创建时间、创建人、Prompt 长度、变更摘要

### 69.2 操作流程

1. **查看版本列表**：进入版本管理，以时间线形式展示所有版本
2. **查看版本详情**：点击版本项展开详情，显示完整的 Prompt 文本
3. **版本对比**：
   - 选择两个版本（通常为当前版本 vs 目标版本）
   - 系统以逐层 Diff 方式展示差异
   - 绿色高亮=新增，红色高亮=删除，黄色高亮=修改
4. **版本回滚**：在目标版本上点击"回滚到此版本"，系统弹窗确认
   - 确认后当前 Prompt 被替换为目标版本的 Prompt
   - 回滚操作本身也会生成一个新版本（回滚后的 v{n+1}）
5. **添加标签**：在版本项上点击"添加标签"，输入标签文本（如"效果最佳版"）
6. **添加备注**：保存 Prompt 时在备注输入框中填写版本备注
7. **筛选版本**：按标签、日期范围、备注关键词筛选版本
8. **导出版本**：选择版本导出为 JSON 文件

### 69.3 界面要求

- **时间线视图**：左侧为垂直时间线，每个版本以时间点形式展示
  - 时间点图标：默认圆形，带标签的版本显示星形图标
  - 时间点连线：连接相邻版本
- **版本卡片**：每个时间点右侧为版本卡片
  - 卡头顶部：版本号（v1, v2...）、创建时间、标签徽章
  - 卡片正文：版本摘要（自动生成的变更简述，如"修改了 L1 Character 和 L3 Action"）
  - 备注区域：显示保存时输入的自定义备注
  - 卡片底部：操作按钮"查看详情"、"对比"、"回滚"、"添加标签"
- **版本对比页面**：
  - **左右双栏布局**：左栏为旧版本，右栏为新版本
  - **逐层对比**：10 层以折叠面板形式排列，每层内显示 Diff
  - **Diff 高亮**：使用绿底（新增行）/ 红底（删除行）/ 黄底（修改行）
  - **差异统计**：顶部显示"新增 X 字符，删除 Y 字符，修改 Z 处"
  - **层开关**：可单独切换显示/隐藏某层的 Diff
  - **全屏模式**：支持 Diff 页面全屏展示
- **版本详情弹窗**：
  - 展示版本完整 Prompt（10 层展开）
  - 显示版本元数据（版本号、创建时间、Prompt 长度（字符数/Token 数））
  - 标签管理和备注编辑区域
- **标签管理**：
  - 标签以彩色胶囊状徽章展示在版本卡片上
  - 点击标签可快速筛选同标签版本
  - 预设标签列表："效果最佳版"、"待评审"、"已评审"、"需优化"、"历史参考"
  - 支持自定义标签输入

## 第70章 Prompt测试中心

### 70.1 功能描述

Prompt 测试中心是 Prompt 质量验证和效果评估的终端模块。用户可以直接将 Prompt 发往生图模型获取图片反馈，或通过 A/B 测试对比两个版本的生成效果，从而快速迭代和优化 Prompt。

**核心功能：**
- **单次 Prompt 测试**：将当前 Prompt 直接发往配置的生图模型，返回生成图片
- **A/B 测试**：同一个 Prompt 的两个版本同时生图，左右对比展示结果
- **测试历史记录**：所有测试任务以列表形式保存，支持回溯查看
- **测试效果评分**：对生成图片进行评分（AI 自动评分 + 用户手动评分）
- **测试参数配置**：自定义生图参数（模型、步数、分辨率、Seed 等）
- **批量测试**：一次性测试多个 Prompt 版本，生成对比画廊

### 70.2 操作流程

**单次测试流程：**
1. **选择 Prompt**：从编辑器加载待测试的 Prompt
2. **配置参数**：选择生图模型、设置分辨率、步数、CFG Scale、Seed 等参数
3. **点击生成**：点击"测试生成"，系统将 Prompt 发往生图模型
4. **等待结果**：显示生成进度（排队中 / 生成中 / 完成）
5. **查看图片**：生成完成后在预览区显示图片
6. **评分**：AI 自动评分 + 用户手动评分（1-5 星）
7. **保存记录**：测试结果自动保存至历史记录

**A/B 测试流程：**
1. **选择版本 A 和版本 B**：从版本列表或编辑器中分别选择两个 Prompt 版本
2. **锁定参数**：确保 A/B 测试使用相同的生图参数（模型、分辨率、Seed 等）
3. **同时提交**：点击"开始 A/B 测试"，系统同时提交两个生成任务
4. **并排对比**：生成完成后，两张图片左右并排展示
5. **投票/评分**：对 A 和 B 分别评分，或选择"A 更好 / B 更好 / 差不多"
6. **记录结果**：A/B 测试结果保存至历史记录，标注获胜版本

### 70.3 界面要求

- **测试控制面板**（单次测试）：
  - Prompt 显示区：加载后显示完整的 10 层合并 Prompt，只读
  - 参数配置区：模型选择下拉、分辨率选择（预设 + 自定义）、步数滑动条、CFG Scale 滑动条、Seed 输入框（支持随机）
  - "测试生成"按钮：醒目的大按钮，提交后变为进度指示器
- **图片结果预览区**：
  - 居中展示，支持缩放（滚轮缩放 + 拖拽平移）
  - 图片下方显示生成耗时、模型名称、Seed 值
  - 提供"放大查看"、"下载图片"、"复制到此 Prompt 版本"按钮
- **评分区**：
  - AI 评分：以星级 + 分数（如 4.2/5.0）展示，附带 AI 评分评语
  - 用户评分：点击 1-5 星手动评分
  - 评语输入框：可选输入文本评价
- **A/B 测试界面**：
  - **左右双栏布局**：左栏为版本 A，右栏为版本 B
  - 每栏顶部显示版本号和 Prompt 摘要
  - 每栏图片区域展示生成结果
  - **投票按钮**：两栏中间区域提供"A 更好"、"差不多"、"B 更好"三个大按钮
  - 投票后自动计算并显示统计结果（如"A 胜出 60%"）
- **测试历史记录**：
  - **列表视图**：表格展示历史记录，列包括：测试 ID、日期时间、Prompt 版本号、模型、耗时、AI 评分、用户评分、类型（单次/A/B）
  - **筛选**：按日期范围、类型、评分范围筛选
  - **详情查看**：点击行展开详情，查看完整 Prompt 和生成图片
  - **对比功能**：勾选两条记录，点击"对比"进入对比视图
  - **导出**：支持导出测试记录为 CSV 或 JSON
- **批量测试画廊**：
  - 网格展示多个 Prompt 版本的生成结果
  - 每张图片底部显示版本号、评分
  - 支持按评分排序
  - 支持"选择最佳"操作，将最佳版本标记并保存到 Panel
