# 第十八篇 插件中心

---

## 第115章 插件管理

### 115.1 功能概述

插件管理模块提供对系统插件的全生命周期管理，包括浏览、安装、卸载、启用/禁用和配置插件。插件机制允许第三方开发者扩展系统功能。

### 115.2 插件列表

#### 功能描述

展示所有已安装的插件和可用的插件，支持查看插件详情和状态。

#### 插件列表展示

| 字段 | 说明 | 示例 |
|------|------|------|
| 插件名称 | 插件标识名称 | "ComfyUI 工作流集成" |
| 插件 ID | 唯一标识 | com.example.comfyui-workflow |
| 版本号 | 当前安装版本 | 1.2.0 |
| 作者 | 插件开发者 | "开发者名" |
| 描述 | 插件功能简要说明 | "集成 ComfyUI 工作流到生图流程" |
| 状态 | 已启用 / 已禁用 / 未安装 | 已启用 |
| 安装时间 | 插件安装时间 | 2026-06-27 |
| 依赖 | 依赖的其他插件 | 无 |
| 兼容性 | 兼容的系统版本 | ≥ v1.2.0 |

#### 操作流程

1. 进入「插件中心」→「插件管理」
2. 默认展示所有已安装的插件列表
3. 点击某个插件 → 展开详情面板

| 详情信息 | 说明 |
|---------|------|
| 插件基本信息 | 名称、ID、版本、作者 |
| 功能说明 | 详细的功能介绍和使用说明 |
| 配置页面 | 插件的配置入口（如有） |
| 依赖关系 | 插件的依赖和冲突信息 |

4. 在插件列表底部或独立 Tab 展示「可用插件」市场
5. 可用插件显示安装按钮和安装次数

#### 界面要求

- 插件以卡片列表展示，每张卡片包含插件图标、名称、版本和状态
- 已启用插件有绿色"已启用"标签
- 已禁用插件有灰色"已禁用"标签
- 插件详情面板支持查看插件的完整文档
- 搜索插件名称和描述
- 按状态、分类筛选

### 115.3 插件启用/禁用

#### 功能描述

支持在不卸载插件的情况下临时启用或禁用插件，方便排查插件冲突或测试。

#### 操作流程

1. 在插件列表中找到目标插件
2. 点击插件卡片上的开关（Toggle）或操作菜单中的「启用/禁用」

| 操作 | 说明 |
|------|------|
| 启用 | 激活插件的所有功能 |
| 禁用 | 临时停用插件，插件代码不加载，不占用资源 |

3. 状态切换即时生效
4. 禁用后的插件在列表中标记为"已禁用"
5. 禁用插件不影响已有数据

#### 依赖检查

| 检查项 | 说明 |
|--------|------|
| 禁用前置检查 | 禁用插件前检查是否有其他插件依赖它 |
| 提示信息 | 如有依赖，显示依赖该插件的其他插件列表 |
| 强制禁用 | 确认后强制禁用，依赖插件的功能可能不可用 |

#### 界面要求

- 启用/禁用开关使用 Toggle 控件
- 切换时如有依赖关系弹出警告对话框
- 状态变更后插件功能即时生效
- 禁用后配置数据保留

### 115.4 插件配置

#### 功能描述

提供插件的配置入口，每个插件可在系统中注册自己的配置页面，用户可在此调整插件的行为参数。

#### 配置方式

| 配置方式 | 说明 |
|---------|------|
| 内嵌配置页 | 插件在系统中注册配置页面，在插件管理内嵌显示 |
| 独立弹窗 | 插件配置以弹窗形式展示 |
| 配置文件 | 插件通过配置文件进行设置（高级用户） |

#### 配置项类型

| 类型 | 说明 |
|------|------|
| 文本输入 | API 地址、Key 等 |
| 开关 | 功能开启/关闭 |
| 下拉选择 | 选项选择 |
| 数字输入 | 阈值、时间等数值 |
| 颜色选择 | 颜色值 |
| 文件选择 | 选择本地文件路径 |

#### 操作流程

1. 在插件详情页点击「配置」按钮
2. 插件加载其配置界面
3. 用户调整配置参数
4. 保存配置
5. 配置生效（部分配置可能需要重启插件或系统）

#### 界面要求

- 配置页面遵循系统统一的 UI 风格
- 配置项有说明文字和默认值提示
- 配置修改后需要保存
- 提供「恢复默认配置」按钮
- 复杂配置提供导入/导出功能

## 第116章 工作流扩展

### 116.1 功能概述

工作流扩展模块支持用户自定义 AI Webtoon Factory 的自动化工作流，通过可视化编排的方式组合不同功能节点，实现灵活的制作流程。

### 116.2 自定义工作流节点

#### 功能描述

系统提供可扩展的工作流节点体系，用户可在已有节点基础上创建自定义节点，扩展工作流的能力。

#### 系统内置节点类型

| 节点类型 | 说明 | 输入 | 输出 |
|---------|------|------|------|
| 小说导入 | 导入小说文件 | 文件路径 | Novel 数据 |
| 角色设计 | 设计角色设定 | 角色描述 | Character 数据 |
| 场景设定 | 设定场景 | 场景描述 | Scene 数据 |
| 剧情分析 | AI 分析剧情 | Novel 数据 | Scene 列表 |
| 语义切句 | 切分画格 | Scene 数据 | Panel 列表 |
| 分镜规划 | 规划镜头 | Panel 数据 | Shot + Layout |
| 气泡规划 | 生成气泡文本 | Panel 数据 | Bubble 数据 |
| Prompt 生成 | 组装 Prompt | 人物+场景+镜头 | Prompt |
| 图片生成 | AI 生图 | Prompt | Image |
| 一致性检测 | 质量检查 | Image | 检测报告 |
| 导出 | 导出漫画 | 页面数据 | 导出文件 |

#### 自定义节点创建

| 步骤 | 说明 |
|------|------|
| 1. 定义节点 | 指定节点名称、描述、输入输出格式 |
| 2. 实现逻辑 | 编写节点的处理逻辑代码（Python 脚本） |
| 3. 注册节点 | 将节点注册到工作流系统 |
| 4. 测试节点 | 在测试环境中验证节点的功能 |
| 5. 发布节点 | 节点可用于正式工作流编排 |

#### 界面要求

- 节点展示使用统一的可视化卡片样式
- 节点输入输出端口清晰标识
- 节点支持拖拽放置到工作流编辑器中
- 自定义节点有区别于内置节点的样式标记

### 116.3 工作流编排

#### 功能描述

通过可视化拖拽编辑器，将各个工作流节点连接为完整的自动化流程管道。

#### 编辑界面布局

```
┌─────────────────────────────────────────────────────────┐
│  工具栏                                                    │
│  [保存] [运行] [导入] [导出] [撤销] [重做] [缩放]            │
├──────────────┬──────────────────────────────────────────┤
│  节点面板     │  工作流画布                                │
│              │                                          │
│  ├ 输入节点   │   [小说导入] ──→ [剧情分析] ──→ [语义切句]   │
│  ├ 处理节点   │       │              │              │     │
│  ├ AI 节点   │       ▼              ▼              ▼     │
│  ├ 输出节点   │   [角色设计]   [场景设定]    [分镜规划]      │
│  └ 自定义     │       │              │              │     │
│              │       └──────┬───────┘              │     │
│  节点库       │              ▼                      ▼     │
│  [搜索节点]   │        [Prompt 生成] ──→ [图片生成]        │
│              │              │                      │     │
│              │              ▼                      ▼     │
│              │        [一致性检测] ──→ [导出]              │
│              │                                          │
└──────────────┴──────────────────────────────────────────┘
```

#### 编排操作

| 操作 | 说明 |
|------|------|
| 添加节点 | 从节点面板拖拽节点到画布 |
| 连接节点 | 从一个节点的输出端口拖拽到另一节点的输入端口 |
| 删除节点 | 选中节点后按 Delete 键或右键选择删除 |
| 编辑节点 | 双击节点打开配置面板 |
| 移动节点 | 拖拽节点在画布上调整位置 |
| 复制节点 | 右键选择复制 |
| 连线校验 | 自动校验连接类型是否匹配 |

#### 工作流执行

| 执行方式 | 说明 |
|---------|------|
| 完整执行 | 从开始节点执行到结束节点 |
| 单步执行 | 逐个节点执行，方便调试 |
| 断点执行 | 在指定节点暂停执行 |
| 增量执行 | 仅执行发生变更的节点及其下游节点 |

#### 界面要求

- 画布支持无限缩放和平移
- 节点连线使用贝塞尔曲线
- 节点执行状态实时显示（未执行/执行中/成功/失败）
- 支持注释节点（在画布上添加说明文本）
- 支持工作流模板保存和加载
- 画布支持网格对齐

### 116.4 第三方工具集成（ComfyUI 工作流）

#### 功能描述

支持将 ComfyUI 工作流作为自定义节点集成到系统中，用户可在 ComfyUI 中设计图片处理流程，然后在 AI Webtoon Factory 中调用。

#### 集成方式

| 集成方式 | 说明 |
|---------|------|
| API 调用 | 通过 ComfyUI API 调用远程工作流 |
| 本地加载 | 加载本地的 ComfyUI 工作流 JSON 文件 |
| 工作流导入 | 将 ComfyUI 工作流导入为系统节点 |

#### 操作流程

1. 在 ComfyUI 中设计好工作流
2. 导出工作流为 JSON 文件（或复制 API 格式的 JSON）
3. 在 AI Webtoon Factory 中创建「ComfyUI 工作流节点」

| 配置项 | 说明 |
|--------|------|
| 工作流名称 | 节点名称 |
| ComfyUI 地址 | ComfyUI 服务地址 |
| 工作流 JSON | 粘贴或上传工作流 JSON |
| 输入映射 | 将工作流的输入映射到系统数据 |
| 输出映射 | 将工作流的输出映射到系统数据 |

4. 配置输入/输出映射：

| 映射项 | 说明 |
|--------|------|
| 系统字段 → 工作流输入 | 如将 Panel 图片传入工作流的 image 输入 |
| 工作流输出 → 系统字段 | 如将工作流的输出图片保存到系统 |

5. 保存并测试集成

#### 界面要求

- ComfyUI 工作流节点在节点面板中以特殊图标标记
- 输入/输出映射以表单形式配置
- 支持工作流 JSON 的可视化预览
- 测试运行后显示生成结果的预览
- 连接失败时显示详细的错误信息

## 第117章 第三方接口

### 117.1 功能概述

第三方接口模块提供系统对外的 API 能力，包括 API Key 管理、Webhook 配置和接口调用频率控制，使系统能力可被外部工具和自动化流程调用。

### 117.2 API Key 管理

#### 功能描述

管理用于访问系统 API 的密钥，支持创建、编辑、删除和轮换 API Key。

#### API Key 数据结构

| 字段 | 说明 | 示例 |
|------|------|------|
| Key 名称 | 标识该 Key 的用途 | "自动上传脚本" |
| Key ID | 密钥标识（非密钥本身） | ak_q3f2a1d8 |
| Key Secret | 密钥值（创建后仅显示一次） | sk_xxxxxxxx... |
| 权限范围 | 该 Key 允许调用的 API 范围 | 生图.读取, 生图.写入 |
| 状态 | 启用 / 禁用 | 启用 |
| 创建时间 | 创建时间 | 2026-06-27 |
| 最后使用时间 | 最后一次调用时间 | 2026-06-27 14:30 |
| 调用次数 | 累计调用次数 | 1,234 |
| 过期时间 | 密钥过期时间（可选） | 2027-06-27 |

#### 权限范围定义

| 权限 | 说明 | 等级 |
|------|------|------|
| 只读 | 仅可读取系统数据 | 最低 |
| 项目.写入 | 可创建和修改项目 | 低 |
| 生图.写入 | 可创建生图任务 | 中 |
| 导出.写入 | 可执行导出操作 | 中 |
| 系统.管理 | 可修改系统配置 | 高 |
| 全部 | 所有操作权限 | 最高 |

#### 操作流程

1. 进入「插件中心」→「第三方接口」→「API Key 管理」
2. 查看所有已创建的 API Key 列表
3. 点击「创建 Key」→ 弹出创建表单

| 字段 | 必填 | 说明 |
|------|------|------|
| Key 名称 | 是 | 标识该 Key 的用途 |
| 权限范围 | 是 | 勾选需要授予的权限 |
| 过期时间 | 否 | 可选项，过期后 Key 自动失效 |

4. 点击「创建」→ 系统生成 Key，弹窗显示 Key Secret（仅显示一次）
5. 用户需要立即复制并保存 Key Secret
6. 管理操作：启用/禁用、删除、编辑名称、重新生成

#### 界面要求

- Key Secret 创建后仅显示一次，关闭后不可再查看
- 列表中的 Key Secret 以掩码显示（如 sk_****...****）
- 权限范围以 Checkbox 列表展示
- 提供「复制 Key ID」和「复制示例代码」按钮
- 删除 Key 需要二次确认
- 支持生成使用示例（Python、JavaScript、CURL）

### 117.3 Webhook 配置

#### 功能描述

支持配置 Webhook，当系统中特定事件发生时，向外部 URL 发送 HTTP 通知。适用于与第三方系统集成、自动化工作流触发等场景。

#### Webhook 事件类型

| 事件 | 触发条件 | 发送数据 |
|------|---------|---------|
| 任务完成 | AI 任务执行成功 | 任务 ID、类型、结果摘要 |
| 任务失败 | AI 任务执行失败 | 任务 ID、类型、错误信息 |
| 生图完成 | 单张图片生成完成 | 图片 ID、预览 URL |
| 批量生图完成 | 批量生图任务完成 | 任务 ID、图片数量 |
| 检测告警 | 一致性检测发现问题 | 项目 ID、Panel 编号、问题类型 |
| 项目更新 | 项目数据变更 | 项目 ID、变更类型 |
| 导出完成 | 导出任务完成 | 导出 ID、文件 URL |

#### Webhook 配置

| 配置项 | 说明 | 必填 |
|--------|------|------|
| 名称 | Webhook 的标识名称 | 是 |
| 目标 URL | 接收通知的 HTTP 端点 | 是 |
| 触发事件 | 勾选需要触发的事件 | 是 |
| Secret | 用于验证通知来源的密钥 | 否 |
| 请求头 | 自定义 HTTP 请求头 | 否 |
| 重试策略 | 失败时的重试次数 | 否（默认 3 次） |
| 超时时间 | 请求超时时间 | 否（默认 10s） |

#### 操作流程

1. 进入「Webhook 配置」页面
2. 查看所有已配置的 Webhook 列表
3. 点击「添加 Webhook」→ 填写配置表单
4. 点击「保存」→ Webhook 配置生效
5. 点击「测试」→ 发送测试通知验证配置是否正确
6. 管理操作：启用/禁用、编辑、删除

#### 通知数据格式

```json
{
  "event": "task.completed",
  "timestamp": "2026-06-27T14:30:00Z",
  "signature": "sha256=...",
  "data": {
    "task_id": "TSK-20260627-001",
    "task_type": "image_generation",
    "project_id": "PRJ-001",
    "status": "completed",
    "summary": "共生成 12 张图片"
  }
}
```

#### 界面要求

- Webhook 列表显示名称、URL、触发事件数、状态
- 事件选择以 Checkbox 列表分组展示
- 签名验证使用 HMAC-SHA256
- 提供 Webhook 调用日志查看（每次调用的请求/响应记录）
- 调用失败时显示错误原因和重试信息

### 117.4 接口调用频率控制

#### 功能描述

配置 API 调用的频率限制，防止恶意调用或意外循环请求导致系统负载过高。

#### 频率限制策略

| 限制级别 | 限制策略 | 默认值 | 说明 |
|---------|---------|--------|------|
| 全局限制 | 所有 API 的总调用频率 | 1000 次/分钟 | 防止突发流量 |
| 按 Key 限制 | 单个 API Key 的调用频率 | 100 次/分钟 | 限制单个客户端 |
| 按端点限制 | 特定 API 端点的频率 | 50 次/分钟 | 保护高负载接口 |
| 按 IP 限制 | 来源 IP 的调用频率 | 200 次/分钟 | 防止 DDoS |

#### 超额处理

| 处理方式 | 说明 |
|---------|------|
| 拒绝请求 | 返回 HTTP 429 (Too Many Requests) |
| 排队等待 | 请求排队，等待令牌释放 |
| 降级服务 | 返回缓存结果或简化数据 |

#### 配置操作

1. 进入「接口管理」→「频率控制」
2. 查看当前的频率限制配置
3. 修改各项限制值
4. 配置超额处理方式
5. 保存配置，即时生效

#### 监控面板

| 指标 | 说明 |
|------|------|
| 当前调用量 | 当前时间窗口的调用次数 |
| 调用量趋势 | 近 24 小时的调用量折线图 |
| 被限流次数 | 因频率限制被拒绝的请求数 |
| 各 Key 调用分布 | 各 API Key 的调用占比 |

#### 界面要求

- 频率限制配置以数字输入框+单位展示
- 修改限制时显示建议值
- 监控图表实时更新
- 限流事件在操作日志中记录
- 提供「重置限流统计」按钮
