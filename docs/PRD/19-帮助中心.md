## 第118章 使用教程

### 118.1 功能概述

使用教程模块为新用户和现有用户提供系统各功能模块的使用指导，帮助用户快速上手和深入使用系统。教程涵盖新手入门和模块专项操作指南。

### 118.2 图文教程

#### 功能描述

提供包含截图、步骤说明和注意事项的图文教程，覆盖新手入门和各模块使用。

#### 教程分类

| 分类 | 说明 | 教程数量（预估） |
|------|------|----------------|
| 新手入门 | 面向首次使用用户的引导教程 | 5-8 篇 |
| 项目操作 | 项目创建、管理、设置相关 | 3-5 篇 |
| 小说管理 | 小说导入、编辑、分析相关 | 4-6 篇 |
| 角色设计 | 人物 IP 中心相关操作 | 5-8 篇 |
| 分镜版式 | 分镜规划和版式编辑相关 | 4-6 篇 |
| Prompt 编辑 | Prompt 中心相关操作 | 3-5 篇 |
| AI 生图 | 生图任务和图片管理相关 | 4-6 篇 |
| 质量检测 | 一致性检测和审核相关 | 3-4 篇 |
| 漫画编辑 | 编辑器使用相关 | 5-8 篇 |
| 导出发布 | 导出和发布相关 | 3-5 篇 |

#### 教程内容结构

每篇教程包含以下部分：

| 部分 | 说明 |
|------|------|
| 教程标题 | 清晰的标题，如"如何导入小说" |
| 适用场景 | 该教程适用的使用场景说明 |
| 前置条件 | 开始本教程前需要完成的操作 |
| 操作步骤 | 分步骤的图文说明（1-2-3 编号） |
| 步骤截图 | 每个步骤对应的界面截图 |
| 注意事项 | 操作中需要注意的事项 |
| 常见问题 | 该操作相关的常见问题链接 |
| 相关教程 | 本操作的上下游教程链接 |

#### 界面要求

- 教程以分类目录树展示在左侧
- 右侧展示教程的完整内容
- 教程支持 Markdown 渲染
- 截图支持点击放大查看
- 支持系统内搜索教程内容
- 教程可标记为"已学习"
- 每个教程显示阅读进度和预计阅读时间

### 118.3 视频教程链接

#### 功能描述

提供视频教程的外部链接或嵌入式播放，视频内容与图文教程互补，适合偏好视频学习的用户。

#### 视频教程内容

| 教程 | 时长（预估） | 内容 |
|------|-------------|------|
| 新手入门 5 分钟快速上手 | 5min | 从安装到导出第一条漫画 |
| 小说导入与 AI 分析 | 8min | 导入格式、分析参数、结果解读 |
| 角色设计完整指南 | 12min | 六视图、服装、表情设计 |
| 高级 Prompt 技巧 | 10min | 10 层 Prompt 结构的深入讲解 |
| 批量生图与质量控制 | 15min | 批量参数设置、一致性检测 |
| 漫画编辑器全面讲解 | 20min | 编辑器各功能详细演示 |
| 自动化工作流设置 | 8min | 自定义工作流编排 |

#### 操作流程

1. 在帮助中心点击「视频教程」选项卡
2. 浏览视频教程列表
3. 点击视频卡片 → 内嵌播放器播放（或跳转到外部平台）
4. 视频支持倍速播放（0.5x / 1x / 1.5x / 2x）
5. 支持下载视频（可选）

#### 界面要求

- 视频以卡片网格展示，卡片包含封面图、标题、时长
- 支持按分类筛选视频
- 内嵌播放器支持全屏
- 视频下方显示相关的图文教程链接
- 记录用户的观看进度

## 第119章 常见问题

### 119.1 功能概述

常见问题（FAQ）模块收集和整理用户在系统使用过程中遇到的常见问题及解答，帮助用户自主解决问题，减少客服咨询。支持按分类浏览、关键词搜索和问题反馈。

### 119.2 FAQ 分类

#### 功能描述

将常见问题按模块分类组织，方便用户快速找到对应的问题领域。

#### 分类结构

| 分类 | 说明 | 问题数量（预估） |
|------|------|----------------|
| 导入问题 | 小说导入格式、编码、大小限制等 | 10-15 |
| 人物问题 | 角色设定、一致性、六视图等 | 8-12 |
| 分镜问题 | 语义切分、分镜规划、版式布局等 | 8-12 |
| Prompt 问题 | Prompt 编写、模板、变量等 | 10-15 |
| 生图问题 | 生图失败、质量差、速度慢等 | 12-18 |
| 导出问题 | 导出格式、文件大小、PSD 兼容性等 | 10-15 |
| 系统问题 | 安装、更新、性能、存储等 | 10-15 |
| 通用问题 | 账号、权限、数据安全等 | 8-10 |

#### 界面要求

- FAQ 分类以大图标卡片形式展示在首页
- 每个分类显示该分类的问题数量
- 点击分类进入该分类的问题列表
- 分类支持按字母序或问题数排序

### 119.3 问题搜索

#### 功能描述

提供全文搜索能力，用户可在所有 FAQ 内容中搜索关键词，快速定位相关问题和答案。

#### 搜索功能

| 功能 | 说明 |
|------|------|
| 关键词搜索 | 搜索问题标题和答案内容 |
| 分类筛选 | 搜索结果中可按分类进一步筛选 |
| 热门搜索 | 显示最近搜索量高的关键词 |
| 搜索建议 | 输入时自动补全常见问题 |

#### 操作流程

1. 在 FAQ 页面顶部的搜索框中输入问题关键词
2. 系统实时显示匹配的问题列表（300ms 防抖）
3. 点击搜索结果 → 展开答案
4. 如搜索无结果，显示"没有找到相关问题的答案"提示
5. 提供"提交问题"入口

#### 界面要求

- 搜索框在页面顶部显著位置
- 搜索结果高亮显示匹配的关键词
- 搜索结果按相关度降序排列
- 支持搜索整个 FAQ 数据库

### 119.4 问题反馈

#### 功能描述

当用户在 FAQ 中找不到答案时，可以通过问题反馈功能向系统管理员或开发者提交问题。

#### 反馈表单

| 字段 | 必填 | 说明 |
|------|------|------|
| 问题分类 | 是 | 选择问题所属的功能模块 |
| 问题标题 | 是 | 简短的描述问题 |
| 问题描述 | 是 | 详细描述问题的表现和复现步骤 |
| 截图/录屏 | 否 | 上传问题截图或录屏文件 |
| 系统版本 | 自动 | 当前系统版本号 |
| 操作系统 | 自动 | 用户操作系统信息 |
| 联系方式 | 否 | 邮箱或其他联系方式 |

#### 操作流程

1. 在 FAQ 页面底部点击「没有找到答案？提交问题」
2. 填写问题反馈表单
3. 点击「提交」→ 反馈提交成功
4. 系统生成反馈编号（如 FB-20260627-001）
5. 反馈处理完成后通知用户

#### 界面要求

- 反馈表单简洁，必填字段清晰标识
- 支持拖拽上传截图
- 提交后显示感谢提示和反馈编号
- 用户可通过反馈编号查询处理进度

- 支持按版本类型筛选

### 120.3 新功能说明

#### 功能描述

详细说明每个版本中新增的功能，包括功能的使用方法和适用场景。

#### 新功能条目结构

```
### 新增功能：插件系统

**功能描述：** 插件系统允许第三方开发者扩展 AI Webtoon Factory 的功能。

**使用方法：**
1. 进入「插件中心」→「插件管理」
2. 浏览可用插件列表
3. 点击安装，插件自动集成到系统

**适用场景：**
- 需要自定义工作流节点
- 需要集成第三方服务
- 需要扩展系统的导出格式支持

**配置说明：**
- 插件安装后可在「插件配置」中调整参数
- 插件可在「插件管理」中启用/禁用
```

#### 界面要求

- 新功能列表按版本分组
- 每个新功能配有功能截图或 GIF 演示
- 新功能标记为"🆕 New"标签
- 点击新功能可定位到相关的使用教程

### 120.4 Bug 修复列表

#### 功能描述

记录每个版本修复的 Bug 列表，帮助用户了解问题是否已在当前版本得到解决。

#### Bug 修复条目结构

```
### Bug 修复

- 修复：导入包含特殊字符的小说文件时编码错误的问题（#42）
- 修复：批量生图任务在特定条件下卡死的问题（#56）
- 修复：深色模式下编辑器气泡文字颜色显示异常（#61）
- 修复：导出长图时部分 Panel 位置偏移的问题（#73）
- 修复：编辑器中撤销操作后图层顺序错乱的问题（#78）
```

#### 界面要求

- Bug 修复列表按版本分组展示
- 每个 Bug 关联问题编号（便于内部追踪）
- 重要 Bug 修复以黄色高亮标记
- 支持搜索 Bug 修复记录
