# 第十三篇 漫画编辑器

## 第85章 编辑器首页

### 85.1 功能概述

编辑器首页是漫画编辑器的入口页面，以可视化方式展示项目各页面的缩略图和页码信息，用户可以通过缩略图快速定位目标页面并进入编辑。编辑器采用经典的三栏布局——左侧工具栏、中间画布、右侧属性面板，为漫画后期编辑提供完整的操作环境。

**输入：**
- 项目 ID
- 页面和 Panel 的结构化数据

**输出：**
- 页面缩略图列表
- 编辑器三栏布局工作区

### 85.2 功能点

#### 85.2.1 项目页面列表（缩略图+页码）

**功能描述：**
- 以缩略图网格形式展示项目的所有页面
- 每个页面显示：页面缩略图（Webtoon 长页预览）、页码编号、页面内 Panel 数量
- 缩略图按页码顺序排列
- 支持页面搜索（按页码 / 关键词）
- 支持页面状态标记（如"已完成"、"待编辑"、"有质量问题"）
- 页面缩略图支持懒加载

**操作流程：**
1. 进入漫画编辑器，默认展示当前项目的所有页面列表
2. 页面以网格布局展示，每行 4-5 个页面缩略图
3. 滚动加载更多页面
4. 每个缩略图显示页码和 Panel 数量徽章
5. 点击缩略图进入该页面的编辑界面
6. 悬停缩略图显示页面状态和操作按钮

**界面要求：**
- 网格布局：响应式网格，每行 4-5 个缩略图
- 缩略图尺寸：约 160×220px（保持 Webtoon 长页比例）
- 页码显示：缩略图左上角的大号数字（如"Page 1"）
- Panel 数量：缩略图右上角的灰色徽章（如"3 Panels"）
- 状态角标：
  - 已完成：绿色 ✓
  - 待编辑：灰色 ⬜
  - 有质量问题：红色 ⚠️
- 悬停浮层：鼠标悬停时显示"编辑"、"预览"、"删除"按钮
- 空状态：无页面时显示"暂无页面，请先在版式中心创建"
- 加载状态：Skeleton 骨架屏

#### 85.2.2 进入编辑

**功能描述：**
- 点击页面缩略图进入该页面的编辑模式
- 编辑模式采用三栏布局
- 页面标题显示当前编辑的章节-页面信息
- 支持通过顶部的页码导航快速切换页面
- 进入编辑时自动加载页面内所有 Panel 的数据

**操作流程：**
1. 在页面列表中点击目标页面缩略图
2. 系统切换到编辑器三栏布局
3. 中间画布加载该页面的完整内容
4. 工具栏和属性面板根据当前选中元素更新
5. 页面标题显示"第 X 章 - 第 Y 页"
6. 页面顶部提供"← 返回页面列表"按钮
7. 页码导航（上一页/下一页）支持快速翻页

**界面要求：**
- 页面切换动画：淡入或滑动过渡
- 页面标题栏：编辑器顶部，显示当前页面信息
- 返回按钮：标题栏左侧的"←"按钮
- 页码导航：标题栏右侧的"上一页"和"下一页"按钮
- 快捷键：PageUp/PageDown 切换页面
- 页面加载中显示加载指示器

#### 85.2.3 编辑器整体布局

**功能描述：**
- 三栏布局：左侧工具栏、中间画布、右侧属性面板
- 左侧工具栏：垂直排列，包含图片编辑、气泡编辑、文本编辑、图层管理、特效编辑等工具
- 中间画布：展示当前页面的完整内容，支持缩放和平移
- 右侧属性面板：根据当前选中工具或元素动态展示对应的属性设置
- 布局支持拖拽调整各栏宽度
- 支持全屏模式（隐藏工具栏和属性面板，画布铺满）

**操作流程：**
1. 进入编辑模式后，默认展示标准三栏布局
2. 左侧工具栏选中一个工具，中间画布进入对应的交互模式
3. 在画布中点击或选中元素，右侧属性面板展示该元素的属性
4. 拖拽工具栏/属性面板的边框调整栏宽
5. 点击"全屏"按钮进入全屏编辑模式
6. 按 ESC 或点击"退出全屏"返回标准布局

**界面要求：**
- 左侧工具栏：宽度约 48-64px，图标按钮垂直排列
- 工具栏图标：每个工具一个图标按钮，选中时高亮
- 中间画布：占据剩余宽度，默认显示比例适配
- 右侧属性面板：默认宽度约 280-320px，可折叠
- 布局调整：工具栏和属性面板的边框可拖拽调整宽度
- 全屏模式入口：编辑器右上角的全屏图标
- 分栏分隔线：可拖拽的分隔条，hover 时变色

### 85.3 数据模型

| 字段 | 类型 | 说明 |
|------|------|------|
| editor_layout | JSON | 编辑器布局配置（各栏宽度） |
| current_page_id | UUID | 当前编辑的页面 ID |
| current_tool | String | 当前选中的工具 |
| current_element_id | UUID | 当前选中的元素 ID |
| zoom_level | Float | 画布缩放级别 |
| created_at | DateTime | 创建时间 |

## 第86章 图片编辑

### 86.1 功能概述

图片编辑模块提供对 Panel 图片的基础编辑能力，包括图片替换、裁切、滤镜和缩放旋转等操作。用户无需切换到外部图片编辑软件即可完成常见的图片调整，提高编辑效率。

**输入：**
- Panel 中的图片对象
- 用户的操作指令

**输出：**
- 编辑后的图片（或引用更新）

### 86.2 功能点

#### 86.2.1 图片替换

**功能描述：**
- 支持将当前 Panel 的图片替换为其他候选图或历史版本
- 替换时保留当前 Panel 的其他元素（气泡、特效等）位置不变
- 替换来源：候选图管理（第 74 章）的候选图、版本管理（第 75 章）的历史版本
- 替换后自动记录到版本历史
- 替换支持 Undo/Redo

**操作流程：**
1. 在画布中选中目标 Panel 图片
2. 在属性面板或右键菜单中选择"替换图片"
3. 弹出图片选择器，展示该 Panel 的候选图和历史版本
4. 点击目标图片预览选择
5. 点击"确认替换"
6. 画布中的图片更新为新选择的图片
7. 原图片自动保存为历史版本

**界面要求：**
- 替换入口：选中图片时属性面板中的"替换图片"按钮
- 右键菜单：右键点击图片显示"替换图片"选项
- 图片选择器弹出面板：候选图 2×2 网格 + 历史版本列表
- 预览切换：点击候选图时在右侧显示大图预览
- 确认按钮：选择器底部的"✓ 确认替换"按钮
- 替换反馈：替换后画布图片更新动画（淡入）
- 撤销：工具栏的撤销按钮支持撤销替换操作

#### 86.2.2 图片裁切

**功能描述：**
- 支持对 Panel 图片进行自由比例裁切
- 裁切模式提供预设裁切比例选项：原始比例 / 1:1 / 4:3 / 16:9 / 自由裁切
- 裁切框支持拖拽调整大小和位置
- 裁切操作实时预览效果
- 裁切支持 Undo/Redo

**操作流程：**
1. 在画布中选中目标 Panel 图片
2. 选择裁切工具或右键菜单选择"裁切"
3. 图片上出现裁切框（半透明遮罩 + 白色边框）
4. 拖拽裁切框的边角调整裁切区域
5. 拖拽裁切框内部移动裁切区域位置
6. 选择预设比例切换裁切框比例
7. 双击裁切框内或点击"应用"确认裁切
8. 裁切完成后图片更新

**界面要求：**
- 裁切框：白色边框 + 边角拖拽手柄（方形白点）
- 裁切遮罩：裁切框外部半透明黑色遮罩
- 预设比例按钮：裁切工具栏中的快捷按钮组（原始/1:1/4:3/16:9/自由）
- 信息显示：裁切框上方显示"宽×高"尺寸
- 应用/取消按钮：裁切工具栏的"✓ 应用"和"✕ 取消"
- 裁切完成后画布图片更新动画
- 键盘快捷键：Enter 确认裁切，ESC 取消裁切

#### 86.2.3 图片滤镜

**功能描述：**
- 提供一组预设图片滤镜效果
- 滤镜效果实时预览（鼠标悬停滤镜时在画布上预览）
- 每种滤镜可调整强度（0-100%）
- 滤镜不影响原图（非破坏性编辑）
- 支持叠加多个滤镜

**预设滤镜列表：**

| 滤镜名称 | 效果说明 | 适用场景 |
|---------|---------|---------|
| 原图 | 无滤镜效果 | 恢复原图 |
| 暖色调 | 增加暖色氛围 | 温馨、回忆场景 |
| 冷色调 | 增加冷色氛围 | 悲伤、神秘场景 |
| 高对比 | 提高对比度和饱和度 | 战斗、动作场景 |
| 梦幻 | 柔光 + 轻微模糊 | 回忆、幻想场景 |
| 复古 | 棕褐色调 | 古代、回忆场景 |
| 黑白 | 去色 | 严肃、深沉场景 |
| 明亮 | 提高亮度 | 阳光场景 |
| 暗黑 | 降低亮度 + 增强暗部 | 阴暗、恐怖场景 |

**操作流程：**
1. 在画布中选中目标 Panel 图片
2. 在右侧属性面板找到"滤镜"区域
3. 滤镜以缩略图网格展示，每个滤镜一个小缩略图效果
4. 鼠标悬停滤镜缩略图，画布上预览滤镜效果
5. 点击滤镜应用到图片
6. 拖动强度滑块调整滤镜强度
7. 点击"原图"恢复无滤镜状态
8. 支持叠加多个滤镜，在滤镜列表中按顺序叠加

**界面要求：**
- 滤镜缩略图网格：横向滚动或 4 列网格，每个约 60×80px
- 悬停预览：悬停滤镜时画布图片临时应用滤镜效果
- 强度滑块：滤镜选择后的强度调整（0-100%）
- 激活状态：已应用的滤镜显示蓝色边框标记
- 滤镜叠加列表：显示已应用的滤镜顺序链
- 清除按钮："清除所有滤镜"一键恢复原图

#### 86.2.4 图片缩放/旋转

**功能描述：**
- 支持对图片进行等比缩放（保持宽高比）
- 支持任意角度旋转（0-360°，步进 1°）
- 也提供快捷旋转：左旋 90° / 右旋 90° / 水平翻转 / 垂直翻转
- 缩放和旋转操作实时在画布上预览
- 所有操作支持 Undo/Redo

**操作流程：**
1. 在画布中选中目标 Panel 图片
2. 在属性面板中找到"变换"区域
3. 缩放：拖拽缩放滑块或输入百分比数值
4. 旋转：拖拽旋转滑块（0-360°）或点击快捷旋转按钮
5. 画布上图片实时响应缩放和旋转
6. 图片四角的控制手柄也支持直接拖拽旋转
7. 点击"重置"恢复原始尺寸和角度

**界面要求：**
- 缩放控件：滑块（50%-200%）+ 数值输入框（百分比）
- 旋转控件：圆形角度选择器 + 数值输入框（0-360°）
- 快捷旋转按钮组：左旋 90°、右旋 90°、水平翻转、垂直翻转
- 控制手柄：选中图片四角显示旋转手柄（弧形箭头图标）
- 缩放时图片边缘显示尺寸指示线
- 重置按钮："↺ 重置"按钮恢复原始状态

### 86.3 数据模型

| 字段 | 类型 | 说明 |
|------|------|------|
| image_edit_id | UUID | 图片编辑记录唯一标识 |
| panel_id | UUID | 关联 Panel ID |
| crop_info | JSON | 裁切信息（x, y, width, height） |
| filters | JSON | 滤镜列表及强度 |
| transform | JSON | 变换信息（scale, rotation, flip） |
| replaced_from | UUID | 替换来源图片 ID（如从历史版本替换） |
| created_at | DateTime | 编辑时间 |

## 第87章 气泡编辑

### 87.1 功能概述

气泡编辑模块提供漫画气泡（对白框、旁白框、内心独白框）的位置调整、大小调整、样式切换和增删管理等操作。用户可以通过拖拽、选择和参数调整等方式，灵活编排气泡在画面中的位置和外观，确保文本的阅读顺序和视觉效果。

**输入：**
- Panel 中的气泡对象列表
- 用户的操作指令

**输出：**
- 调整后的气泡位置、大小、样式
- 新增或删除的气泡

### 87.2 功能点

#### 87.2.1 气泡拖拽移动

**功能描述：**
- 支持在画布上直接拖拽气泡自由移动
- 拖拽时显示实时位置反馈
- 支持吸附对齐（与其他气泡边缘或画面边缘对齐）
- 支持按方向键微调位置（1px/次 或 10px/次）
- 拖拽范围限制在画布区域内

**操作流程：**
1. 选中气泡编辑工具
2. 在画布中点击目标气泡选中它
3. 按住鼠标左键拖拽气泡到目标位置
4. 拖拽时显示位置坐标（x, y）和对齐参考线
5. 释放鼠标完成移动
6. 也可选中气泡后使用键盘方向键精调位置
7. 按住 Shift + 方向键可 10px 步进移动

**界面要求：**
- 选中气泡：显示蓝色边框 + 四角控制手柄
- 拖拽时：气泡跟随鼠标，显示半透明位置参考
- 对齐辅助线：拖拽到接近其他气泡或画面边缘时，显示蓝色对齐参考线
- 位置信息：画布左上角或气泡下方显示当前坐标（如"x: 120, y: 350"）
- 选中高亮：选中的气泡比其他气泡颜色更亮

#### 87.2.2 气泡大小调整

**功能描述：**
- 支持通过拖拽控制手柄调整气泡大小
- 支持按照宽高比例锁定等比缩放
- 调整时文本自动重新换行适配新尺寸
- 最小尺寸限制（防止过小导致文字无法显示）
- 支持输入精确尺寸数值

**操作流程：**
1. 选中目标气泡
2. 拖拽气泡四角控制手柄调整宽度和高度
3. 按住 Shift 键拖拽时可等比缩放
4. 调整过程中气泡内部文本实时重新排版
5. 也可在属性面板中输入精确的宽度和高度值
6. 点击"自动适配"按钮让气泡自动根据文本内容调整大小

**界面要求：**
- 控制手柄：四个角上的白色方形手柄，hover 时变为双向箭头光标
- 等比缩放：拖拽时气泡宽高比锁定，四角显示"🔒"图标
- 尺寸信息：拖拽时显示"宽：180px × 高：120px"
- 自动适配按钮：属性面板中的"自动适配"一键按钮
- 最小尺寸：气泡无法缩小时闪烁提示"已达最小尺寸"

#### 87.2.3 气泡样式切换

**功能描述：**
- 支持切换气泡的视觉样式
- 预设样式库：椭圆对白框、矩形旁白框、云状独白框、虚线框、无框等
- 样式切换时气泡内容不变
- 支持自定义样式参数（边框颜色、填充色、边框粗细、圆角等）
- 样式预览实时更新

**预设气泡样式：**

| 样式名称 | 形状 | 适用类型 | 特点 |
|---------|------|---------|------|
| 椭圆对白 | 椭圆 | 对白 | 标准漫画对白框，带尾部指向说话人 |
| 矩形旁白 | 直角矩形 | 旁白 | 旁白框，通常无尾部 |
| 圆角旁白 | 圆角矩形 | 旁白 | 较温和的旁白样式 |
| 云朵独白 | 云朵形 | 内心独白 | 模拟思考气泡效果 |
| 虚线独白 | 椭圆虚线 | 内心独白 | 虚线边框，带尾部 |
| 锯齿独白 | 锯齿形 | 内心独白 | 锯齿状边框 |
| 无框纯文本 | 无边框 | 旁白/特效 | 无框文本直接浮动 |
| 半透明底框 | 矩形+透明背景 | 旁白 | 半透明色块底衬 |

**操作流程：**
1. 选中目标气泡
2. 在右侧属性面板找到"气泡样式"区域
3. 样式预设以缩略图网格展示
4. 点击某个预设样式，画布上的气泡立即切换样式
5. 在"自定义样式"区域调整参数（边框颜色、填充、圆角等）
6. 调整参数时画布上实时更新
7. 点击"设为默认样式"将当前样式保存为个人偏好

**界面要求：**
- 样式预设网格：2 行 × 4 列，每个样式一个小图标示
- 选中样式：蓝色边框高亮
- 自定义参数面板：
  - 边框颜色：颜色选择器
  - 填充色：颜色选择器
  - 边框粗细：滑块（1-8px）
  - 圆角大小：滑块（0-20px，仅矩形有效）

#### 88.2.1 气泡内文本修改

**功能描述：**
- 支持双击气泡进入文本编辑模式
- 在气泡内直接编辑文本内容（所见即所得）
- 支持中文、英文、韩文等多语言文本输入
- 编辑过程中气泡自适应文本长度

- 编辑状态指示：气泡边框变为绿色（编辑中）

**功能描述：**
- 支持为文本选择字体（从字体库中选取）
- 支持字号调整（8-96pt）
- 支持字体颜色调整（颜色选择器）
- 支持文本加粗、斜体、下划线
- 支持描边（颜色 + 宽度）
- 当前调整的文本属性实时预览

**操作流程：**
1. 选中目标气泡（或在气泡内选中部分文本）
2. 在右侧属性面板的"文本样式"区域调整
3. 字体：从下拉列表中选择字体（包含字体预览文字）
4. 字号：拖动滑块或输入数值
5. 颜色：点击色块打开颜色选择器
6. 加粗/斜体/下划线：点击对应的 T 按钮
7. 描边：勾选启用 + 选择颜色 + 调整宽度
8. 所有调整在画布上实时预览

**界面要求：**
- 字体选择器：下拉列表，每行显示字体名称和 "Aa" 预览
- 字号滑块：8-96pt 范围，带数值输入框
- 颜色选择器：色盘 + HEX 输入 + 预设颜色（最近使用）
- 格式化工具栏：B（加粗）/ I（斜体）/ U（下划线）按钮组
- 描边配置：勾选框 + 颜色选择器 + 宽度滑块
- 选中部分文本时，调整只应用于选中文本
- 未选中文本时，调整应用于整个气泡

#### 88.2.3 文本对齐

**功能描述：**
- 支持三种文本对齐方式：左对齐、居中、右对齐

- 不同气泡类型默认对齐方式：
  - 对白：左对齐
  - 旁白：左对齐
  - 内心独白：左对齐

**操作流程：**
1. 选中目标气泡
2. 在属性面板的"文本对齐"区域选择对齐方式
3. 点击左对齐/居中/右对齐图标按钮

**界面要求：**

- 对齐预览：点击后即时看到文本排列变化

#### 88.2.4 文本换行

**功能描述：**

- 换行预览：切换策略时文本重排动画

**功能描述：**
- 为整个 Panel 画面添加全局特效
- 支持三种画面特效类型：
  - 发光：模拟光源发光效果
  - 模糊：高斯模糊效果
  - 动态：运动模糊效果（模拟动态镜头）
- 画面特效可作用于全屏或指定区域
- 支持叠加多个画面特效

**操作流程：**
1. 选中目标 Panel
2. 在属性面板切换到"画面特效" Tab
3. 点击"添加特效"选择特效类型（发光/模糊/动态）
4. 调整特效参数：
   - 发光：强度（1-10）、颜色、半径
   - 模糊：强度（1-20px）
   - 动态：方向（角度）、强度（1-20px）
5. 如需要区域特效，在画布上绘制特效区域
6. 预览特效效果
7. 点击"应用"确认添加

**界面要求：**
- 添加特效按钮："➕ 添加特效"下拉按钮
- 特效列表：已添加的特效列表，每个特效显示类型图标和强度
- 参数面板：根据选中特效类型动态变化
- 区域特效：画布上显示半透明区域框，可拖拽调整
- 特效预览开关：勾选"预览"时画布上显示特效效果
- 清除按钮：特效列表旁的"✕ 删除"按钮
- 特效排序：支持拖拽调整多个特效的叠加顺序

#### 90.2.4 特效参数面板

**功能描述：**
- 为每种特效提供专用的参数调整面板
- 参数面板根据特效类型动态切换
- 所有参数调整实时预览
- 支持参数预设保存和加载
- 参数面板可折叠

**操作流程：**
1. 选中已添加的特效
2. 右侧属性面板显示该特效的参数配置
3. 根据不同特效类型展示对应的参数控件
4. 调整参数时画布上实时渲染效果
5. 点击"保存为预设"保存当前参数配置
6. 点击"加载预设"快速应用之前保存的配置

**界面要求：**
- 动态面板：根据特效类型切换参数布局
- 发光特效参数：
  - 强度：滑块（1-10）
  - 发光颜色：颜色选择器
  - 发光半径：滑块（5-50px）
  - 混合模式：下拉选择（叠加/滤色/柔光）
- 模糊特效参数：
  - 模糊类型：下拉选择（高斯模糊/径向模糊）
  - 强度：滑块（1-20px）
- 动态特效参数：
  - 方向：角度表盘（0-360°）
  - 强度：滑块（1-20px）
  - 中心点：坐标输入（用于径向动态效果）
- 预设管理：参数面板底部的"预设"区域
- 参数重置：面板右上角的"重置"按钮

| panel_id | UUID | 关联 Panel ID |

## 第91章 页面编辑

### 91.1 功能概述

页面编辑模块提供漫画页面的整体结构管理能力，包括页面的新增与删除、页面内 Panel 布局调整、跨页面移动 Panel、以及页面模板切换。该模块是漫画编辑器中管理整体版面结构的核心工具。

**输入：**
- 页面列表和 Panel 数据

**输出：**
- 调整后的页面结构
- Panel 布局的变化

### 91.2 功能点

#### 91.2.1 页面新增/删除

**功能描述：**
- 支持在项目任意位置新增空白页面
- 新增页面可选择页面模板（来自 Webtoon 模板库）
- 支持删除空白页面或包含内容的页面
- 删除页面时该页面的所有 Panel 移至"未分配 Panel"池
- 删除操作确认防止误删
- 页面新增/删除后后续页面编号自动重排

**操作流程：**

**新增页面：**
1. 在页面列表底部或右键菜单中选择"新增页面"
2. 选择页面模板（可选）
3. 新页面插入到当前选中页面的下一页位置
4. 页面列表更新，新增页面缩略图显示
5. 新增页面自动应用默认版式

**删除页面：**
1. 在页面列表中右键目标页面或悬停时点击删除按钮
2. 弹出删除确认对话框
3. 对话框显示页面缩略图和提示"删除后 Panel 将移至未分配池"
4. 确认删除后页面从列表中移除
5. 后续页面编号自动重排

**界面要求：**
- 新增按钮：页面列表底部的"＋ 新增页面"按钮
- 模板选择弹窗：新增页面时弹出的模板选择器
- 删除按钮：页面缩略图悬停时右上角的"✕"删除图标
- 删除确认弹窗：包含页面缩略图 + Panel 数量 + 确认选项
- 页码重排：删除后所有页面编号无感更新
- 新增动画：新页面缩略图淡入出现

#### 91.2.2 页面内 Panel 布局调整

**功能描述：**
- 支持调整页面内 Panel 的位置和尺寸
- 拖拽 Panel 边框调整 Panel 大小
- 拖拽 Panel 移动其在页面内的位置
- Panel 对齐辅助线（吸附到其他 Panel 边缘或页面边缘）
- Panel 间距统一调整

**操作流程：**
1. 在画布页面视图中选中目标 Panel
2. 拖拽 Panel 边缘的控制手柄调整大小
3. 拖拽 Panel 内部移动位置
4. 移动/调整时自动吸附对齐到相邻 Panel
5. 移动/调整后，页面上的其他 Panel 自动重排适应
6. 也支持在属性面板中输入精确的"位置和尺寸"数值
7. 点击"统一间距"按钮自动均衡各 Panel 间距

**界面要求：**
- Panel 选中：蓝色边框 + 四角控制手柄
- 拖拽调整：Panel 边缘拖拽时显示尺寸数值
- 对齐辅助线：蓝色对齐线，显示对齐关系
- 属性面板显示：位置（x, y）+ 尺寸（width, height）
- 间距工具：选中多个 Panel 后显示的"统一间距"按钮
- 布局预设：属性面板中的快捷布局按钮（如"均分"、"上下排列"等）
- 自动重排动画：其他 Panel 调整位置时平滑过渡动画

#### 91.2.3 跨页面移动 Panel

**功能描述：**
- 支持将 Panel 从一个页面移动到另一个页面
- 移动后源页面和目标页面自动更新布局
- 支持拖拽到页面列表中完成跨页移动
- 支持复制 Panel 到其他页面（保留原 Panel 的副本）
- 移动后关联的 Prompt 和图片数据保持不变

**操作流程：**
1. 在画布中选中要移动的 Panel（支持多选）
2. 右键选择"移动到页面"或拖拽到页面列表中的目标页面
3. 拖拽到页面列表目标页面缩略图上时，该页面高亮
4. 释放鼠标完成移动
5. 源页面自动调整布局填补空缺
6. 目标页面自动布局适应新增 Panel
7. 也可右键选择"复制到页面"创建副本

**界面要求：**
- 拖拽移动面板：左侧页面列表可拖放区域
- 拖拽时 Panel 缩略图跟随鼠标，显示"移动到第 X 页"提示
- 目标页面高亮：拖到目标页面上时，页面缩略图高亮（蓝色边框）
- 右键菜单："移动到页面"子菜单列出所有页面编号
- 操作反馈：移动完成后 toast 提示"已移动到第 X 页"
- 自动布局：移动/复制后页面自动调整 Panel 位置

#### 91.2.4 页面模板切换

**功能描述：**
- 支持为页面切换不同的 Webtoon 模板
- 模板切换后 Panels 自动重新布局适配新模板
- 模板预览：切换前展示模板效果预览
- 切换后的布局冲突时提示用户手动调整
- 模板来自 Webtoon 模板库（第 55 章）

**操作流程：**
1. 在页面列表或画布中选中目标页面
2. 在属性面板中找到"页面模板"区域
3. 点击"切换模板"按钮
4. 弹出模板选择器，以缩略图网格展示可用模板
5. 鼠标悬停模板缩略图时预览效果
6. 点击选中模板
7. 系统自动将当前 Panel 重新布局到新模板
8. 若自动布局结果不满意，提示手动调整
9. 点击"应用"确认切换

**界面要求：**
- 模板缩略图网格：展示模板布局预览（Panel 分割示意）
- 每个模板显示：名称 + Panel 分割示意缩略图 + Panel 数量
- 悬停预览：画布上临时展示新模板布局
- 自动布局结果展示：切换后显示新的 Panel 排布
- 冲突提示：当 Panel 数量与模板不匹配时显示警告
- 应用/取消按钮：模板选择器底部的"应用"和"取消"
- 模板切换记录：切换后原模板保留为历史可回退

### 91.3 数据模型

| 字段 | 类型 | 说明 |
|------|------|------|
| page_id | UUID | 页面唯一标识 |
| project_id | UUID | 所属项目 ID |
| page_number | Integer | 页码 |
| template_id | UUID | 关联模板 ID |
| panel_ids | JSON | 页面内的 Panel ID 列表（有序） |
| page_width | Integer | 页面宽度 |
| page_height | Integer | 页面高度 |
| created_at | DateTime | 创建时间 |
| updated_at | DateTime | 更新时间 |

## 第92章 长图预览

### 92.1 功能概述

长图预览模块提供整话漫画的连续滚动预览功能，将一话中的所有页面按阅读顺序拼接为连续的长图，用户可以通过滚轮或拖拽流畅浏览。预览支持缩放控制、点击放大查看细节，并在预览中标有页码和 Panel 编号，方便用户定位和审阅。

**输入：**
- 一话内所有页面的图片数据

**输出：**
- 长图滚动预览界面

### 92.2 功能点

#### 92.2.1 整话长图滚动预览

**功能描述：**
- 将一话的所有页面垂直拼接为连续长图
- 页面之间以分隔线或间距区分
- 支持鼠标滚轮滚动浏览
- 支持触屏设备的触摸滚动
- 滚动流畅，长图性能优化（虚拟滚动/分片加载）
- 支持跳转到指定页码

**操作流程：**
1. 进入长图预览模式
2. 所有页面从上到下连续加载
3. 使用鼠标滚轮或触摸板平滑滚动
4. 滚动时顶部进度条显示当前浏览位置
5. 点击页码导航可直接跳转到目标页面
6. 页面之间的分隔带可点击（"上一页"/"下一页"按钮）
7. 按 Home 键回到顶部，按 End 键跳到底部

**界面要求：**
- 长图容器：全宽居中显示，最大宽度限制（1200px）
- 页面分隔：页面之间 20px 灰色间隔 + 页码标识
- 滚动进度条：页面右侧或顶部的竖直线性进度条
- 页码跳转：进度条上的页码标记点，点击跳转
- 加载状态：图片懒加载，未加载区域显示淡灰色占位
- 性能优化：离屏区域自动卸载，保持内存占用稳定
- 滚动速度：默认平滑滚动（CSS scroll-behavior: smooth）

#### 92.2.2 缩放控制

**功能描述：**
- 支持缩放预览视图（50%-200%）
- 缩放方式：鼠标滚轮缩放 + 按钮缩放
- 缩放以鼠标位置为中心点
- 缩放级别显示在状态栏
- 一键适配宽度 / 适配高度 / 原始尺寸

**操作流程：**
1. 使用鼠标滚轮缩放（Ctrl+滚轮）
2. 或点击缩放工具栏的 +/- 按钮
3. 縮放以鼠标为中心点
4. 缩放级别显示在工具栏中央（如"125%"）
5. 点击"适配宽度"自动调整缩放使页面宽度适应屏幕
6. 点击"原始尺寸"恢复 100% 缩放
7. 缩放变化时画布内容平滑过渡

**界面要求：**
- 缩放工具栏：预览底部或顶部的浮动工具栏
- 缩放按钮组："−" "100%" "+"
- 适配按钮："⊞ 适配宽度"、"⊟ 适配高度"
- 缩放指示：缩放级别以百分比显示（如"150%"）
- 滚轮缩放：Ctrl + 滚轮，以鼠标位置为中心
- 缩放范围限制：最小 50%，最大 200%
- 缩放动画：过渡动画 200ms ease

#### 92.2.3 点击放大查看细节

**功能描述：**
- 点击长图中的任意位置可放大查看细节
- 点击放大后进入局部放大模式
- 放大模式支持拖拽平移查看
- 再次点击或 ESC 退出放大模式
- 放大模式下显示十字线辅助定位

**操作流程：**
1. 在长图中点击任意位置
2. 视图平滑缩放到点击位置（放大到 150% 或 200%）
3. 进入局部放大模式，鼠标变成手型
4. 按住鼠标左键拖拽平移查看周围区域
5. 再次点击或按 ESC 退出放大模式
6. 视图平滑缩回到之前的缩放级别
7. 支持连续放大（点击 → 放大 → 再次点击 → 进一步放大）

**界面要求：**
- 点击放大动画：平滑缩放到点击位置（300ms 过渡）
- 放大模式光标：手型光标（grab）
- 拖拽平移：按住拖拽时变为抓取光标（grabbing）
- 退出按钮：画面角落的"✕ 退出放大"按钮
- 快捷键：ESC 退出放大模式
- 放大级别指示：底部显示当前放大倍率

#### 92.2.4 标注页码和 Panel 号

**功能描述：**
- 在预览长图中标注每个页面的页码
- 在页面内标注每个 Panel 的编号
- 页码和 Panel 号以水印样式叠加在图片上
- 标注样式可配置显示/隐藏
- 标注导出时可以选择是否包含标注

**操作流程：**
1. 进入长图预览，默认显示页码标注
2. 页码显示在每个页面的左上角或右上角
3. Panel 编号显示在每个 Panel 的右上角
4. 点击"显示标注"按钮切换标注的显隐
5. 标注始终浮在图片之上
6. 导出时可选择"包含标注"或"不包含标注"

**界面要求：**
- 页码标注：页面左上角的半透明黑色背景 + 白色字体
  - 格式："— Page 1 —"
  - 字体大小：14px
  - 透明度：80%
  - 位置固定，不随滚动变化
- Panel 编号标注：每个 Panel 右上角的小号编号
  - 格式："#1" "#2"
  - 字体大小：11px
  - 圆角背景标签样式
- 标注切换按钮：预览工具栏的"🏷 标注"开关按钮
- 标注导出选项：导出设置中的"包含标注"复选框
- 标注样式：标注不遮挡关键画面内容

### 92.3 数据模型

| chapter_id | UUID | 关联章节 ID |
