## 第122章 名词解释

### 122.1 功能概述

名词解释章节汇集了 AI Webtoon Factory 项目中使用的所有专业术语，提供中英文对照和详细的定义说明，帮助读者统一理解项目文档中的概念。

### 122.2 通用术语

| 术语（中文） | 术语（英文） | 定义说明 |
|-------------|-------------|---------|
| 项目 | Project | 用户创建的漫画制作单元，包含从小说导入到导出的完整数据 |
| 小说 | Novel | 原始文本内容，作为漫画改编的源材料 |
| 章节 | Chapter | 小说的自然划分单位，用于组织故事内容 |
| 场景 | Scene | 在同一时间和地点发生的连续事件单元 |
| 画格 | Panel | 漫画中的单个画面，是漫画的最小视觉单元 |
| 页面 | Page | Webtoon 中的一页，由多个 Panel 组成 |
| 镜头 | Shot | 从特定角度和距离拍摄的画面，类似于电影中的镜头 |
| 气泡 | Bubble / Speech Bubble | 漫画中承载角色对白或旁白的文字容器 |
| 对白 | Dialogue | 角色之间说话的内容 |
| 旁白 | Narration | 叙述者的文字解说 |
| 内心独白 | Thinking / Inner Monologue | 角色内心的想法 |
| 拟声词 | Onomatopoeia / SFX | 模拟声音的文字表达 |
| 分镜 | Storyboard | 规划镜头构图、景别和运镜的蓝图 |
| 版式 | Layout | Panel 在页面中的排列布局方式 |
| Prompt | Prompt | 向 AI 模型输入的描述性文本，用于引导生成结果 |

### 122.3 项目核心术语

| 术语（中文） | 术语（英文） | 定义说明 |
|-------------|-------------|---------|
| 人物 IP | Character IP | 角色在漫画中的完整设定，包括外观、服装、表情、姿势等 |
| 六视图 | Six Views | 角色从 6 个角度（正面、侧面、背面、3/4、俯视、仰视）的设定图 |
| 人物关系图 | Relationship Sheet | 展示角色之间关系的图表 |
| 人物尺寸图 | Scale Sheet | 展示角色相对大小和比例的图表 |
| 语义切句 | Semantic Split | AI 将小说文本按语义划分为最小场景单元的过程 |
| 节奏 | Beat | 漫画中控制读者阅读节奏的时间单位 |
| Webtoon 模板 | Webtoon Template | 预定义的页面布局和样式模板 |
| 候选图 | Candidate Image | AI 生图时产生的多张备选图片 |
| Prompt 模板 | Prompt Template | 定义了 Prompt 框架和变量的可复用模板 |

### 122.4 技术术语

| 术语（中文） | 术语（英文） | 定义说明 |
|-------------|-------------|---------|
| 大语言模型 | LLM (Large Language Model) | 用于理解和生成文本的 AI 模型，如 GPT-4 |
| 生图模型 | Image Generation Model | 用于根据 Prompt 生成图片的 AI 模型，如 SDXL |
| 采样步数 | Sampling Steps | AI 生图时从噪声到清晰图像的迭代步数 |
| CFG Scale | Classifier-Free Guidance Scale | 控制生成结果与 Prompt 关联程度的参数 |
| 种子 | Seed | 用于控制随机数生成的数值，相同种子可复现相同结果 |
| 一致性检测 | Consistency Check | AI 检测同一角色或场景在不同 Panel 中是否一致的自动化过程 |
| 工程包 | Project Package (.awfproj) | 可导入/导出的项目数据打包格式 |
| 项目包 | Project Archive (.awfarchive) | 包含完整数据和版本历史的项目归档格式 |
| 插件 | Plugin | 可独立安装的功能扩展模块 |
| 工作流 | Workflow | 由多个节点组成的自动化处理流程 |

### 122.5 角色术语

| 术语 | 定义 |
|------|------|
| 创作者（Creator） | 使用系统制作 Webtoon 的主要用户 |
| 审核员（Reviewer） | 负责质量检查的辅助角色 |
| 管理员（Admin） | 管理系统配置和用户权限的管理角色 |

### 122.6 文件格式术语

| 格式 | 全称 | 说明 |
|------|------|------|
| PNG | Portable Network Graphics | 无损压缩的图片格式，支持透明背景 |
| JPG / JPEG | Joint Photographic Experts Group | 有损压缩的图片格式，文件体积小 |
| WebP | Web Picture Format | Google 开发的现代图片格式 |
| PSD | Photoshop Document | Adobe Photoshop 的原生文件格式 |
| SVG | Scalable Vector Graphics | 可缩放的矢量图形格式 |
| CSV | Comma-Separated Values | 逗号分隔的表格数据格式 |

## 第126章 版本规划

### 126.1 功能概述

版本规划章节定义了系统的版本号规范、各版本的发布时间规划以及向后兼容策略，为开发和发布提供标准化指导。

### 126.2 版本号规范

#### 规范标准

系统版本号遵循语义化版本规范（Semantic Versioning）：`主版本号.次版本号.补丁号`

| 版本段 | 说明 | 变更条件 |
|--------|------|---------|
| 主版本号（X） | 重大架构变更或不兼容的 API 修改 | 1 → 2 → 3 |
| 次版本号（Y） | 向下兼容的新功能发布 | 0 → 1 → 2 |
| 补丁号（Z） | 向下兼容的 Bug 修复 | 0 → 1 → 2 |

#### 版本格式

完整的版本号格式：`v{X}.{Y}.{Z}`

示例：
- `v1.0.0`：第一个正式发布版本
- `v1.1.0`：在 v1.0.0 基础上增加新功能
- `v1.1.1`：在 v1.1.0 基础上修复 Bug
- `v2.0.0`：重大架构变更

#### 版本标签

| 标签 | 说明 | 使用场景 |
|------|------|---------|
| 无标签 | 正式版（Release） | 公开发布的稳定版本 |
| -alpha.N | 内测版 | 内部测试，功能不完整 |
| -beta.N | 公测版 | 公开测试，功能基本完整 |
| -rc.N | 候选发布版 | 最终测试，通过后即为正式版 |

示例：
- `v1.0.0-alpha.1`：第一次内测
- `v1.2.0-beta.2`：第二次公测
- `v1.2.0-rc.1`：第一个候选发布版

### 126.4 向后兼容策略

#### API 兼容性

| 兼容级别 | 说明 | 保证范围 |
|---------|------|---------|
| 完全兼容 | 次版本/补丁版本升级不影响已有 API | 请求/响应格式不变 |
| 扩展兼容 | 新增参数/字段不影响已有调用 | 新增可选参数 |
| 不兼容变更 | 主版本升级时的 API 变更 | 需发布迁移指南 |

#### 数据兼容性

| 数据类型 | 兼容策略 |
|---------|---------|
| 项目数据 | 次版本内保持完全兼容，主版本升级时提供迁移工具 |
| 工程包 | 前向兼容（新版本可导入旧版本工程包） |
| 项目包 | 前向兼容，附版本迁移说明 |
| 配置数据 | 保持兼容，新增配置项有默认值 |

#### 数据库迁移

| 迁移类型 | 策略 |
|---------|------|
| 小版本升级 | 自动迁移，无需用户干预 |
| 大版本升级 | 提供迁移脚本，支持回滚 |
| 数据格式变更 | 使用数据版本号管理，渐进式迁移 |

#### 弃用策略

| 阶段 | 说明 | 示例 |
|------|------|------|
| 弃用公告 | 弃用前至少一个次版本周期 | v1.1.0 公告弃用 v1.0 的某 API |
| 弃用期 | 弃用后至少一个次版本周期内仍可用 | v1.2.0 仍支持但标记弃用 |
| 移除 | 下一个主版本移除 | v2.0.0 移除弃用的 API |
