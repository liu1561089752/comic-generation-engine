# 第二篇 工作台

## 第8章 Dashboard（首页工作台）

### 8.1 功能概述

Dashboard 是用户登录系统后看到的第一个页面，承担"工作台"的核心定位——让用户快速了解全局状态、快捷进入最近项目、关注待处理事项，并通过快速开始向导引导新用户上手。

### 8.2 项目总览仪表盘

#### 功能描述

在 Dashboard 顶部区域展示当前用户所有项目的宏观统计数据，以卡片化布局呈现关键指标。

**统计指标：**

| 指标 | 说明 | 示例 |
|------|------|------|
| 总项目数 | 用户创建的所有项目总数（不含已归档） | 12 |
| 进行中的项目 | 状态为"制作中"的项目数 | 3 |
| 本月完成章节数 | 本月累计完成的章节数量 | 18 |
| 待审核图片数 | 等待人工审核的图片总数 | 47 |
| 总生图数 | 累计生成的图片总数 | 1,284 |

#### 界面要求

- 顶部通栏布局，5 个指标卡片横向排列（视窗 < 1200px 时自动换行，2-3 列）
- 每个卡片包含：图标（彩色）、数值（大号加粗字体）、标签（灰色小字）
- 数值变化时伴有微动效（数字递增动画）
- 支持点击跳转至相关页面（如"待审核图片数"→ 质量控制中心）
- 卡片支持自定义隐藏/显示（通过设置面板）

### 8.3 最近项目快捷入口

#### 功能描述

在 Dashboard 中部展示用户最近操作过的 6 个项目列表，点击即可直接进入项目详情页。

#### 操作流程

1. 系统自动按"最近更新时间"降序排列项目
2. 每个项目卡片展示：项目封面缩略图、项目名称、项目类型、最后更新时间、完成度百分比
3. 点击项目卡片 → 跳转到该项目详情页
4. 点击"查看全部项目" → 跳转到项目管理页

#### 界面要求

- 网格布局展示项目卡片（3 列 × 2 行）
- 项目封面缩略图尺寸 240×160px，圆角 8px
- 项目名称单行显示，超出省略
- 完成度以进度条形式展示，颜色随百分比变化（<30% 红、30-70% 橙、>70% 绿）
- 鼠标悬停时卡片轻微上浮阴影效果
- 无项目时显示"创建一个新项目"引导按钮

### 8.4 生产进度概览

#### 功能描述

以可视化图表展示当前活跃项目的生产完成度，帮助用户快速了解项目整体处于哪个阶段。

**进度阶段拆解（百分比）：**

| 阶段 | 说明 | 占比权重 |
|------|------|---------|
| 小说处理 | 导入、清洗、章节拆分 | 10% |
| 世界观设定 | 场景、道具、风格模板 | 10% |
| 角色设计 | 人物六视图、关系图 | 15% |
| 剧情拆解 | Scene/Panel 切分 | 15% |
| 分镜版式 | 镜头、布局、气泡规划 | 15% |
| Prompt 生成 | 10 层 Prompt 组装 | 10% |
| AI 生图 | 批量生图 + 候选图 | 15% |
| 质量检测 | 一致性检测 + 人工审核 | 5% |
| 编辑导出 | 最终编辑 + 导出 | 5% |

#### 操作流程

1. 默认展示当前打开次数最多的项目
2. 可通过下拉切换其他活跃项目
3. 点击进度条上的某个阶段 → 跳转到该阶段对应的功能页面
4. 每个阶段右侧显示该阶段的通过/失败状态图标

#### 界面要求

- 水平进度条分段显示，每个阶段用不同颜色标识
- 鼠标悬停某个阶段时显示该阶段的详细进度（如"50/120 Panel 已完成"）
- 已完成阶段显示 ✓ 图标，当前阶段高亮闪烁，未开始阶段灰色
- 进度条下方显示整体百分比数值

### 8.5 待处理任务提醒

#### 功能描述

在 Dashboard 右侧边栏（或底部区域）展示当前需要用户关注和处理的任务列表。

**任务类型：**

| 类型 | 说明 | 示例文案 |
|------|------|---------|
| 审核任务 | AI 检测完成，需要人工确认 | "《修仙之王》第 5 章有 12 个 Panel 待审核" |
| 失败任务 | 任务执行失败，需要处理 | "《校园恋爱》角色生成任务失败，点击重试" |
| 配置缺失 | 缺少必要配置 | "《玄幻大陆》尚未导入小说，点击导入" |
| 版本更新 | 系统有可用更新 | "AI Webtoon Factory v1.2 已发布" |

#### 操作流程

1. 系统自动聚合所有未处理的任务，按"优先级 × 创建时间"综合排序
2. 每条任务显示：图标、标题、描述、时间
3. 点击任务 → 跳转至相应的处理页面
4. 点击"忽略"→ 任务移至"已忽略"，不再展示
5. 处理完成后任务自动消失

#### 界面要求

- 列表形式展示，最多显示 10 条
- 超过 10 条时显示"还有 N 条待处理"折叠提示
- 每条任务左侧有类型图标（颜色区分）
- 高优先级任务置顶并以红色标记
- 支持一键"全部标为已读"
- 无任务时显示"一切正常，暂无待处理事项"空状态提示

### 8.6 快速开始向导

#### 功能描述

为新用户提供引导式的新建项目流程，降低首次使用门槛。

#### 向导步骤

| 步骤 | 内容 | 操作 |
|------|------|------|
| 第1步：欢迎 | 展示引导欢迎语和系统简介 | 点击"开始"进入下一步 |
| 第2步：选择模板 | 提供多个预设模板（如"穿越修仙"、"校园恋爱"、"都市悬疑"） | 选择一个模板 |
| 第3步：导入小说 | 上传 TXT/DOCX/Markdown 文件或粘贴文本 | 上传或粘贴 |
| 第4步：开始制作 | 确认信息后进入项目详情页 | 点击"开始制作" |

#### 界面要求

- 仅新用户（无任何项目的用户）首次登录时自动弹出
- 以底部浮层（Drawer）或独立页面的形式呈现
- 每一步都有"上一步/下一步"导航按钮
- 第4步完成后自动创建项目并跳转
- 用户随时可以关闭向导，关闭后不再自动弹出（可在设置中重新打开）
- 已有项目的用户不显示向导，改为在页面右下角显示小浮窗"需要帮助？"

## 第9章 项目管理

### 9.1 项目列表

#### 功能描述

以列表或网格形式展示用户所有项目，支持搜索、筛选和排序，方便用户快速定位目标项目。

#### 操作流程

1. 进入项目管理页面 → 默认展示所有项目列表
2. 支持三种视图切换：**网格视图**（卡片式，默认）、**列表视图**（表格式）、**紧凑视图**（仅显示项目名和状态）
3. **搜索功能**：在搜索框输入关键字 → 实时过滤项目名称和描述
4. **筛选功能**：
   - 按状态筛选：全部 / 制作中 / 已完成 / 已归档
   - 按类型筛选：全部 / 穿越修仙 / 校园恋爱 / 都市悬疑 / 玄幻 / 历史 / 其他
   - 按创建时间筛选：全部 / 今天 / 最近7天 / 最近30天 / 自定义日期范围
5. **排序功能**：按更新时间（默认）/ 创建时间 / 项目名称（字母序）/ 完成度 排序

#### 界面要求

- 页面顶部为搜索框 + 筛选条件行
- 搜索框支持 Enter 确认搜索，也支持输入时实时过滤（300ms 防抖）
- 筛选条件支持多选组合，每个筛选项以 Tag 形式展示，可单独取消
- 网格视图：项目卡片 4 列（视窗自适应），每张卡片含封面图、名称、类型标签、进度条、最后更新时间
- 列表视图：表格列含项目名、类型、状态、完成度、最后更新、操作（进入/复制/归档/删除）
- 紧凑视图：适合项目多的情况，仅显示项目名和状态指示灯
- 支持分页（每页 20 条）或无限滚动
- 无项目时显示"暂无项目，点击创建第一个项目"空状态

### 9.2 项目创建

#### 功能描述

提供项目创建表单，用户可指定项目名称、选择项目类型和初始模板。

#### 操作流程

1. 点击"创建项目"按钮 → 弹出创建对话框/跳转创建页面
2. 填写/选择以下信息：

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| 项目名称 | 文本输入框 | 是 | 最长 50 字 |
| 项目描述 | 文本域 | 否 | 最长 300 字 |
| 项目类型 | 下拉选择 | 是 | 从预设类型中选择 |
| 初始模板 | 模板选择器 | 否 | 选择预置模板可自动填充初始设定 |
| 封面图 | 图片上传 | 否 | 可选，用于项目列表展示 |

3. 点击"确认创建" → 系统创建项目，自动跳转到项目详情页
4. 如果选择了初始模板，系统会一并导入模板中的世界观、角色预设和风格设定

#### 模板选择器界面要求

- 以网格展示可用的模板卡片（封面图 + 模板名 + 简介）
- 选中模板时高亮显示边框
- 鼠标悬停显示"预览"按钮，点击可查看模板的详细内容
- 支持"不使用模板"的选项（创建空白项目）
- 模板支持搜索和按类型筛选

#### 界面要求

- 创建表单以模态对话框（Modal）呈现，宽度 640px
- 支持键盘快捷键：Enter 提交，Esc 取消
- 项目名称做实时重名检测（当前用户范围内），重复时显示警告
- 创建按钮在表单未填完必填项时置灰禁用
- 创建过程若后端处理时间较长（>2s），显示加载状态

### 9.3 项目详情

#### 功能描述

项目详情页是项目的"首页"，展示项目的基本信息、生产进度、成员（角色）和管理入口。

#### 页面布局

| 区域 | 内容 |
|------|------|
| 顶部 | 项目封面大图、项目名称、类型标签、状态标签、操作按钮行 |
| 中部左侧 | 生产进度概览（同 Dashboard 阶段进度条） |
| 中部右侧 | 项目统计（章节数、Panel 总数、图片总数、完成度） |
| 下部 | 快捷操作入口卡片（小说管理 → 角色 → 分镜 → 生图 → 导出） |

#### 操作入口

- **编辑项目**：修改项目名称、描述、封面图
- **进入制作**：按生产流程分步进入下一阶段
  - "导入小说"→ 跳转小说管理
  - "设计角色"→ 跳转人物IP中心
  - "剧情拆解"→ 跳转剧情拆解中心
  - ...依次类推
- **项目设置**：项目级配置（默认模型、分辨率、风格偏好等）
- **进入任务中心**：查看该项目关联的所有任务
- **复制项目**：生成一个项目副本
- **归档/删除**：改变项目状态

#### 界面要求

- 布局清晰，信息层次分明
- 进度概览可点击各阶段跳转
- 快捷操作入口以 3×2 网格排列，每个卡片包含图标、名称、简短描述
- 已完成阶段的操作卡片显示 ✓ 和"已完稿"标记
- 当前阶段卡片高亮且带"继续"按钮
- 未开始阶段卡片灰色

### 9.4 项目删除与归档

#### 功能描述

提供项目的归档和删除功能，帮助用户管理工作空间。

#### 操作流程

**归档流程：**
1. 在项目列表或项目详情页点击"归档"
2. 弹出确认对话框："归档后项目将移至归档列表，可随时恢复"
3. 确认 → 项目状态变为"已归档"
4. 归档项目在默认列表中隐藏，在筛选条件选择"已归档"后显示

**删除流程：**
1. 在项目列表或项目详情页点击"删除"
2. 首次确认："确定要删除《项目名》吗？此操作不可撤销。"
3. 二次确认：输入项目名称以确认删除
4. 确认 → 系统彻底删除项目及所有关联数据

**恢复流程（归档项目）：**
1. 在归档列表中点击目标项目的"恢复"按钮
2. 确认 → 项目状态恢复为"制作中"

#### 界面要求

- 删除操作必须有二次确认机制，防止误操作
- 归档操作仅需一次确认
- 归档项目在列表中置灰显示
- 归档页面与普通项目列表共用同一页面，通过筛选切换
- 删除操作涉及大量数据时需显示删除进度条

### 9.5 项目复制

#### 功能描述

基于已有项目创建一个完全独立的新项目副本，复用所有设定，用于快速开启相似题材的新项目。

#### 操作流程

1. 在项目列表操作栏或项目详情页点击"复制"
2. 弹出复制对话框：
   - **新项目名称**（必填，默认："原项目名 - 副本"）
   - **复制内容选择**：

| 复制选项 | 说明 | 默认 |
|---------|------|------|
| 世界观设定 | 场景、道具、风格模板 | ✓ |
| 角色设定 | 人物 IP、服装、表情、姿势 | ✓ |
| 分镜模板 | 分镜策略模板 | ✓ |
| 版式模板 | Panel 布局模板 | ✓ |
| Prompt 模板 | Prompt 模板库 | ✓ |
| 小说内容 | 源小说及章节数据 | ✗ |
| 图片数据 | 已生成的图片 | ✗ |

3. 点击"确认复制" → 系统创建新项目
4. 复制完成后跳转到新项目详情页
5. 弹出提示："项目已复制，您可以在新项目中修改设定后重新开始制作"

#### 界面要求

- 复制选项以 Checkbox 列表形式展示，每项附带简要说明
- 对于"小说内容"和"图片数据"选项，显示预估数据量（如"约 2.3MB"）
- 复制过程显示进度条（预估耗时取决于数据量）
- 复制完成后发送系统通知
- 项目名重名检测

## 第10章 任务中心

### 10.1 功能概述

任务中心是系统所有异步任务的统一管理界面，涵盖 AI 分析任务、生图任务、一致性检测任务等。用户可在此查看任务状态、跟踪任务进度、手动触发或取消任务。

### 10.2 任务列表

#### 功能描述

以列表形式展示所有任务，支持多维筛选和排序。

#### 任务数据结构

| 字段 | 说明 | 示例值 |
|------|------|--------|
| 任务 ID | 唯一标识 | TSK-2026-0627-001 |
| 任务名称 | 任务描述 | "《修仙之王》第3章 Panel 批量生图" |
| 关联项目 | 所属项目 | 修仙之王 |
| 任务类型 | AI分析 / 生图 / 检测 / 导出 | 生图 |
| 状态 | 排队中/处理中/已完成/失败/已取消 | 处理中 |
| 优先级 | 高/中/低 | 高 |
| 创建时间 | 任务提交时间 | 2026-06-27 10:30:00 |
| 完成时间 | 任务完成时间（如已完成） | 2026-06-27 10:35:22 |
| 进度 | 0-100% | 67% |

#### 操作流程

1. 进入任务中心 → 默认展示最近7天的所有任务
2. **筛选操作**：
   - 按状态筛选：全部 / 排队中 / 处理中 / 已完成 / 失败 / 已取消
   - 按类型筛选：全部 / AI分析 / 生图 / 检测 / 导出
   - 按优先级筛选：全部 / 高 / 中 / 低
   - 按项目筛选：全部项目 / 指定项目
   - 按时间范围筛选：今天 / 最近7天 / 最近30天 / 全部
3. **排序操作**：按创建时间（默认降序）/ 优先级（高→低）/ 状态
4. 点击某条任务 → 展开或跳转到任务详情

#### 界面要求

- 默认以表格列表展示，每行包含：状态指示灯 + 任务名称 + 类型标签 + 关联项目 + 进度条 + 时间 + 操作按钮
- 状态指示灯：排队中（灰点）、处理中（蓝旋转）、已完成（绿✓）、失败（红✗）、已取消（灰—）
- 支持多选，批量操作（批量取消、批量重试）
- 筛选条件组合后数量为 0 时显示"没有符合条件的任务"
- 支持实时刷新（每 5 秒自动轮询更新状态）

### 10.3 任务详情查看

#### 功能描述

展开任务详情，查看任务的完整信息、执行日志和产出结果。

#### 详情内容

| 区域 | 内容 |
|------|------|
| 基本信息 | 任务 ID、名称、类型、状态、优先级、创建/开始/完成时间 |
| 关联信息 | 关联项目、关联章节/Scene/Panel（如有） |
| 执行参数 | 任务执行的参数配置（如生图参数、模型名称等） |
| 执行日志 | 实时输出的日志流 |
| 产出列表 | 任务产出的文件/数据列表（如已生成的图片） |
| 失败信息 | 失败原因、错误堆栈（仅失败任务） |

#### 操作流程

1. 在任务列表点击任务行 → 任务行展开显示详情面板（或跳转到独立详情页）
2. 查看执行日志 → 自动滚动到最新日志行
3. 查看产出 → 点击产出列表中的项 → 在弹窗中预览
4. 点击"复制任务 ID"→ 复制到剪贴板（用于反馈问题）

#### 界面要求

- 展开式详情面板不脱离列表上下文（推荐）
- 执行日志区域固定高度 200px，可滚动，保留最近 500 行
- 日志行每行带时间戳
- 产出列表以缩略图网格展示
- 失败信息红色背景高亮，显示错误码和详细错误信息

### 10.4 任务依赖关系

#### 功能描述

展示任务之间的前后依赖关系，帮助用户理解任务执行顺序和阻塞原因。

#### 依赖类型

| 类型 | 说明 | 示例 |
|------|------|------|
| 前置依赖 | 当前任务依赖的前置任务 | "语义切句"任务完成后才能执行"分镜规划" |
| 后置依赖 | 依赖当前任务的任务 | "分镜规划"完成后才能执行"版式规划" |
| 并行任务 | 可与其他任务并行执行 | "角色生成"和"场景生成"可并行 |

#### 界面要求

- 在任务详情中以有向无环图（DAG）可视化展示依赖关系
- 已完成节点绿色、当前节点蓝色闪烁、未就绪节点灰色、失败节点红色
- 鼠标悬停节点显示任务名称和状态
- 点击节点跳转到对应任务
- 阻塞原因以文字提示（如"等待《...》任务完成"）

### 10.5 手动触发任务

#### 功能描述

支持用户手动触发指定任务的执行，用于跳过自动流程或重新执行某个环节。

#### 操作流程

1. 在任务中心或项目某功能页面中，找到"手动触发"入口
2. 点击手动触发 → 弹出任务创建对话框
3. 选择或确认任务参数：

| 参数 | 说明 | 必填 |
|------|------|------|
| 任务类型 | 选择要执行的任务类型 | 是 |
| 关联范围 | 全部章节 / 指定章节 / 指定 Scene / 指定 Panel | 是 |
| 执行参数 | 模型、参数等运行配置 | 否 |
| 优先级 | 高/中/低 | 否 |

4. 点击"确认执行" → 任务加入队列
5. 跳转到 AI 任务队列页面，查看任务排队情况

#### 界面要求

- 手动触发入口在任务中心页面右上角"手动创建任务"按钮
- 同时在项目内部各功能模块页面也有触发的快捷入口
- 任务参数对话框包含所有必要参数，默认参数基于当前上下文自动填充
- 确认后显示"任务已创建"Toast 提示

### 10.6 取消/重试任务

#### 功能描述

支持用户取消排队中或处理中的任务，以及对失败任务进行重试。

#### 操作流程

**取消任务：**
1. 在任务列表中找到排队中或处理中的任务
2. 点击"取消"按钮（或选择多个任务后点击批量取消）
3. 确认对话框："确定要取消选中的 N 个任务吗？"
4. 确认 → 任务状态变为"已取消"

**重试任务：**
1. 在任务列表中找到状态为"失败"的任务
2. 点击"重试"按钮（或选择多个失败任务后点击批量重试）
3. 可选：修改任务参数（如更换模型、调整参数）
4. 确认 → 新任务加入队列（可复用原任务 ID 或生成新 ID）

#### 界面要求

- 取消按钮仅对"排队中"和"处理中"状态的任务可用
- 重试按钮仅对"失败"状态的任务可用
- 批量操作时显示选中的任务数量
- 取消确认对话框显示任务名称，防止误操作
- 重试时提供"使用原参数"和"修改参数"两个选项

## 第11章 AI 任务队列

### 11.1 功能概述

AI 任务队列是任务中心的"实时视图"，专注于展示 AI 相关任务的实时排队和执行状态。与任务中心不同，队列视图强调实时性和可操作性，适合在生产过程中监控 AI 任务流的用户。

### 11.2 实时队列状态

#### 功能描述

以可视化方式展示 AI 任务队列的实时状态，包括排队中、处理中、已完成和失败四个状态区的动态变化。

#### 状态分区

| 区域 | 展示内容 | 说明 |
|------|---------|------|
| 排队中（Pending） | 等待执行的任务列表 | 按优先级和创建时间排序 |
| 处理中（Running） | 当前正在执行的任务 | 显示实时进度 |
| 已完成（Completed） | 最近完成的 N 个任务 | 自动从队列移除（保留最近 20 条） |
| 失败（Failed） | 执行失败的任务 | 标记红色，需人工处理 |

#### 操作流程

1. 进入 AI 任务队列页面 → 默认四栏分区布局
2. 每个任务卡片在状态变更时自动移动至对应分区（动画过渡）
3. 点击某个队列中的任务 → 查看详情（弹窗或侧边栏）
4. 队列自动刷新（WebSocket 实时推送或每 3 秒轮询）

#### 界面要求

- 四栏看板布局（Kanban 风格），每栏顶部显示当前数量
- 排队中队列按"优先级 × 入队时间"自动排序
- 处理中队列显示当前并行执行的任务（取决于并发设置）
- 已完成队列只显示最近完成的 20 条，自动滚动移除
- 支持拖拽调整排队中任务的顺序（仅高优先级用户）
- 空状态时显示"当前没有排队中的任务"

### 11.3 队列优先级管理

#### 功能描述

支持用户调整任务的优先级，确保关键任务优先执行。

#### 优先级级别

| 级别 | 标签颜色 | 说明 |
|------|---------|------|
| 最高 | 深红 | 紧急任务，始终排在最前 |
| 高 | 橙 | 重要任务，优先执行 |
| 中 | 蓝 | 默认优先级 |
| 低 | 灰 | 非紧急任务，最后执行 |

#### 操作流程

1. 在排队中任务卡片的优先级区域点击 → 弹出优先级选择器
2. 选择新的优先级 → 任务在队列中重新排序
3. 也可在创建任务时直接指定优先级

#### 界面要求

- 优先级以彩色标签显示在任务卡片左上角
- 点击标签可快速切换优先级
- 最高优先级任务有特殊视觉效果（置顶、边框高亮）
- 优先级调整后任务卡片以动画方式移动到新位置

### 11.4 任务进度条

#### 功能描述

为处理中的任务提供精确的进度展示，包括百分比和预计剩余时间。

#### 进度数据类型

| 数据类型 | 说明 | 示例 |
|---------|------|------|
| 百分比 | 当前完成进度 | 67% |
| 已处理量 | 已处理的子任务数 | 8/12 Panel |
| 已用时间 | 任务已执行时间 | 00:03:25 |
| 预计剩余时间 | 基于当前速度的预估 | 约 1 分 45 秒 |
| 当前步骤 | 正在执行的子步骤 | "正在生成第 9/12 个 Panel" |

#### 界面要求

- 进度条：渐变蓝色填充，宽度百分比实时更新
- 进度条右侧显示百分比数字
- 进度条下方显示当前步骤的文字描述
- 任务卡片底部显示已用时间和预计剩余时间
- 预计剩余时间随实际执行速度动态调整
- 当任务接近完成（>90%）时，进度条颜色渐变为绿色

### 11.5 失败任务详情与重试

#### 功能描述

查看失败任务的详细错误信息，并提供智能重试能力。

#### 失败信息展示

| 信息项 | 说明 |
|--------|------|
| 错误码 | 系统定义的有意义错误码，如 E1001（模型超时）、E2003（参数错误） |
| 错误信息 | 人类可读的错误描述 |
| 错误详情 | 技术层面的详细错误信息（可选展开） |
| 失败步骤 | 任务执行到哪一步失败的 |
| 失败时间 | 任务失败的时间戳 |
| 重试次数 | 该任务已自动重试的次数 |

#### 操作流程

1. 在失败队列中点击任务卡片 → 右侧展开详情面板
2. 查看错误信息和错误码
3. 提供"智能建议"：系统根据错误类型推荐解决方案
   - 模型超时 → "建议降低分辨率或切换到轻量模型"
   - 参数错误 → "建议检查 Prompt 参数"
   - 服务不可用 → "模型服务可能暂时不可用，建议稍后重试"
4. 点击"重试"→ 任务重新入队
5. 点击"修改后重试"→ 弹出参数编辑界面，修改后重试

#### 界面要求

- 失败任务卡片红色标记，醒目
- 错误信息折叠展示，默认显示错误码和简要信息
- 智能建议以蓝色提示框展示
- 重试按钮带有 3 秒倒计时防误触（可选）

### 11.6 批量任务取消

#### 功能描述

支持一次性取消多个排队中和处理中的任务。

#### 操作流程

1. 在排队中或处理中队列上方点击"批量选择"按钮
2. 勾选需要取消的任务（支持全选/反选）
3. 点击"取消选中任务"按钮
4. 确认对话框："确定要取消选中的 N 个任务吗？取消后关联数据可能不完整。"
5. 确认 → 所有选中任务状态变为"已取消"

#### 界面要求

- 批量选择模式下每个任务卡片左侧显示 Checkbox
- 顶部显示已选数量（"已选择 5 个任务"）
- 全选 Checkbox 在顶部栏
- 取消确认对话框显示选中的任务数量及任务名称列表
- 批量取消进度以 Toast 通知（"正在取消... 已取消 3/5"）

## 第12章 通知中心

通知中心是系统所有通知的汇集地，涵盖任务完成通知、失败告警、审核提醒和系统公告。用户可查看和管理所有通知，并自定义通知偏好。

#### 界面要求

- 通知铃铛图标：有未读时显示红点 + 未读数量

- 未读通知背景浅蓝，已读通知背景白色
- 通知按时间降序排列
- 通知中心完整页面支持分页展示所有历史通知

### 12.3 审核通知

#### 功能描述

当 AI 一致性检测发现问题或人工审核有结果时，系统向用户发送审核相关通知。

#### 审核通知类型

| 类型 | 触发条件 | 示例文案 |

## 第13章 全局搜索

### 13.1 功能概述

全局搜索提供跨模块的统一搜索能力，用户可在一处搜索所有类型的数据，包括小说、角色、场景、Panel 等。全局搜索是提升操作效率的核心功能。

### 13.2 跨模块搜索

#### 功能描述

支持同时搜索系统中所有主要数据模块，按相关性排序返回结果。

#### 搜索范围

| 模块 | 搜索内容 | 示例 |
|------|---------|------|
| 项目 | 项目名称、描述 | "修仙之王" |
| 小说 | 小说标题、章节名、段落内容 | "第5章 宗门大比" |
| 角色 | 角色名称、描述、特征 | "剑仙 李明" |
| 场景 | 场景名称、描述 | "青云宗大殿" |
| 道具 | 道具名称、描述 | "飞剑" |
| Panel | Panel 编号、关联原文内容 | "Panel-0032" |
| 任务 | 任务名称、任务 ID | "TSK-2026-0627-001" |

#### 操作流程

1. 触发搜索：点击搜索图标（🔍）或使用快捷键 Ctrl+K（Mac: Cmd+K）
2. 在搜索框输入关键词 → 系统实时返回结果（300ms 防抖延迟）
3. 结果按"模块分类 + 相关性得分"排列
4. 使用 ↑/↓ 键在结果中导航
5. 按 Enter → 跳转到选中结果
6. 按 Esc → 关闭搜索面板

#### 界面要求

- 搜索面板以全屏模态层（Modal）或顶部覆盖层形式打开
- 搜索框自动获得焦点
- 输入框内显示搜索提示文案（如"搜索项目、小说、角色、场景..."）
- 搜索结果按模块分组，每组显示前 5 条，点击"查看更多"展开全部
- 每个搜索结果项显示：标题、所属模块标签、所属项目、关键上下文摘要
- 搜索关键词在结果中高亮标记
- 搜索结果为空时显示"未找到相关结果"
- 支持拼音搜索（如输入"xiuzhen"可搜索到"修仙"相关内容）

### 13.3 搜索结果分类展示

#### 功能描述

搜索结果按模块分类展示，每个类别有独立的标签和计数。

#### 分类展示格式

```
搜索 "剑仙" 的结果（共 47 条）

角色（12）
  ├── 剑仙 李明 · 修仙之王

场景（5）

  └── ... 更多

小说（8）
  ├── 第3章 "剑仙重现" · 修仙之王
```

#### 界面要求

- 每个分类有独立的折叠/展开开关
- 分类标题显示该分类的结果数量
- 每个结果项显示足够的上下文信息以帮助判断相关性
- 不同分类使用不同颜色的标签图标
- 点击分类标题 → 在对应模块内搜索该关键词

### 13.4 快捷键支持

#### 功能描述

支持通过快捷键快速调用全局搜索，以及快捷键导航浏览搜索结果。

#### 快捷键列表

| 快捷键 | 功能 |
|--------|------|
| Ctrl+K（Mac: Cmd+K） | 打开全局搜索 |
| Esc | 关闭全局搜索 |
| ↑/↓ | 在搜索结果中上下导航 |

| Ctrl+Enter | 在当前模块内搜索（不跳出上下文） |

#### 操作流程

1. 按下 Ctrl+K → 搜索面板打开，搜索框获得焦点
2. 输入关键词 → 实时搜索
3. 使用 ↑/↓ 选择结果
4. 按 Enter 打开
5. 按 Esc 关闭

#### 界面要求

- 搜索框内显示当前快捷键提示（"Ctrl+K 打开搜索"）
- 快捷键仅在焦点不在输入框时生效
- 快捷键可通过"用户设置"自定义
- 支持键盘导航时的视觉高亮反馈

### 13.5 最近搜索记录

#### 功能描述

自动记录用户的搜索历史，方便快速重复搜索。

#### 操作流程

1. 打开全局搜索面板（搜索框为空时）→ 显示最近搜索记录
2. 最近搜索记录默认显示最近 10 条
3. 点击某条历史 → 自动填入搜索框并执行搜索
4. 点击历史记录右侧的"✕"→ 删除单条记录
5. 点击底部"清除全部"→ 清空所有搜索记录

#### 界面要求

- 搜索记录以列表形式展示在搜索框下方
- 每条记录显示：搜索关键词 + 搜索时间（如"3 分钟前"）
- 搜索记录按时间降序排列
- 搜索记录仅在用户登录状态下保存
- 搜索记录保存在浏览器本地存储（LocalStorage）和服务器端双备份
- 搜索记录保留最近 100 条
- 无搜索历史时显示"暂无搜索记录"空状态

### 13.6 高级搜索（进阶功能）

#### 功能描述

支持高级搜索语法，实现精确搜索和条件组合。

#### 高级搜索语法

| 语法 | 功能 | 示例 |
|------|------|------|
| `keyword` | 基础关键词搜索 | `剑仙` |
| `"exact phrase"` | 精确短语搜索 | `"剑仙从天而降"` |
| `module:type` | 按模块筛选 | `module:角色` 或 `type:Panel` |
| `project:name` | 按项目筛选 | `project:修仙之王` |
| `tag:tag_name` | 按标签筛选 | `tag:主角` |

#### 操作流程

1. 在搜索框输入含语法的搜索词
2. 系统自动识别语法并实时过滤结果
3. 也可以在搜索面板左侧打开高级搜索面板，通过表单构建搜索条件

#### 界面要求

- 高级搜索语法输入时，搜索框下方显示语法提示
- 输入 `module:` 后自动弹出模块选择下拉
- 搜索结果顶部显示当前搜索条件标签（如"模块:角色 × 项目:修仙之王"）
- 点击条件标签可移除该条件
- 高级搜索面板（表单模式）在主搜索面板左侧滑出
