## 第71章 生图任务管理

### 71.1 功能概述

生图任务管理是 AI 生图中心的调度中枢，负责所有图片生成任务的创建、排队、调度和状态追踪。系统将每个 Panel 的生图请求封装为独立任务，通过任务队列管理并发和优先级，确保生图资源高效利用。用户可通过任务管理中心查看所有生图任务的状态、进度和耗时，并对任务进行取消、重新排队等操作。

**输入：**
- 选定的 Panel ID 列表
- Prompt 版本 ID（来自 Prompt 中心）
- 生图模型参数配置（模型、宽高、步数、CFG Scale、Seed 等）

**输出：**
- 任务状态更新（排队中/进行中/已完成/失败/已取消）
- 生成的候选图片集合

### 71.2 功能点

#### 71.2.1 任务创建

**功能描述：**
- 支持从单图生成、批量生成等多种入口创建生图任务
- 创建任务时需选择：目标 Panel、使用的 Prompt 版本、生图模型及参数
- 任务创建成功后自动加入任务队列
- 系统自动为每个任务分配唯一任务 ID
- 任务记录创建时的完整上下文（Panel 信息、Prompt 快照、参数快照）

**操作流程：**
1. 用户在单图生成页或批量生成页中，选择目标 Panel 和 Prompt 版本
2. 配置生图模型和参数（宽高、步数、CFG Scale、Seed 等）
3. 点击"提交生图"按钮
4. 系统校验参数完整性（Panel 是否关联有效 Prompt、模型是否可用等）
5. 校验通过后创建生图任务，加入任务队列
6. 页面跳转到任务列表，新任务显示为"排队中"状态
7. 校验失败时弹出错误提示，定位具体问题

**界面要求：**
- 任务提交按钮：生图页面底部或右侧的"提交生图"主按钮（紫色）
- 提交时显示加载状态，防止重复提交
- 校验失败提示：红色 toast 提示 + 字段高亮
- 创建成功后 toast 提示"生图任务已加入队列（任务 ID: xxx）"
- 支持按 Ctrl+Enter 快捷提交

#### 71.2.2 任务列表

**功能描述：**
- 以列表形式集中展示所有生图任务
- 每个任务显示：任务 ID、关联 Panel 编号、状态、进度百分比、耗时、创建时间
- 支持按状态筛选（全部/排队中/进行中/已完成/失败/已取消）
- 支持按创建时间排序（正序/倒序）
- 支持关键词搜索（任务 ID / Panel 编号）
- 列表自动刷新（WebSocket 实时推送状态变更）

**操作流程：**
1. 进入生图任务管理页面，默认展示所有任务（按创建时间倒序）
2. 使用顶部筛选标签切换视图（全部/排队中/进行中/已完成/失败）
3. 查看每个任务的实时状态和进度
4. 点击任务行展开详情，查看任务参数和生成结果
5. 已完成的任务可点击"查看结果"跳转到候选图管理

**界面要求：**
- 任务列表：表格布局，列包含：
  - 状态指示灯（色点 + 状态文字）
  - 任务 ID（可复制）
  - 关联 Panel（显示章节-场景-Panel 编号，可点击跳转）
  - 进度（进度条 + 百分比，仅进行中显示）
  - 耗时（格式化时间，如"32s""2m15s"）
  - 创建时间（格式化时间）
  - 操作按钮
- 状态颜色映射：
  - 排队中：灰色 ⏳
  - 进行中：蓝色 🔄
  - 已完成：绿色 ✅
  - 失败：红色 ❌
  - 已取消：灰色 ⬜
- 筛选标签：横向排列在列表上方
- 自动刷新：页面顶部显示"实时更新中"标识，WebSocket 断连时显示重连按钮
- 空状态：无任务时显示"暂无生图任务，前往单图生成或批量生图创建"
- 任务数量统计：筛选器旁显示"共 X 个任务"

#### 71.2.3 任务优先级控制

**功能描述：**
- 支持对排队中的任务设置优先级（高/中/低）
- 高优先级任务在队列中优先被调度执行
- 优先级可在任务创建时指定，或在排队中动态调整
- 正在进行中的任务不受优先级调整影响
- 同一优先级按 FIFO（先进先出）顺序调度

**操作流程：**
1. 在任务创建时，通过优先级选择器设定任务优先级（默认"中"）
2. 在任务列表中，对排队中的任务点击优先级下拉框调整
3. 调整后任务在队列中的位置实时重排
4. 高优先级任务自动排到所有中等优先级任务之前
5. 用户可在任务列表中看到调整后的排序变化

**界面要求：**
- 优先级选择器：任务创建时的下拉框（高/中/低），带颜色标识
- 任务列表中的优先级列：彩色徽章（高=红色/中=蓝色/低=灰色）
- 优先级调整：排队中任务的优先级列可点击切换
- 队列排序可视化：任务列表默认按"优先级高→低→创建时间早→晚"排序
- 优先级说明提示：hover 优先级徽章时显示"优先级仅在排队中生效"

#### 71.2.4 任务取消/重新排队

**功能描述：**
- 支持取消排队中和进行中的生图任务
- 取消后任务状态变更为"已取消"
- 已取消的任务支持重新加入队列
- 已完成或已失败的任务不支持取消
- 批量操作：支持多选任务批量取消或重新排队

**操作流程：**

**取消任务：**
1. 在任务列表中勾选要取消的任务（支持多选）
2. 点击列表顶部"取消任务"按钮
3. 弹出确认对话框"确认取消 X 个任务？"
4. 确认后任务状态变更为"已取消"
5. 进行中的任务取消后，正在生成的图片作废

**重新排队：**
1. 在任务列表中筛选"已取消"或"失败"状态的任务
2. 点击任务右侧的"重新排队"按钮
3. 可选择是否使用最新的 Prompt 版本和参数配置
4. 确认后创建新的生图任务加入队列

**界面要求：**
- 取消按钮：列表顶部的批量操作栏中的"取消任务"按钮（红色）
- 单任务操作：每行右侧的"取消"图标按钮（仅排队中和进行中显示）
- 重新排队按钮：已取消/失败状态任务的"↻ 重新排队"按钮
- 确认弹窗：显示选中任务数量和 Panel 信息列表
- 批量勾选：表头复选框支持全选/取消全选
- 操作反馈：操作后显示 toast 提示"已取消 X 个任务"或"X 个任务已重新排队"

### 71.3 数据模型

| 字段 | 类型 | 说明 |
|------|------|------|
| task_id | UUID | 任务唯一标识 |
| project_id | UUID | 所属项目 ID |
| panel_id | UUID | 关联 Panel ID |
| prompt_version_id | UUID | 使用的 Prompt 版本 ID |
| model_config | JSON | 模型参数配置快照 |
| priority | Enum | high / medium / low |
| status | Enum | queued / running / completed / failed / cancelled |
| progress | Integer | 进度百分比（0-100） |
| started_at | DateTime | 开始执行时间 |
| completed_at | DateTime | 完成时间 |
| duration_ms | Integer | 总耗时（毫秒） |
| error_message | String | 失败原因（失败时记录） |
| result_image_ids | JSON | 生成结果图片 ID 列表 |
| created_at | DateTime | 创建时间 |

## 第72章 单图生成

### 72.1 功能概述

单图生成模块支持用户针对单个 Panel 执行图片生成操作。用户选择一个 Panel 后，系统展示该 Panel 的完整 Prompt 内容（10 层结构），用户可以灵活调整生图参数，触发 AI 生图并实时查看生成进度。单图生成是批量生成的基础单元，也是 Prompt 测试和参数调优的核心操作场所。

**输入：**
- 选定的单个 Panel ID
- 目标 Prompt 版本及 10 层 Prompt 内容
- 生图参数（宽高、步数、CFG Scale、Seed 等）

**输出：**
- 4-8 张候选图（A/B/C/D，默认 4 张）
- 生成过程进度反馈

### 72.2 功能点

#### 72.2.1 选择一个 Panel 进行生图

**功能描述：**
- 支持从 Panel 列表、分镜中心或版式中心跳转到单图生成
- 选中 Panel 后，自动加载其关联的 Prompt 和参数配置
- 页面展示 Panel 的基本信息：所属章节、场景编号、Panel 编号、构图信息
- 支持通过上下 Panel 导航按钮快速切换

**操作流程：**
1. 进入单图生成页面，默认展示最近编辑的 Panel
2. 也可通过 Panel 选择器（左侧面板或下拉框）选择目标 Panel
3. 选中后系统自动加载该 Panel 的 Prompt 和参数
4. 页面标题更新为"第 X 章 - 场景 Y - Panel Z 单图生成"
5. 可通过"上一个 / 下一个"按钮切换到相邻 Panel
6. 切换时未保存的 Prompt 修改自动保存

**界面要求：**
- Panel 选择器：左侧 Panel 缩略图列表（按章节-场景-面板层级树）
- 当前选中 Panel 高亮显示
- 导航按钮：页面顶部，"← 上一个 Panel"和"下一个 Panel →"
- Panel 信息栏：显示章节号、场景编号、Panel 编号、Panel 尺寸
- 键盘快捷键：← → 方向键切换相邻 Panel
- Panel 缩略图显示在信息栏右侧（如有已生成的图片）

#### 72.2.2 显示当前 Prompt 内容（10 层）

**功能描述：**
- 完整展示当前 Panel 的 10 层 Prompt 结构
- 10 层为：（1）角色描述、（2）场景描述、（3）道具描述、（4）服装描述、（5）表情描述、（6）姿势描述、（7）动作描述、（8）构图描述、（9）镜头描述、（10）画风描述
- 每层可单独展开/折叠查看详细内容
- 支持在生图前对 Prompt 内容进行微调
- 显示当前使用的 Prompt 版本号

**操作流程：**
1. 选择 Panel 后，Prompt 区域自动加载该 Panel 最新版本的 Prompt
2. 10 层结构以折叠面板（Accordion）形式展示
3. 默认全部折叠，点击层标题展开查看详细内容
4. 每层显示：层名称 + 内容预览（前 50 字）+ 折叠/展开箭头
5. 展开后可查看和编辑该层完整内容
6. 页面顶部显示 Prompt 版本号（如"v3"）
7. 点击版本号可切换到其他历史版本

**界面要求：**
- 10 层 Prompt 区域：页面左栏或上方面板，宽度占页面的 50%-60%
- 折叠面板样式：每层一行，左侧为层编号/名称，右侧为内容预览 + 展开按钮
- 展开状态：显示完整文本内容（等宽字体，灰色背景代码块样式）
- 层名称颜色编码：
  - 角色层：蓝色
  - 场景层：绿色
  - 道具层：橙色
  - 服装层：紫色
  - 表情层：粉色
  - 姿势层：青色
  - 动作层：红色
  - 构图层：金色
  - 镜头层：灰色
  - 画风层：深蓝
- 版本号显示：Prompt 区域顶部的标签，点击弹出版本列表
- 编辑模式：展开后内容变为可编辑文本框，带"保存"和"撤销"按钮

#### 72.2.3 生图参数调整

**功能描述：**
- 提供完整的生图参数调整面板
- 参数包括：图片宽高、采样步数、CFG Scale、Seed 值
- 参数有合理范围约束，超出范围自动修正
- 支持参数预设保存和快速加载
- 参数变更时自动计算对生图质量和速度的影响预估

**参数说明：**

| 参数 | 类型 | 默认值 | 范围 | 说明 |
|------|------|--------|------|------|
| 宽度 | 整数 | 1080 | 512-2048 | 图片宽度（像素），需为 64 的倍数 |
| 高度 | 整数 | 1440 | 512-2048 | 图片高度（像素），需为 64 的倍数 |
| 采样步数 | 整数 | 30 | 10-100 | 采样步数，越高越精细但越慢 |
| CFG Scale | 浮点数 | 7.0 | 1.0-20.0 | 提示词相关性，越高越贴近提示词 |
| Seed | 整数 | -1 | -1 ~ 2^32-1 | 随机种子，-1 表示随机 |
| 采样器 | 下拉选择 | Euler a | - | 采样器算法选择 |

**操作流程：**
1. 在参数面板中调整各参数值
2. 宽高：通过数值输入框调整，右侧提供预设比例快捷按钮（1:1、4:3、16:9、Webtoon）
3. 步数：滑块 + 数值输入框
4. CFG Scale：滑块 + 数值输入框
5. Seed：数值输入框 + 骰子图标（随机生成）
6. 采样器：下拉选择框
7. 参数调整后自动计算预估耗时并显示

**界面要求：**
- 参数面板：页面右栏或右侧抽屉面板
- 宽高设置：两个并列输入框（宽 × 高）
- 预设比例按钮：宽高输入框下方的快捷按钮组
- 步数滑块：带刻度标记，显示"低质量/快速"到"高质量/慢速"标签
- CFG 滑块：带刻度标记，显示"自由"到"严格"标签
- Seed: 输入框 + 随机按钮（🎲 图标）
- 参数预设：参数面板顶部的下拉框（"默认"、"高质量"、"快速生成"等）
- 保存预设按钮：参数面板底部的"保存为预设"
- 预估耗时：参数面板底部显示"预估耗时：约 25 秒"

#### 72.2.4 点击生成

**功能描述：**
- 配置完 Prompt 和参数后，点击生成按钮触发 AI 生图
- 生成前进行参数完整性校验
- 生成请求提交到任务队列（第 71 章）
- 支持"仅生成"和"生成并对比"两种模式
- 防止重复提交（按钮置灰 + 倒计时）

**操作流程：**
1. 确认 Prompt 内容和生图参数无误
2. 点击"生成"按钮（或选择"生成并对比"）
3. 系统校验参数完整性，若有缺失项高亮提示
4. 校验通过后创建生图任务，自动跳转到任务进度页面
5. 按钮状态变更为"生成中..."并置灰
6. 生成完成后自动跳转到候选图管理页面
7. 若选择"生成并对比"，则生成后直接进入对比模式

**界面要求：**
- 生成按钮：页面底部或右侧底部的"✨ 生成"大按钮（紫色渐变）
- "生成并对比"按钮：主按钮旁的次要按钮
- 按钮置灰状态：生成中显示"⏳ 生成中..."，不可点击
- 校验失败：字段红色高亮 + 顶部错误提示
- 快捷键：Ctrl+Enter 触发生成
- 生成确认弹窗（可选）：大参数调整后弹出"当前参数有较大变更，确认生成？"

#### 72.2.5 进度显示

**功能描述：**
- 实时显示当前生图任务的进度
- 进度信息包括：排队位置（如有等待）、生成进度百分比、预估剩余时间
- 支持 WebSocket 实时推送进度更新
- 进度页面提供取消当前任务的入口
- 可收起进度面板，继续浏览其他内容

**操作流程：**
1. 提交生成后自动进入进度展示面板
2. 排队中：显示"队列中第 X 位"和预计等待时间
3. 生成中：进度条从 0% 推进到 100%，显示当前步骤描述
4. 每步更新：如"正在生成候选图 2/4"、"采样步骤 15/30"
5. 完成后进度条变为绿色，显示"生成完成"
6. 可点击"最小化"收起进度面板，面板缩小为底部状态条

**界面要求：**
- 进度面板：生成页面中央或右侧的大型卡片
- 排队动画：带有跳动小人的等待动画 + "队列中第 X 位"文字
- 进度条：渐变蓝色进度条，带百分比数字
- 步骤描述：进度条下方的小字，显示当前执行步骤
- 预估剩余时间：进度条右侧的"剩余约 X 秒"
- 取消按钮：进度面板右上角的"✕ 取消"按钮
- 最小化按钮：进度面板右下角的"收起"按钮
- 完成动画：进度条变为绿色 + 勾号 + "✨ 生成完成！"文字
- 查看结果按钮：完成后显示的"查看候选图"按钮

### 72.3 数据模型

| 字段 | 类型 | 说明 |
|------|------|------|
| generation_id | UUID | 生成记录唯一标识 |
| panel_id | UUID | 关联 Panel ID |
| task_id | UUID | 关联任务 ID |
| prompt_snapshot | JSON | 生成时的 Prompt 快照 |
| parameters | JSON | 生图参数快照 |
| result_images | JSON | 生成图片 ID 列表（4-8 张候选图） |
| created_at | DateTime | 创建时间 |

## 第73章 批量生成

### 73.1 功能概述

批量生成模块支持用户同时选择多个 Panel 统一执行生图操作，大幅提高生产效率。用户可通过多选或范围选择批量指定目标 Panel，统一设置生图参数后一键提交批量任务。系统提供批量进度总览面板，实时展示每批次任务的完成情况，并在批量结束后生成汇总展示。

**输入：**
- 多个 Panel ID（支持全选、范围选择、条件筛选）
- 统一的 Prompt 版本和生图参数配置
- 批量并行度设置

**输出：**
- 批量任务队列
- 每个 Panel 的 4-8 张候选图
- 批量生成汇总报告

### 73.2 功能点

#### 73.2.1 多选 Panel 批量生图

**功能描述：**
- 支持多种 Panel 选择方式：
  - 手动逐一点选（带复选框的 Panel 列表）
  - 按章节全选（选中某个章节的所有 Panel）
  - 按场景全选（选中某个场景的所有 Panel）
  - 范围选择（从 Panel A 到 Panel B 之间的所有 Panel）
  - 条件筛选选择（如"所有尚无生成图片的 Panel"）
- 已选 Panel 以列表形式展示，支持移除个别 Panel
- 显示已选数量，避免误操作
- 支持选择所有 Panel（全项目）

**操作流程：**
1. 进入批量生成页面，默认展示当前项目的 Panel 层级树

## 第75章 图片版本管理

### 75.1 功能概述

图片版本管理模块记录每个 Panel 的图片变更历史。每次用户重新生成图片并选择新图时，系统自动将上一版���保存为新版本，形成可追溯的版本链。用户可以在版本列表中浏览所有历史版本，切换当前选中的版本，或删除不需要的版本。版本管理为创作者提供了充分的试错空间和历史回溯能力。

**输入：**
- Panel ID
- 每次选择新候选图时自动触发版本保存

**输出：**
- 按版本号排列的历史版本列表
- 版本切换操作

### 75.2 功能点

#### 75.2.1 每次重新生成保存为新版本

**功能描述：**
- 每次用户从候选图中选择一张图片时，自动创建一个新版本
- 版本命名规则：v1, v2, v3...（按选择顺序递增）
- 每个版本记录完整的生成上下文（Prompt 版本、参数、模型信息）
- 版本创建时自动添加时间戳
- 没有图片的 Panel 无版本信息

**操作流程：**
1. 用户在候选图管理中选择一张图作为最终图片
2. 系统自动检测当前 Panel 是否已有选中图片
3. 若已有图片，当前图片自动转为历史版本（版本号 +1）
4. 新选择的图片成为当前版本（最新版本）
5. 版本记录写入数据库，包含生成上下文快照
6. 用户可在版本管理中查看完整的版本链

**界面要求：**
- 版本创建无感（后台自动完成）
- 版本变化时显示 toast 提示"已保存为 vX 版本"
- 版本号的增长对所有 Panel 独立计算

#### 75.2.2 版本号（v1, v2, v3...）

**功能描述：**
- 每个 Panel 的版本号独立递增
- 版本号格式：v + 数字（如 v1、v2、v3）
- 版本号按创建时间递增，不可手动修改
- 删除中间版本不影响其他版本的编号
- 版本号在版本列表和图片引用中作为唯一标识

**操作流程：**
1. 首次选择图片时版本号为 v1
2. 再次选择新图时版本号变为 v2，v1 保留在历史中
3. 如果在 v3 版本删除了 v2，版本列表为 v1、v3
4. 选择新图后版本号变为 v4
5. 版本号始终递增，不会复用已删除的编号

**界面要求：**
- 版本号以徽章形式展示（如"v3"）
- 当前版本号高亮显示
- 版本号在候选图管理、编辑器等多处同步显示

#### 75.2.3 版本缩略图列表

**功能描述：**
- 以缩略图列表形式展示某 Panel 的所有历史版本
- 缩略图按版本号倒序排列（最新在前）
- 每个版本项显示：版本号、缩略图、创建时间、是否为当前版本
- 悬停缩略图显示版本信息浮层
- 点击缩略图可进行版本切换

**操作流程：**
1. 进入版本管理页面，默认展示当前 Panel 的版本列表
2. 版本以水平滚动缩略图列表展示
3. 当前版本以高亮边框标记
4. 鼠标悬停某版本缩略图，弹出浮层显示版本号、时间和参数摘要
5. 点击某版本缩略图执行版本切换
6. 在缩略图上点击"删除"按钮删除版本

**界面要求：**
- 缩略图列表：水平横向滚动，超出屏幕显示滚动箭头
- 每个版本项：约 150×200px 的竖版卡片
- 卡片内容：上方为图片缩略图，下方为版本号 + 时间
- 当前版本：金色边框 + 右上角"当前"标记
- 悬浮效果：卡片悬停上移 4px，带阴影
- 滚动箭头：列表左右两侧的半透明箭头按钮
- 缩略图裁切：保持宽高比，居中裁切
- 空版本状态："暂无历史版本"

#### 75.2.4 版本切换

**功能描述：**
- 切换到历史版本时，该版本成为 Panel 的当前选中图片
- 切换操作会保留切换前的版本状态（不删除）
- 版本切换后可立即在编辑器中看到效果
- 版本切换记录计入操作日志
- 支持批量切换（多 Panel 统一切换版本）

**操作流程：**
1. 在版本列表中点击目标版本的缩略图
2. 弹出确认弹窗"切换到 vX 版本？当前版本将保留为 vY"
3. 确认后目标版本成为当前版本
4. 页面中 Panel 的图片更新为新选择的版本
5. 版本列表中高亮标记移动到新的当前版本
6. 若切换前当前版本有未保存的编辑，提示保存

**界面要求：**
- 切换确认弹窗：显示切换前的版本和切换后的版本缩略图对比
- 弹窗信息："从 vX 切换到 vY" + 两个版本的生成时间
- 切换中显示加载动画（图片替换中...）
- 切换成功后 toast 提示"已切换到 vX 版本"
- 切换失败时显示错误提示（图片加载失败等）

#### 75.2.5 版本删除

**功能描述：**
- 支持删除不需要的历史版本
- 当前版本不可删除（需先切换到其他版本）
- 删除后版本从版本列表中移除
- 删除操作支持撤销（回收站机制，保留 7 天）
- 批量删除支持

**操作流程：**
1. 在版本列表中点击目标版本缩略图上的"删除"图标
2. 弹出删除确认弹窗
3. 弹窗提示：版本号、缩略图、创建时间
4. 确认后版本标记为"已删除"，从版本列表中消失
5. 删除后 toast 提示"已删除 vX 版本" + "撤销"按钮
6. 点击"撤销"可恢复被删除的版本（7 天内）
7. 不可删除当前版本（删除按钮置灰并提示"请先切换版本"）

**界面要求：**
- 删除按钮：版本缩略图右上角的"✕"图标（红色，悬停显示）
- 删除确认弹窗：居中模态，宽度约 400px
- 弹窗显示版本信息摘要 + 警告文字"删除后可在 7 天内撤销"
- 当前版本删除按钮置灰，hover 提示"当前版本不可删除"
- 批量删除：版本列表顶部的"管理"模式切换，勾选多个版本后批量删除
- 撤销按钮：toast 中的"撤销"链接，点击后恢复版本
- 删除动画：版本卡片缩小消失动画

## 第76章 图片历史记录

### 76.1 功能概述

图片历史记录模块提供 Panel 级别的完整操作日志记录和追溯能力。系统记录每个 Panel 每一次生图操作的全链路信息，包括：触发时间、使用的 Prompt 和参数、生成的候选图、最终选择结果等。用户可在此查看 Panel 的生图演变过程，并支持将历史图片重新选为当前版本。

**输入：**
- Panel ID
- 每次生图操作的事件数据

**输出：**
- 结构化的历史操作日志
- 历史图片重新选中操作

### 76.2 功能点

#### 76.2.1 完整操作日志

**功能描述：**
- 记录某个 Panel 的每一次生图操作事件
- 每个事件记录：操作时间、操作类型、操作结果摘要
- 事件类型包括：生图提交、候选图生成、图片选择、版本切换、版本删除
- 日志按时间倒序排列（最新在前）
- 日志支持筛选（按操作类型、按时间范围）

**操作流程：**
1. 进入图片历史记录页面，选择目标 Panel
2. 默认展示该 Panel 的完整操作日志（时间线视图）
3. 每条日志显示：时间戳 + 事件类型 + 事件描述
4. 点击日志条目展开查看详情
5. 使用顶部筛选器按类型或时间范围过滤
6. 支持导出日志

**界面要求：**
- 时间线视图：垂直时间线布局，左侧为时间轴，右侧为事件卡片
- 时间轴：垂直线 + 每个事件的时间点圆点
- 事件卡片：从左向右排列，包含：
  - 事件类型图标（🎨 生图 / ✅ 选择 / 🔄 切换 / 🗑️ 删除）
  - 事件描述（摘要文字）
  - 时间戳（格式：2026-06-27 14:30:25）
  - 展开按钮（▶ 展开详情）
- 展开详情：显示该事件的完整参数信息
- 筛选器：日志顶部的下拉筛选（全部/生图/选择/切换/删除）+ 时间范围选择器
- 日志计数：顶部显示"共 X 条操作记录"
- 导出日志按钮：页面右上角的"📥 导出日志"按钮

#### 76.2.2 Prompt、参数、模型信息记录

**功能描述：**
- 每次操作日志详细记录该次的 Prompt 内容、生图参数和模型信息
- Prompt 记录：10 层结构、版本号、是否手动修改过
- 参数记录：宽高、步数、CFG Scale、Seed、采样器等
- 模型记录：模型名称、模型版本、模型提供方
- 信息以结构化格式展示，支持复制

**操作流程：**
1. 展开某条日志条目
2. 日志详情面板展示三个 Tab：「Prompt 信息」「参数信息」「模型信息」
3. 「Prompt 信息」Tab：展示 10 层 Prompt 结构
4. 「参数信息」Tab：以表格形式展示所有参数
5. 「模型信息」Tab：展示模型名称、版本、调用参数
6. 每个 Tab 都有"复制"按钮
7. 信息不可编辑（纯记录用途）

**界面要求：**
- 详情面板：日志展开后的下方区域
- Tab 切换：三个 Tab 标签页
- 「Prompt 信息」Tab：折叠式 10 层结构，与第 72 章相同样式
- 「参数信息」Tab：两列表格（参数名 | 参数值）
- 「模型信息」Tab：信息卡片布局
- 复制按钮：每个 Tab 右上角的"📋 复制"按钮
- 复制后 toast 提示"已复制"

#### 76.2.3 历史图片可重新选为当前版本

**功能描述：**
- 支持在历史记录中将任意历史版本图片重新设为当前版本
- 重新选择后，自动创建一个新版本（版本号 +1）
- 操作记录中新增一条"历史版本重选"记录
- 可批量将多个 Panel 的历史图片重新选为当前版本

**操作流程：**
1. 在操作日志中找到目标历史版本条目
2. 点击条目上的"重新选为此图"按钮
3. 弹出确认弹窗："将历史版本 vX 的图片重新设为当前版本？"
4. 确认后系统创建一个新版本（vN+1），内容为历史图片
5. 新版本成为当前版本
6. 原当前版本自动转入历史版本链
7. 日志中新增一条"历史重选"记录

**界面要求：**
- "重新选为此图"按钮：历史版本缩略图或日志条目中的链接按钮
- 确认弹窗：显示历史版本缩略图 + 版本号 + 创建时间
- 弹窗提示："这将创建一个新版本（vN+1），使用此历史图片"
- 操作成功后 toast 提示"已创建 vN+1 版本（历史重选）"
- 批量重选：在历史列表中选择多个版本后批量操作
- 版本链展示：在版本管理中看到此次操作的版本继承关系

### 76.3 数据模型

| 字段 | 类型 | 说明 |
|------|------|------|
| log_id | UUID | 日志唯一标识 |
| panel_id | UUID | 关联 Panel ID |
| event_type | Enum | generation / selection / version_switch / version_delete / history_restore |
| description | String | 事件描述文本 |
| prompt_snapshot | JSON | Prompt 快照 |
| parameter_snapshot | JSON | 参数快照 |
| model_snapshot | JSON | 模型信息快照 |
| affected_version_ids | JSON | 影响的版本 ID 列表 |
| created_at | DateTime | 事件发生时间 |
