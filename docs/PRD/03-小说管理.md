# 第三篇 小说管理

---

## 第14章 小说导入

### 14.1 功能概述

小说导入是 AI Webtoon Factory 生产管线的起点。用户将原始小说文件（TXT、DOCX、Markdown）上传至系统，经过编码检测和格式验证后，存入项目的小说库中，供后续预处理和分析流程使用。

### 14.2 支持的文件格式

| 格式 | 扩展名 | 说明 |
|------|--------|------|
| 纯文本 | .txt | 无格式文本，需自动检测编码 |
| Word 文档 | .docx | 支持段落样式、标题层级识别 |
| Markdown | .md | 支持标题（#）、段落分隔等标记 |

### 14.3 功能点

#### 14.3.1 拖拽上传 + 文件选择器

**功能描述：**
- 页面提供拖拽区域，用户可将本地文件直接拖入
- 同时提供"选择文件"按钮，通过系统文件选择器选取文件
- 支持单个文件上传和批量文件上传
- 文件拖入时高亮显示拖拽区域边框

**操作流程：**
1. 用户进入小说导入页面
2. 从本地拖拽文件到拖拽区域，或点击"选择文件"按钮
3. 系统验证文件格式和大小
4. 验证通过后自动开始上传
5. 上传完成后显示导入成功提示

**界面要求：**
- 拖拽区域：居中放置，约 400×250px，虚线边框，中间显示云上传图标 + "拖拽文件到此处或点击上传"提示文字
- 文件类型限制提示：小字显示"支持 TXT、DOCX、Markdown 格式"
- 拖入文件时边框变为实线并变色（如蓝色高亮）
- 文件选择器支持多选

#### 14.3.2 上传进度显示

**功能描述：**
- 文件上传过程中实时显示上传进度
- 支持多个文件同时上传时分别显示进度
- 上传完成后显示成功状态

**操作流程：**
1. 文件开始上传后，文件列表项显示进度条
2. 进度条根据上传百分比实时更新
3. 上传完成后进度条变为绿色完成状态
4. 上传失败显示红色错误状态及错误原因

**界面要求：**
- 进度条：横向条状，蓝色渐变填充，右侧显示百分比数字
- 文件列表：每个文件一行，显示文件名、文件大小、上传状态图标
- 状态图标：上传中（旋转箭头）、成功（绿色勾）、失败（红色感叹号）
- 失败时鼠标悬停显示具体错误信息

#### 14.3.3 编码自动检测

**功能描述：**
- TXT 文件上传时自动检测文件编码
- 支持常见编码格式检测：UTF-8（含 BOM）、UTF-16、GBK/GB2312、GB18030、Big5、Shift-JIS、Latin-1 等
- 检测结果在界面上显示
- 允许用户手动指定编码并重新加载预览

**操作流程：**
1. 文件上传完成后，后端自动执行编码检测
2. 检测结果显示在文件列表的编码列
3. 若检测结果不准确，用户可手动选择编码
4. 选择新编码后立即重新渲染预览内容

**界面要求：**
- 编码列：显示自动检测到的编码名称
- 编码选择器：下拉列表，列出常见编码供用户切换
- 切换编码后预览区域即时更新

#### 14.3.4 文件大小限制提示

**功能描述：**
- 设定单文件大小上限（默认 50MB）
- 超过限制时明确提示用户
- 在拖拽区域和文件选择器中提前告知限制

**操作流程：**
1. 用户拖入或选择文件时，系统验证文件大小
2. 若超过限制，弹出提示"文件大小超过 50MB 限制，请拆分后上传"
3. 超过限制的文件不会进入上传队列

**界面要求：**
- 拖拽区域底部显示"单文件不超过 50MB"的提示文字
- 超过限制时在文件列表项中显示红色警告

### 14.4 数据模型

| 字段 | 类型 | 说明 |
|------|------|------|
| file_id | UUID | 文件唯一标识 |
| project_id | UUID | 所属项目 ID |
| original_name | String | 原始文件名 |
| file_path | String | 服务器存储路径 |
| file_size | Integer | 文件大小（字节） |
| file_format | Enum | txt / docx / md |
| encoding | String | 检测到的编码 |
| upload_status | Enum | uploading / completed / failed |
| created_at | DateTime | 上传时间 |

## 第15章 小说预处理

### 15.1 功能概述

小说预处理模块对已导入的原始小说文件进行自动化清洗、章节拆分和段落编号，为后续的剧情分析和编辑器提供结构化、标准化的数据基础。预处理完成后需经用户确认方可生效。

### 15.2 功能点

#### 15.2.1 自动清洗

**功能描述：**
- 删除多余空行（连续空行合并为最多一个）
- 删除首尾空白字符
- 统一标点符号（如将英文引号 `""` 转为中文引号 `「」` 或 `""`）
- 全角半角转换（数字、字母统一为半角，中文标点统一为全角）
- 删除不可见控制字符
- 可选：删除注释行（如 `<!-- ... -->` 格式）

**操作流程：**
1. 用户选择已导入的小说文件，点击"开始预处理"
2. 系统自动执行清洗规则
3. 清洗完成后显示清洗前后对比
4. 用户可开关每项清洗规则以预览不同效果
5. 确认清洗结果后进入下一步

**界面要求：**
- 清洗规则列表：每项规则带开关切换，右侧显示该规则处理的数据量（如"已删除 23 个多余空行"）
- 对比视图：左右分栏或上下分栏，左侧为原文，右侧为清洗后文本
- 差异高亮：清洗前后有差异的部分用颜色高亮标记（新增绿色、删除红色）
- "全部应用" 按钮一键确认所有规则

#### 15.2.2 章节拆分（AI 自动识别章节边界）

**功能描述：**
- AI 自动识别小说的章节边界
- 识别规则包括：`第X章`、`Chapter X`、`第X话`、`第X节` 等常见章节标题格式
- 支持阿拉伯数字和中文数字（如 `第一章`、`第 1 章`）
- 对于无明确章节标记的小说，AI 根据语义分段（场景切换、时间跳转等）
- 返回每个章节的起始行号和标题

**操作流程：**
1. 清洗完成后，用户点击"开始章节拆分"
2. 后端调用 LLM 执行章节边界识别
3. 拆分结果展示在预览列表中
4. 用户可人工调整拆分结果（合并/分割/重命名）
5. 确认无误后提交

**界面要求：**
- 拆分结果列表：每行显示章序号、章节标题、起止段落范围、段落数
- 预览区：选中某章节时，在下方预览区显示该章节内容
- 合并操作：拖拽章节卡片到另一章节上触发合并
- 分割操作：在内容预览区选中分割点，点击"在此分割"
- 进度指示：AI 分析进行中显示加载动画

#### 15.2.3 段落编号

**功能描述：**
- 对清洗和拆分后的段落进行统一编号
- 编号格式为 4 位数字：0001、0002、0003……
- 编号在章节内连续，跨章节不连续（每章从头开始）
- 段落编号为只读 ID，不可修改，作为后续引用原文的唯一标识

**操作流程：**
1. 确认章节拆分结果后，系统自动执行段落编号
2. 编号结果在内容预览区显示
3. 用户仅可查看，不可编辑编号

**界面要求：**
- 编号显示在段落文本左侧，灰色小字，右对齐
- 编号区域宽度固定（约 50px）
- 编号与段落文本之间有分割线或间距

#### 15.2.4 预处理结果预览

**功能描述：**
- 综合展示清洗、拆分、编号后的完整结果
- 以树形结构展示：小说 → 章节 → 段落
- 支持展开/折叠章节
- 支持搜索特定段落（按编号或关键词）

**操作流程：**
1. 所有预处理步骤完成后，进入结果预览页
2. 默认折叠所有章节，仅显示章节标题和统计信息
3. 点击章节可展开查看该章节所有段落
4. 可在顶部搜索框搜索关键词，定位到对应段落

**界面要求：**
- 树形结构：左侧缩进层级，带有展开/折叠图标
- 章节行：显示章序号、标题、段落数统计
- 段落行：显示段落编号 + 段落文本（最多显示 3 行，超出截断）
- 搜索结果高亮标记匹配文本

#### 15.2.5 人工确认/调整拆分结果

**功能描述：**
- 用户可在预览阶段对 AI 的拆分结果进行调整
- 支持的操作：合并章节、分割章节、重命名章节、删除空章节
- 调整后系统自动重新编号受影响的章节段落
- 确认提交后，预处理结果正式写入数据库

**操作流程：**
1. 在预览页面查看 AI 拆分结果
2. 对不满意的拆分进行操作：
   - 合并章节：将两个相邻章节合并
   - 分割章节：指定段落位置分割章节
   - 重命名：双击章节标题进行编辑
   - 删除：删除空内容章节
3. 每次调整后系统自动刷新预览
4. 点击"确认提交"完成预处理

**界面要求：**
- 章节行右侧操作按钮：编辑（铅笔图标）、删除（垃圾桶图标）、更多（省略号下拉菜单）
- 合并：拖拽模式下目标章节高亮
- 分割：在预览区右键菜单选择"在此分割章节"
- 提交前二次确认弹窗："确认后将生成正式章节数据，是否继续？"

### 15.3 数据模型

| 字段 | 类型 | 说明 |
|------|------|------|
| chapter_id | UUID | 章节唯一标识 |
| novel_id | UUID | 所属小说 ID |
| chapter_number | Integer | 章序号 |
| title | String | 章节标题 |
| paragraph_count | Integer | 段落数 |
| status | Enum | draft / confirmed |
| sort_order | Integer | 排序权重 |
| created_at | DateTime | 创建时间 |

| 字段 | 类型 | 说明 |
|------|------|------|
| paragraph_id | UUID | 段落唯一标识 |
| chapter_id | UUID | 所属章节 ID |
| paragraph_number | String | 段落编号（0001 格式） |
| content | Text | 段落文本内容 |
| annotation_type | Enum | unmarked / dialogue / narration / action / description |
| sort_order | Integer | 在章节内的排序 |
| created_at | DateTime | 创建时间 |

## 第16章 小说编辑器

### 16.1 功能概述

小说编辑器提供纯文本编辑环境，用户可在不操作原文段落 ID 的前提下对小说内容进行修改。同时支持段落标注、注释和版本历史追溯，是后续剧情分析和 AI 处理前的人工编辑调整入口。

### 16.2 功能点

#### 16.2.1 纯文本编辑

**功能描述：**
- 用户可编辑段落文本内容
- 编辑操作不影响段落编号（ID 保持只读）
- 支持添加、删除段落
- 支持文本格式化（加粗、斜体，存储为 Markdown）
- 自动保存编辑内容（实时或定时）

**操作流程：**
1. 进入小说编辑器，默认按章节展示所有段落
2. 点击段落文本区域进入编辑模式
3. 编辑完成后点击保存或失去焦点自动保存
4. 新增段落：在段落之间点击"+"按钮插入新段落
5. 删除段落：右键菜单选择"删除段落"或按删除键
6. 所有编辑记录进入版本历史

**界面要求：**
- 段落编号显示在左侧，灰色不可编辑
- 段落文本区域为可编辑文本框，边框在聚焦时显示
- 新增段落按钮：段落之间显示 + 按钮，鼠标悬停时浮现
- 自动保存指示器：右上角显示"已保存"或"保存中..."
- 段落编号不因增删段落而改变（新增段落编号标记为 0001a、0001b 等）

#### 16.2.2 段落标注

**功能描述：**
- 用户可对每个段落标注类型
- 标注类型：对话（Dialogue）、旁白（Narration）、动作（Action）、描述（Description）
- 标注结果作为后续 AI 分析和分镜规划的输入参考
- 支持批量标注多个段落

**操作流程：**
1. 选中一个或多个段落
2. 在段落上方的标注工具栏选择类型
3. 标注后段落左侧显示对应类型图标/颜色标记
4. 点击已标注段落可修改标注类型
5. 支持按标注类型筛选显示段落

**界面要求：**
- 标注工具栏：浮动在选中段落上方或固定在编辑器顶部
- 类型色彩映射：
  - 对话（Dialogue）：蓝色
  - 旁白（Narration）：紫色
  - 动作（Action）：橙色
  - 描述（Description）：绿色
- 段落左侧色条：宽度 3px 竖条，颜色对应标注类型
- 筛选功能：顶部过滤按钮，点击后只显示指定类型的段落

#### 16.2.3 注释功能

**功能描述：**
- 用户可在段落上添加注释
- 注释用于标记需要特别注意的段落（如重要剧情点、需 AI 特殊处理等）
- 注释内容为纯文本，支持富文本
- 注释会被传递到后续的 AI 分析流程作为参考

**操作流程：**
1. 右键点击段落，选择"添加注释"
2. 在弹窗中输入注释内容
3. 保存后段落右上角显示注释标记（气泡图标）
4. 鼠标悬停在注释标记上显示注释内容预览
5. 点击注释标记可编辑或删除注释

**界面要求：**
- 注释标记：段落右上角小气泡图标（带数字表示注释数量）
- 注释弹窗：居中弹窗，输入框可输入多行文本
- 注释预览：tooltip 悬浮显示前 100 字注释内容
- 已注释段落底部显示淡黄色背景

#### 16.2.4 版本历史

**功能描述：**
- 每次编辑操作均记录版本快照
- 支持查看任意历史版本的差异对比
- 支持回退到历史版本
- 版本按时间倒序排列

**操作流程：**
1. 点击"版本历史"按钮打开版本列表侧边栏
2. 列表按时间倒序显示所有版本（版本号 + 时间戳 + 修改摘要）
3. 点击任一版本，主编辑区切换为该版本内容（只读模式）
4. 点击"对比当前"显示当前版本与历史版本的差异
5. 点击"恢复此版本"将当前内容回退到该历史版本

**界面要求：**
- 版本列表侧边栏：右侧滑出，宽度 320px
- 版本条目：版本号（V1、V2...）、时间、修改摘要
- 差异对比：分左右两栏（历史版/当前版），差异行高亮（新增绿色、删除红色）
- 恢复操作二次确认弹窗
- 当前版本显示"当前"标记

### 16.3 数据模型

| 字段 | 类型 | 说明 |
|------|------|------|
| version_id | UUID | 版本唯一标识 |
| novel_id | UUID | 所属小说 ID |
| version_number | Integer | 版本号 |
| content_snapshot | JSON | 全量内容快照 |
| change_summary | String | 修改摘要（AI 自动生成/用户手动输入） |
| created_by | UUID | 操作用户 ID |
| created_at | DateTime | 创建时间 |

## 第17章 小说章节管理

### 17.1 功能概述

小说章节管理模块提供对预处理后章节的集中管理功能，包括列表查看、排序、重命名、删除、拆分与合并等操作，是后续剧情分析和 AI 处理的数据结构基础。

### 17.2 功能点

#### 17.2.1 章节列表

**功能描述：**
- 以列表形式展示小说所有章节
- 显示信息：序号、标题、段落数、标注统计、状态
- 支持按状态筛选和关键词搜索
- 列表支持分页（章节较多时）

**操作流程：**
1. 进入章节管理页面，默认显示完整章节列表
2. 可搜索章节标题快速定位
3. 可筛选"未标注""已确认""问题"等状态的章节
4. 点击章节行进入该章节的编辑器

**界面要求：**
- 表格/列表布局，每行包含：
  - 序号（左侧拖拽手柄图标）
  - 章节标题（可点击进入编辑）
  - 段落数（数字徽章）
  - 标注统计（各类型段落数量的微型柱状图或百分比条）
  - 状态标签（草稿/已确认/处理中）
  - 操作按钮（编辑、更多）
- 搜索框位于列表上方
- 筛选标签页位于搜索框下方

#### 17.2.2 章节排序（拖拽调整）

**功能描述：**
- 用户通过拖拽调整章节顺序
- 拖拽后章节序号自动重新排列
- 段落编号保持不变（仅章节顺序变动）

**操作流程：**
1. 点击章节行左侧的拖拽手柄
2. 拖拽章节到目标位置（目标位置显示插入指示线）
3. 释放鼠标完成排序
4. 系统自动更新章节序号

**界面要求：**
- 拖拽手柄：章节行左侧六点图标（⋮⋮）
- 拖拽中：原位置显示占位灰块，跟随鼠标显示半透明卡片
- 插入指示线：目标位置显示蓝色横线
- 排序完成后显示"章节顺序已更新"提示

#### 17.2.3 章节重命名

**功能描述：**
- 用户可修改章节标题
- 重命名不会影响章节内的段落数据和标注

**操作流程：**
1. 点击章节行的编辑按钮或双击标题
2. 标题变为可编辑输入框
3. 输入新标题后按 Enter 确认或点击外部取消
4. 重命名成功后刷新列表显示

**界面要求：**
- 编辑模式：标题文本变为输入框，边框显示
- 输入框初始选中标题全部文字，方便直接替换
- 标题长度限制 100 字符
- 快捷键 Enter 保存，Esc 取消

#### 17.2.4 章节删除与拆分合并

**功能描述：**
- 删除：删除指定章节（含所有段落数据），需二次确认
- 拆分：将一个章节拆分为两个章节（指定拆分位置）
- 合并：将两个相邻章节合并为一个章节
- 删除章节后的段落编号不会重新分配（保持唯一性）

**操作流程：**

**删除：**
1. 点击章节行的"删除"按钮
2. 弹出确认对话框："删除后章节内所有段落将不可恢复，是否继续？"
3. 确认后删除章节及关联数据

**拆分：**
1. 选中目标章节，点击"拆分"按钮
2. 选择要拆分的段落位置
3. 输入新章节标题
4. 确认后原章节被拆分为两个

**合并：**
1. 选中需要合并的一个章节
2. 点击"合并到上一章"或"合并到下一章"
3. 也可拖拽章节到相邻章节实现合并
4. 合并后段落保持原有编号，章节标题沿用第一个章节

**界面要求：**
- 删除确认弹窗：红色警告样式，"确认删除"按钮为红色
- 拆分界面：在当前章节内容上方显示分割线拖拽手柄
- 合并操作需有二次确认弹窗
- 所有操作均有撤销提示（"操作已撤销"按钮，5 秒内有效）

## 第18章 剧情分析

### 18.1 功能概述

剧情分析模块利用 AI 对小说章节进行自动化剧情理解与分析，提取关键事件、识别剧情转折点、生成剧情摘要。分析结果将作为后续 Scene 提取和分镜规划的重要参考。用户可对 AI 分析结果进行人工修正。

### 18.2 功能点

#### 18.2.1 AI 自动分析章节剧情要点

**功能描述：**
- 对每个章节进行深入分析，识别核心剧情要素
- 分析维度包括：章节核心主题、主要冲突、人物动机、情感基调
- 输出结构化分析结果（JSON 格式）
- 分析结果关联到对应章节

**操作流程：**
1. 用户选择目标章节（支持多选），点击"开始剧情分析"
2. 系统调用 LLM 对章节内容进行逐章分析
3. 分析完成后以结构化卡片形式展示结果
4. 用户可以逐条查看和编辑分析结果

**界面要求：**
- 分析进度：多章分析时显示总进度（如"第 3/12 章分析中"）
- 分析结果卡片：每章一张卡片，显示章节标题 + 核心分析点
- 分析点标签化：核心主题、主要冲突等以标签形式展示
- 可折叠/展开分析详情

#### 18.2.2 提取关键事件

**功能描述：**
- AI 从章节中自动提取关键事件
- 每个事件包含：事件名称、涉及人物、发生时间（与时间线关联）、事件描述
- 事件按时间顺序排列
- 每个事件可关联到具体段落

**操作流程：**
1. 剧情分析完成后，默认展示关键事件列表
2. 事件按章节分组展示
3. 点击事件展开详情（含关联段落引用）
4. 用户可添加、编辑、删除事件
5. 事件可标记重要性（主要/次要/背景）

**界面要求：**
- 事件列表：时间轴样式或卡片列表
- 事件卡片：标题 + 涉及人物头像 + 简短描述
- 关联段落：事件卡片下方显示段落编号引用，点击跳转到编辑器对应位置
- 重要性标记：主要事件用星标（⭐），次要事件不标记
- 新增事件按钮在列表底部或章节分组标题旁

#### 18.2.3 识别剧情转折点

**功能描述：**
- AI 自动识别剧情中的转折点（情节突然变化、冲突升级、重大发现等）
- 转折点标记所在段落位置
- 对每个转折点进行分类：冲突爆发、真相揭露、关系转变、场景切换等
- 生成剧情发展曲线图

**操作流程：**
1. AI 分析完成后在剧情时间轴上标记转折点
2. 转折点以特殊图标显示在事件列表中
3. 点击转折点显示详细分类和说明
4. 用户可调整转折点的位置或删除/新增

**界面要求：**
- 剧情曲线图：以折线图或阶梯图展示剧情发展起伏
- X 轴：段落/章节进度，Y 轴：剧情张力/情绪强度
- 转折点在曲线图上以标记点显示，颜色区分类型
- 选中转折点时对应段落内容在预览区显示
- 用户可拖拽调整转折点的位置

#### 18.2.4 生成剧情摘要

**功能描述：**
- AI 为每章生成 100-300 字的剧情摘要
- 支持生成全篇总摘要（所有章节概要汇总）
- 摘要格式包括：叙事摘要 + 关键事件清单
- 摘要结果可导出为文本

**操作流程：**
1. 剧情分析完成后，自动生成章节摘要
2. 摘要显示在章节分析卡片的顶部
3. 用户可编辑摘要文本
4. 点击"生成总摘要"合并所有章节摘要
5. 总摘要支持导出为 TXT 或 Markdown

**界面要求：**
- 摘要区域：每章卡片顶部，带有淡黄色背景区分
- 编辑模式：点击摘要文本进入编辑，实时保存
- 总摘要：独立页面或弹窗展示，左侧为章节列表，右侧为完整总摘要
- 导出按钮位于总摘要页面的右上角

#### 18.2.5 人工修改 AI 分析结果

**功能描述：**
- 用户可对 AI 分析的所有结果进行编辑
- 支持新增、修改、删除事件、转折点、摘要
- 修改后的内容标记为"人工编辑"状态
- 支持重新分析（覆盖人工修改）

**操作流程：**
1. 点击分析结果中的编辑按钮
2. 修改内容后自动保存或点击保存按钮
3. 修改后的条目显示"已编辑"标记
4. 如需重新 AI 分析，点击"重新分析"，弹窗提示"将覆盖所有人工修改，是否继续？"

**界面要求：**
- 编辑按钮：每个可编辑字段旁显示铅笔图标
- "已编辑"标记：修改后的条目右上角显示小字"已编辑"
- 重新分析按钮在页面顶部，带确认弹窗
- 修改历史可在操作日志中查看

|------|------|------|

| chapter_id | UUID | 所属章节 ID |
| analysis_type | Enum | plot / event / turning_point / summary |
| content | JSON | 分析结果内容 |
| is_ai_generated | Boolean | 是否为 AI 生成 |

## 第20章 人物分析

### 20.1 功能概述

人物分析模块利用 AI 自动从小说中提取所有出现的人物，识别其基本信息、出场章节和重要性，并给出创建为 IP 角色的建议。分析结果是后续人物 IP 中心的数据基础，也是确保角色一致性的前提。

### 20.2 功能点

#### 20.2.1 AI 自动提取所有人物

**功能描述：**
- AI 通读小说，提取所有有名字的人物（含昵称、称号、别名）
- 识别同一人物的不同称呼并智能归并（如"张三""张先生""三哥"视为同一人）
- 区分主要人物和背景人物（只有称呼无独立对话的 NPC）
- 支持手动添加 AI 遗漏的人物

**操作流程：**
1. 用户点击"开始人物分析"
2. 后端调用 LLM 进行全篇人物提取
3. 提取结果以人物列表展示
4. 相同人物的不同称呼自动归并，在列表中显示"曾用名/别名"
5. 用户可手动添加未识别的人物

**界面要求：**
- 人物列表：头像占位 + 姓名（大号） + 角色类型标签 + 出现章节数
- 角色类型标签：主角🔴 / 重要配角🟠 / 一般配角🟡 / 背景人物⚪
- 别名显示在姓名下方，灰色小字
- 添加人物：列表底部的"添加人物"按钮，弹窗填写姓名和基本信息
- 批量导入识别结果后，显示"AI 识别到 X 个人物"的汇总提示

#### 20.2.2 人物基本信息

**功能描述：**
- AI 提取每个角色的基本信息
- 基本信息项：姓名、别名、年龄、性别、身份/职业、性格特征、外貌描述
- 信息来源标注对应的原文段落
- 用户可编辑所有基本信息字段

**操作流程：**
1. 点击人物列表中的某个人物，进入人物详情
2. 详情页展示 AI 提取的所有基本信息
3. 每项信息右侧标注来源段落编号
4. 用户点击编辑按钮可修改任意字段
5. 未识别到的字段留空，用户可自行补充

**界面要求：**
- 人物详情页：分左（头像区）右（信息区）两栏
- 信息区按字段排列：姓名、别名、年龄、性别、身份、性格、外貌
- 每个字段显示标签 + 内容 + 来源段落链接
- 来源段落链接以数字编号形式显示，点击跳转到编辑器
- 编辑模式：字段变为输入框，底部有"保存"和"取消"按钮

#### 20.2.3 人物出场章节标记

**功能描述：**
- 标记每个人物首次出场的章节
- 列出人物在每章中出现的具体段落
- 生成人物出场时间线（按章节分布）
- 统计人物在每章的出现频次

**操作流程：**
1. 在人物详情页中查看"出场章节"标签页
2. 默认按章节顺序展示出场记录
3. 每章显示该人物出现的段落数
4. 展开章节可查看具体段落编号列表
5. 点击段落编号跳转到编辑器

**界面要求：**
- 出场章节列表：章节名 + 频次徽章（如"第1章 · 12次"）
- 展开/折叠：点击章节行展开段落编号列表
- 出场时间线：以水平条状图展示各章节出场次数
- 时间线中首次出场用特殊颜色标记

#### 20.2.4 人物重要性评级

**功能描述：**
- AI 根据人物的出场频次、对话量、剧情影响度进行自动评级
- 评级等级：S（核心主角）/ A（主要角色）/ B（重要配角）/ C（一般配角）/ D（背景人物）
- 评级结果以星级或等级标签展示
- 用户可手动调整评级

**操作流程：**
1. AI 分析完成后，每个人物显示评级标签
2. 评级依据自动计算：出场次数 × 权重 + 对话段落数 × 权重 + 被其他角色提及次数 × 权重
3. 用户点击评级标签，下拉选择新的评级
4. 手动调整后标记为"人工评级"

**界面要求：**
- 评级标签：S（金色⭐）/ A（绿色）/ B（蓝色）/ C（灰色）/ D（浅灰）
- 评级依据弹窗：点击"详情"显示评级计算公式和各项数值
- 人工调整后的评级标签显示"手动"标记
- 按评级筛选：人物列表顶部提供按评级过滤的选项

#### 20.2.5 建议创建为 IP 角色的提示

**功能描述：**
- 对评级为 S 级和 A 级的人物，系统自动提示创建为 IP 角色
- IP 角色信息可从人物分析自动填充
- 用户一键创建 IP 角色，跳转到人物 IP 中心进行详细设计
- 已创建的 IP 角色在列表中显示关联状态

**操作流程：**
1. 在人物列表中，S/A 级人物旁显示"创建 IP 角色"按钮
2. 点击按钮，弹窗显示即将创建的角色信息预览
3. 确认后自动创建 IP 角色，信息同步到人物 IP 中心
4. 创建后按钮变为"已创建"状态，点击跳转 IP 角色详情
5. 支持批量创建（选中多个 S/A 级人物，一次操作全部创建）

**界面要求：**

- 创建预览弹窗：显示人物名称、基本信息摘要、来源小说

## 第21章 地点分析

### 21.1 功能概述

地点分析模块利用 AI 自动从小说中提取所有故事发生的地点，进行分类、频次统计和场景关联，为后续的场景资产库建设和分镜背景规划提供数据支持。

### 21.2 功能点

#### 21.2.1 AI 自动提取故事中所有地点

**功能描述：**
- AI 通读小说全文，提取所有涉及的地点名称
- 识别同一地点的不同叫法并归并（如"王府""王爷府""王府大院"视为同一地点）
- 区分主要场景地点和仅被提及的地点
- 提取地点的描述信息（环境、氛围、特征等）

**操作流程：**
1. 用户点击"开始地点分析"
2. 后端调用 LLM 进行全篇地点提取
3. 提取结果以地点列表展示
4. 归并后的地点显示别名信息
5. 用户可手动添加 AI 遗漏的地点

**界面要求：**
- 地点列表：卡片网格或列表布局，显示地点名称 + 分类标签 + 出现次数
- 别名显示在地点名称下方，灰色小字
- 列表可按分类、出现频次排序
- 顶部搜索框支持按地点名称搜索

#### 21.2.2 地点分类

**功能描述：**
- 对每个地点进行分类
- 一级分类：室内 / 室外 / 虚构 / 现实
- 二级分类细化：如室内→（客厅/卧室/教室/宫殿等），室外→（森林/街道/战场等）
- AI 自动判定分类，用户可手动调整

**操作流程：**
1. AI 分析完成后自动为每个地点分配分类
2. 分类以标签形式显示在地点卡片上
3. 用户点击分类标签可修改分类
4. 支持按分类筛选地点列表

**界面要求：**
- 分类标签：一级分类用底色区分（室内🏠蓝色 / 室外🌳绿色 / 虚构✨紫色 / 现实🌍灰色）
- 二级分类：小字标签显示在一级分类旁
- 筛选栏：分类筛选器位于列表顶部，点击切换
- 分类编辑器：弹窗形式，一级/二级分类均为下拉选择

#### 21.2.3 地点出现频次统计

**功能描述：**
- 统计每个地点在整篇小说中出现的总次数
- 按章节统计地点的出现分布
- 以图表形式展示频次数据
- 标记高频地点（主要场景）

**操作流程：**
1. AI 分析完成后自动生成频次统计
2. 频次数据显示在地点卡片上和详情页中
3. 点击频次数字可查看按章节的分布详情
4. 高频地点自动标记为"主要场景"

**界面要求：**
- 频次展示：地点卡片右侧显示"出现 X 次"数字徽章
- 章节分布：弹窗中以柱状图展示各章节出现次数
- 主要场景标记：频次前 5 的地点卡片加金色边框
- 排序功能：列表支持按频次降序排列

#### 21.2.4 地点关联场景列表

**功能描述：**
- 每个地点关联其在故事中出现的具体场景
- 场景列表包含：关联章节、关联段落、场景描述摘要
- 场景描述可链接到后续的 Scene 管理模块

**操作流程：**
1. 点击地点卡片进入地点详情
2. 详情页中默认显示"关联场景"列表
3. 每个场景项显示：章节名 + 段落编号 + 场景描述摘要
4. 点击场景项跳转到编辑器或 Scene 管理
5. 用户可手动添加或删除场景关联

**界面要求：**
- 场景列表：表格形式，列包含"章节""段落""场景摘要"
- 场景摘要：显示最多 50 字，超出截断加省略号
- 跳转链接：每个场景项右侧有"跳转"按钮
- 新增关联：详情页底部的"添加场景关联"按钮

## 第22章 时间线分析

### 22.1 功能概述

时间线分析模块利用 AI 自动构建故事的时间线结构，识别时间跨度、时间跳跃和事件先后顺序，以可视化方式呈现故事的时间脉络，帮助创作者理解和管理故事的时间结构。

### 22.2 功能点

#### 22.2.1 AI 自动构建故事时间线

**功能描述：**
- AI 通读小说全文，自动提取时间参考信息
- 构建事件与时间的映射关系
- 支持时间格式：具体日期（2023年1月1日）、相对时间（三天后、一年前）、季节时间（春天、冬天）、模糊时间（很久以前、多年后）
- 输出结构化时间线数据，按时间顺序排列事件

**操作流程：**
1. 用户点击"开始时间线分析"
2. 后端调用 LLM 对小说进行时间线分析
3. 分析过程中显示进度
4. 完成后展示完整时间线
5. 用户可调整和补充时间点

**界面要求：**
- 加载分析时显示"正在分析时间结构..."
- 分析完成后自动定位到时间线视图
- 时间线中的每个事件显示事件名 + 时间标记 + 关联段落

#### 22.2.2 时间跨度识别

**功能描述：**
- 识别故事整体时间跨度（如"故事从 2020 年跨越到 2025 年"）
- 识别每个章节的时间跨度
- 统计故事中的有效时间（实际推进的天数/月数
