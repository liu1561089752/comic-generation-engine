# 第十四篇 导出中心

## 第93章 导出漫画

### 93.1 功能概述

导出漫画是将完整的漫画作品输出为可分发、可发布格式的核心出口。系统支持多种导出格式，满足不同平台和用途的需求。用户可选择将整部漫画、单个章节或自定义范围的画格批量导出。

### 93.2 导出为长图

#### 功能描述

将选定的漫画章节或页面序列合并为一张纵向连续的长图，适配 Webtoon 平台的阅读方式。长图的宽度固定为 1080px，高度根据页面数量自动累加（无限高），每页 Panel 按阅读顺序纵向排列。

#### 操作流程

1. 在导出中心选择「导出为长图」功能
2. 选择导出范围：全部 / 指定章节 / 指定 Page 范围
3. 配置长图参数：

| 参数 | 说明 | 默认值 | 可选范围 |
|------|------|--------|---------|
| 宽度 | 长图宽度 | 1080px | 720 / 1080 / 1200 |
| 画格间距 | 相邻 Panel 之间的间隔 | 8px | 0-20px |
| 背景色 | 画格之间的背景颜色 | #FFFFFF | 可自定义 |
| 包含气泡 | 是否包含文字气泡 | 是 | 是/否 |
| 水印 | 是否添加水印 | 否 | 是/否 |

4. 点击「预览长图」→ 系统生成预览（前 10 个 Panel）
5. 确认无误后点击「导出」
6. 系统开始导出任务，进度显示在导出队列中
7. 导出完成后自动下载 PNG 文件

#### 界面要求

- 参数配置区在页面左侧，预览区在右侧
- 预览区支持滚轮滚动查看长图效果
- 预览质量较低（压缩 50%），正式导出为全质量
- 长图底部显示总高度和 Panel 总数
- 支持中断导出（取消按钮）

### 93.3 导出为单页 PNG 序列

#### 功能描述

将漫画的每一页（Page）导出为独立的 PNG 文件，保持 Webtoon 版式的完整布局。导出的 PNG 序列以文件夹形式组织，便于用户逐页使用。

#### 导出组织方式

```
导出文件夹/
├── 修仙之王_第5章/
│   ├── Page-001.png
│   ├── Page-002.png
│   ├── Page-003.png
│   └── ...
├── 修仙之王_第6章/
│   ├── Page-001.png
│   ├── Page-002.png
│   └── ...
└── 修仙之王_第7章/
    ├── Page-001.png
    └── ...
```

#### 操作流程

1. 选择「导出为 PNG 序列」
2. 选择导出范围：全部 / 指定章节 / 指定 Page 范围
3. 配置参数：

| 参数 | 说明 | 默认值 |
|------|------|--------|
| 分辨率 | 图片分辨率 | 1080×1440+（按版式） |
| 颜色模式 | RGB / CMYK | RGB |
| 文件名格式 | 命名规则 | Page-{编号} / {章节}-{编号} |
| 压缩级别 | 0-9（0 无压缩） | 3 |
| 包含元数据 | 是否嵌入元数据 | 否 |

4. 点击「导出」→ 系统按 Page 逐页导出
5. 导出完成后打包为 ZIP 文件下载
6. 或选择「另存为文件夹」直接保存到指定目录

#### 界面要求

- 文件命名规则支持自定义模板，如 `{项目名}_{章}_{Page编号}`
- 压缩级别选择时显示预估文件大小
- 导出进度显示当前处理的 Page 编号
- 支持导出完成后预览前 5 页

### 93.4 导出为 JPG

#### 功能描述

将漫画页面导出为 JPG 格式，以较小的文件体积适用于网络传输和快速分享。用户可调节 JPG 压缩质量以平衡画质和文件大小。

#### 操作流程

1. 选择「导出为 JPG」
2. 选择导出范围：全部 / 指定章节 / 指定 Page
3. 配置 JPG 质量参数：

| 参数 | 说明 | 默认值 | 可选范围 |
|------|------|--------|---------|
| 质量 | JPG 压缩质量 | 90% | 1%-100% |
| 分辨率 | 图片分辨率 | 1080×1440+ | 自定义 |
| 色彩空间 | sRGB / Adobe RGB | sRGB | sRGB / Adobe RGB |
| 缩略图模式 | 是否同时生成缩略图 | 否 | 是/否 |

4. 点击「导出」→ 系统导出并打包下载
5. 质量参数调整时，实时显示预估文件大小和画质等级

#### 界面要求

- 质量滑块拖动时，右侧显示对应质量的预览图对比
- 显示各质量等级的文件大小估算
- 支持批量导出时统计总文件大小

### 93.5 导出进度显示

#### 功能描述

所有导出任务在导出中心统一显示进度，用户可实时查看导出状态、取消或重试任务。

#### 进度显示内容

| 信息 | 说明 |
|------|------|
| 导出任务名称 | 如"《修仙之王》第5章 PNG 导出" |
| 导出格式 | PNG / JPG / 长图 |
| 当前进度 | 如"12/36 Page 完成" |
| 百分比 | 如 33% |
| 已用时间 | 00:01:23 |
| 预计剩余时间 | 约 2 分 45 秒 |
| 文件大小 | 已导出 45MB / 预估总计 120MB |
| 状态 | 处理中 / 已完成 / 失败 / 已取消 |

#### 操作流程

1. 导出任务提交后自动加入导出队列
2. 在导出中心底部（或右侧面板）显示导出进度列表
3. 每个导出任务显示进度条和详细信息
4. 已完成任务显示「下载」按钮
5. 失败任务显示错误原因和「重试」按钮

#### 界面要求

- 导出进度列表最多保留最近 20 条记录
- 超过 20 条时自动清理最早的已完成记录
- 支持清除历史记录
- 导出完成后发送系统通知

## 第94章 导出图片

### 94.1 功能概述

导出图片模块专注于单张或多张图片的独立导出，不依赖漫画页面布局。用户可从项目中的任意位置选择图片进行导出，适用于需要单独使用某张图片的场景。

### 94.2 单张图片导出

#### 功能描述

从编辑器、画廊或图片预览中导出当前查看的单张图片到本地。

#### 操作流程

1. 在图片预览或编辑界面找到「导出」入口
2. 点击「导出当前图片」→ 弹出导出选项

| 选项 | 说明 | 默认 |
|------|------|------|
| 导出格式 | PNG / JPG / WebP | PNG |
| 分辨率 | 原始分辨率 / 自定义缩放 | 原始 |
| 质量 | 仅 JPG/WebP 可用 | 90% |
| 文件名 | 自定义文件名（默认使用图片 ID） | 图片 ID |
| 输出路径 | 选择保存位置 | 浏览选择 |

3. 配置完成后点击「导出」
4. 系统处理后保存到指定路径并在桌面弹出通知

#### 界面要求

- 导出选项在图片查看器上方以工具栏形式展示
- 格式选择时显示各格式优缺点（如"PNG 无损，文件大；JPG 有损，文件小"）
- 支持右键菜单「另存为」

### 94.3 批量图片导出

#### 功能描述

从项目中选择多张图片进行批量导出，适用于需要同时获取多张图片的场景。

#### 操作流程

1. 进入批量导出模式（可从图片资源库或画廊中选择）
2. 选择需要导出的图片（支持多选 / 全选 / 按条件筛选）
3. 点击「批量导出」→ 配置导出参数

| 参数 | 说明 | 默认 |
|------|------|------|
| 导出格式 | PNG / JPG / WebP（支持统一或自动） | PNG |
| 分辨率 | 原始 / 缩放至指定尺寸 | 原始 |
| 质量 | 仅 JPG/WebP | 90% |
| 文件名格式 | 命名规则模板 | {项目名}_{序号} |
| 打包方式 | ZIP 压缩包 / 文件夹 | ZIP |

4. 确认导出数量和总文件大小预估
5. 点击「确认导出」→ 系统开始批量处理
6. 处理完成后下载或打开输出文件夹

#### 界面要求

- 图片选择界面以网格缩略图展示，已选图片有选中标记
- 顶部显示已选数量（如"已选择 15 张图片"）
- 支持按 Panel 编号、生成时间、模型筛选后全选
- 批量处理进度条显示当前处理进度
- 导出完成后自动打开输出文件夹（可选）

### 94.4 导出格式选择

#### 功能描述

在导出图片时提供多种格式选项，每种格式适配不同的使用场景。

#### 格式对比

| 格式 | 适用场景 | 优点 | 缺点 | 透明度支持 |
|------|---------|------|------|-----------|
| PNG | 高质量保存、二次编辑 | 无损、支持透明 | 文件大 | ✓ |
| JPG | 网络分享、快速传输 | 文件小、兼容性好 | 有损压缩 | ✗ |
| WebP | Web 使用 | 文件更小、支持透明 | 兼容性略低 | ✓ |
| BMP | 需要原始数据 | 无压缩 | 文件极大 | ✗ |
| TIFF | 印刷出版 | 高质量、多图层 | 不常用 | ✓ |

#### 操作流程

1. 在导出设置中选择目标格式
2. 格式切换时，系统自动显示该格式特有的参数配置
3. 显示该格式的预估文件大小
4. 可预览不同格式下的画质对比（仅 JPG/WebP 有损格式）

#### 界面要求

- 格式选择以下拉菜单或 Radio Button 组展示
- 切换格式时，参数配置区域动态变化
- 支持设置默认导出格式（在用户偏好中）

## 第95章 导出工程

### 95.1 功能概述

导出工程模块提供将当前项目以可编辑工程格式导出的能力，便于用户在其他专业软件中继续编辑，或将项目打包供后续导入系统继续制作。

### 95.2 导出为 PSD

#### 功能描述

将漫画页面导出为 Adobe Photoshop PSD 格式，保留页面中各元素的图层结构，方便在 Photoshop 中进一步精细编辑。

#### 图层组织结构

```
修仙之王_第5章_Page-001.psd
├── Background（背景层）
├── Panel-001（第1画格组）
│   ├── Layer-001（图片层）
│   ├── Bubble-001（气泡层）
│   │   ├── Bubble-Body（气泡主体）
│   │   └── Bubble-Text（气泡文字）
│   └── Effects（特效层）
├── Panel-002（第2画格组）
│   └── ...
├── Panel-003（第3画格组）
│   └── ...
└── Watermark（水印层，可选）
```

#### 操作流程

1. 选择「导出为 PSD」功能
2. 选择导出范围：当前 Page / 指定章节
3. 配置 PSD 导出参数：

| 参数 | 说明 | 默认值 | 可选值 |
|------|------|--------|--------|
| 图层模式 | 是否为每个元素创建独立图层 | 是 | 是/否 |
| 分组方式 | 按 Panel 分组 / 按元素类型分组 | 按 Panel 分组 | Panel / 类型 |
| 包含文本图层 | 气泡中的文本是否作为可编辑文本层 | 是 | 是/否（栅格化） |
| 色彩模式 | RGB / CMYK | RGB | RGB / CMYK |
| 位深度 | 8bit / 16bit | 8bit | 8bit / 16bit |
| 兼容模式 | 最大化兼容旧版 Photoshop | 是 | 是/否 |

4. 点击「导出」→ 系统逐页生成 PSD 文件
5. 处理完成后打包为 ZIP 下载，或保存到指定目录

#### 界面要求

- 显示预计 PSD 文件大小（取决于图层数量和图片尺寸）
- 提示用户 Photoshop 版本兼容性信息
- 导出进度显示当前正在处理的 Page 编号
- 支持取消正在进行的导出任务

### 95.3 导出为工程包

#### 功能描述

将项目导出为专属工程包格式（.awfproj），供后续导入系统继续编辑。工程包包含项目的结构化数据和关联资源文件。

#### 工程包内容

```
项目名_工程包.zip（或 .awfproj）
├── project.json              （项目元数据）
├── novel/                     （小说数据）
│   ├── chapters.json
│   └── scenes.json
├── characters/                （人物数据）
│   ├── characters.json
│   └── references/            （人物参考图）
├── world/                     （世界观数据）
│   ├── scenes.json
│   ├── props.json
│   └── styles.json
├── storyboard/                （分镜数据）
│   ├── storyboard.json
│   └── layouts.json
├── panels/                    （画格数据）
│   ├── panels.json
│   └── prompts.json
├── images/                    （图片资源）
│   ├── generated/             （AI 生成的图片）
│   └── references/            （参考图片）
├── bubbles/                   （气泡数据）
│   ├── dialogues.json
│   └── narrations.json
└── manifest.json              （清单文件，含版本和校验和）
```

#### 操作流程

1. 选择「导出为工程包」
2. 选择需要导出的数据范围：

| 导出范围 | 说明 | 默认 |
|---------|------|------|
| 全部数据 | 项目所有数据和资源 | 是 |
| 仅结构化数据 | 不包含图片等二进制资源 | 否 |
| 仅选定章节 | 仅导出指定章节的数据 | 否 |

3. 配置导出参数：

| 参数 | 说明 | 默认 |
|------|------|------|
| 包含图片 | 是否包含已生成的图片 | 是 |
| 图片分辨率 | 原始/压缩 | 原始 |
| 包含参考图 | 是否包含参考图片 | 是 |
| 加密 | 是否加密工程包 | 否 |

4. 点击「导出」→ 系统打包导出
5. 导出完成后下载 .awfproj 文件

#### 界面要求

- 显示预估打包大小
- 导出进度条实时更新
- 支持导出完成后复制文件路径
- 工程包文件名自动包含项目名和导出时间

### 95.4 工程包导入

#### 功能描述

将导出的工程包重新导入系统，恢复为可编辑的项目状态。

#### 操作流程

1. 在「项目列表」页面或「导出中心」点击「导入工程包」
2. 选择 .awfproj 文件（支持拖拽上传）
3. 系统解析包内容，显示导入预览：

| 预览信息 | 说明 |
|---------|------|
| 项目名称 | 原项目名称 |
| 导出时间 | 工程包创建时间 |
| 数据概览 | 章节数、角色数、Panel 数、图片数 |
| 总大小 | 工程包文件大小 |
| 版本兼容 | 当前系统版本是否兼容该工程包 |

4. 导入选项：

| 选项 | 说明 | 默认 |
|------|------|------|
| 作为新项目导入 | 创建一个新项目 | 是 |
| 覆盖现有项目 | 覆盖同名项目的现有数据 | 否（仅作为新项目） |
| 冲突处理 | 遇到同名资源时自动重命名/覆盖/跳过 | 自动重命名 |

5. 点击「导入」→ 系统解包并加载数据
6. 导入完成后跳转到项目详情页

#### 界面要求

- 支持拖拽上传和文件选择对话框
- 导入进度条显示解包和加载进度
- 版本不兼容时显示兼容性警告
- 导入完成后显示导入结果摘要

## 第96章 导出项目包

### 96.1 功能概述

导出项目包是完整项目归档功能，与工程包的区别在于：项目包是"快照式"完整归档，包含项目的所有数据、资源、图片以及版本历史，适合长期存档或跨设备迁移。

### 96.2 完整项目归档

#### 功能描述

将整个项目的完整数据打包导出，包括所有章节数据、人物设定、分镜数据、Prompt 数据、生成的图片、编辑历史、版本记录等。

#### 归档内容

```
项目名_归档_20260627.zip
├── archive.json               （归档元数据：版本、时间、系统信息）
├── project/                   （项目数据）
│   ├── project.json           （项目配置和设置）
│   └── tasks.json             （任务历史）
├── data/                      （所有结构化数据）
│   ├── novel/                 （小说）
│   ├── characters/            （人物）
│   ├── world/                 （世界观）
│   ├── scenes/                （场景）
│   ├── panels/                （画格）
│   ├── storyboard/            （分镜）
│   ├── layouts/               （版式）
│   ├── bubbles/               （气泡）
│   └── prompts/               （Prompt）
├── assets/                    （资源文件）
│   ├── images/                （所有图片，按版本组织）
│   ├── fonts/                 （字体文件）
│   └── uploads/               （用户上传素材）
├── history/                   （历史记录）
│   ├── changelog.json         （变更日志）
│   └── versions/              （版本快照）
└── checksums.json             （完整性校验文件）
```

#### 操作流程

1. 进入项目详情页或导出中心
2. 点击「导出项目包」
3. 配置归档参数：

| 参数 | 说明 | 默认 |
|------|------|------|
| 包含图片 | 是否包含所有已生成的图片 | 是 |
| 包含历史版本 | 是否包含图片版本历史 | 是 |
| 包含任务历史 | 是否包含任务执行记录 | 否 |
| 包含系统日志 | 是否包含该项目的相关日志 | 否 |
| 压缩级别 | 0-9 | 6 |
| 分卷大小 | 大文件时分卷打包 | 不分卷 / 2GB / 4GB |

4. 点击「开始归档」
5. 系统显示归档预估大小和进度
6. 归档完成后下载或保存到指定路径

#### 界面要求

- 归档前显示数据量统计（如"项目数据 45MB，图片 1.2GB，历史版本 280MB"）
- 显示预估总大小和压缩后大小
- 归档过程中实时显示进度百分比和当前处理的数据模块
- 归档完成后自动验证完整性（校验和匹配）
- 支持将归档包保存到系统配置的备份存储路径

### 96.3 导入项目包

#### 功能描述

从项目包归档文件恢复项目到系统，支持完整恢复或选择性恢复。

#### 操作流程

1. 在「项目列表」页面或「导出中心」点击「导入项目包」
2. 选择归档文件（.zip 或 .awfarchive）
3. 系统解析并显示导入预览：

| 预览信息 | 说明 |
|---------|------|
| 项目名称 | 原项目名称 |
| 归档时间 | 归档文件创建时间 |
| 数据内容 | 包含的数据模块列表 |
| 版本信息 | 系统版本兼容性 |
| 文件校验 | 完整性校验结果 |

4. 选择导入方式：

| 导入方式 | 说明 |
|---------|------|
| 完整恢复 | 恢复所有数据和资源 |
| 选择性恢复 | 仅恢复选定的数据模块 |
| 合并到现有项目 | 将归档数据合并到已存在的项目中 |

5. 点击「导入」→ 系统解包并加载数据
6. 导入完成后跳转到项目详情页

#### 界面要求

- 支持多文件导入（分卷归档）
- 导入前进行文件完整性校验
- 版本不兼容时提供升级/降级建议
- 导入进度条展示解压进度和数据加载进度
- 导入完成后显示导入结果报告

### 96.4 项目包版本

#### 功能描述

项目包支持版本号管理，每次归档生成唯一版本号，便于用户管理不同版本的项目快照。

#### 版本号规范

项目包版本号格式：`v{主版本}.{次版本}.{归档编号}`

| 版本段 | 说明 | 示例 |
|--------|------|------|
| 主版本 | 项目主要迭代版本，手动标注 | 1, 2, 3 |
| 次版本 | 重大变更时的版本 | 0, 1, 2 |
| 归档编号 | 自动递增的归档序号 | 001, 002 |

例如：`v1.0.003` 表示项目第 1 个大版本的初始状态下的第 3 次归档。

#### 版本管理功能

| 功能 | 说明 |
|------|------|
| 版本标注 | 导出时可为本次归档添加版本标签和说明 |
| 版本列表 | 查看项目包的所有历史版本 |
| 版本对比 | 比较两个版本之间的差异（数据量、章节数、图片数） |
| 版本回滚 | 从旧版本归档恢复项目状态 |

#### 界面要求

- 版本号自动生成，允许用户自定义版本标签
- 版本列表按时间降序排列
- 支持为重要版本添加星标标记
- 对比视图并排展示两个版本的数据统计

## 第97章 发布管理

### 97.1 功能概述

发布管理是为已完成的项目提供版本化发布管理的功能模块，适用于需要连载发布或版本迭代的场景。用户可追踪每次导出的内容变更，管理发布版本历史。

### 97.2 发布版本管理

#### 功能描述

支持为项目创建和管理发布版本，每个版本对应一次完整的导出内容，可记录版本说明和变更内容。

#### 发布版本数据结构

| 字段 | 说明 | 示例 |
|------|------|------|
| 版本号 | 语义化版本号 | v1.0.0 |
| 版本名称 | 用户自定义版本名称 | "初版发布" |
| 关联章节 | 该版本包含的章节 | 第1-5章 |
| 创建时间 | 版本创建时间 | 2026-06-27 14:30:00 |
| 修改时间 | 最后修改时间 | 2026-07-01 10:00:00 |
| 发布状态 | 草稿 / 已发布 / 已归档 | 已发布 |
| 版本说明 | Markdown 格式的变更说明 | 版本说明文本 |
| 关联文件 | 该版本导出的文件列表 | [file1.png, file2.png] |
| 版本标签 | 用户定义的标签 | ["初稿", "修正版"] |

#### 操作流程

1. 进入「发布管理」页面 → 默认展示当前项目的发布版本列表
2. 点击「创建新版本」→ 弹出版本创建对话框
3. 填写版本信息：

| 字段 | 必填 | 说明 |
|------|------|------|
| 版本号 | 是 | 自动建议，可手动编辑 |
| 版本名称 | 否 | 用户自定义名称 |
| 关联章节 | 是 | 选择该版本包含的章节范围 |
| 版本说明 | 否 | 描述本次版本的变更内容 |

4. 点击「创建」→ 版本创建成功，状态为"草稿"
5. 在版本详情中可「发布」→ 状态变为"已发布"
6. 已发布的版本不可修改，可「归档」→ 移出版本列表

#### 界面要求

- 版本列表以时间线样式展示
- 每个版本显示版本号、状态标签、创建时间和版本说明摘要
- 草稿版本显示编辑按钮，已发布版本显示下载按钮
- 支持版本对比（对比两个版本的导出内容差异）
- 版本数量无上限

### 97.3 发布日志

#### 功能描述

记录每次发布的详细日志，包含本次发布的变更内容、导出的文件清单和已知问题。

#### 发布日志内容

| 内容项 | 说明 |
|--------|------|
| 变更摘要 | 本次发布的主要变更概要 |
| 新增功能/内容 | 新增的章节、角色、场景等 |
| 修改内容 | 对已有内容的修改说明 |
| 修复问题 | 修复的 Bug 或问题的列表 |
| 已知问题 | 本次发布中已知但未解决的问题 |
| 导出文件清单 | 本次发布导出的所有文件列表 |
| 导出参数 | 本次导出使用的参数配置 |
| 签名信息 | 文件完整性校验和 |

#### 操作流程

1. 创建或编辑版本时，在「版本说明」区域编写发布日志
2. 支持 Markdown 格式和富文本编辑
3. 系统自动记录导出文件清单和导出参数
4. 发布日志可导出为独立的 Markdown 文件

#### 界面要求

- 发布日志编辑器支持 Markdown 预览
- 系统自动生成的部分（文件清单、参数）不可编辑但可复制
- 发布日志支持全文搜索
- 日志以时间轴形式展示历史

### 97.4 导出记录列表

#### 功能描述

记录用户所有导出操作的历史列表，包括每次导出的时间、格式、范围和结果。

#### 导出记录数据结构

| 字段 | 说明 | 示例 |
|------|------|------|
| 导出 ID | 唯一标识 | EXP-20260627-001 |
| 导出时间 | 操作时间 | 2026-06-27 15:30:00 |
| 导出格式 | PNG / JPG / 长图 / PSD / 工程包 | PNG 序列 |
| 导出范围 | 全部 / 指定章节 | 第3章 |
| 关联项目 | 所属项目 | 修仙之王 |
| 关联版本 | 关联的发布版本（如有） | v1.0.0 |

| 文件数量 | 导出的文件数 | 24 |

4. 成功记录显示「打开文件夹」按钮
5. 失败记录显示「重试」按钮
6. 支持按时间和格式筛选导出记录
7. 支持删除单条或批量清除历史记录

#### 界面要求

- 导出记录以表格列表展示
- 状态列使用图标+颜色标识（绿色✓ / 黄色⚠ / 红色✗）
- 支持分页显示（每页 20 条）
- 支持导出记录导出为 CSV 文件
- 查看详情时弹窗展示完整的导出参数和文件清单
